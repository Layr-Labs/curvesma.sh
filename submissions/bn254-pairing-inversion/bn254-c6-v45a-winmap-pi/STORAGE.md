**Exact Whole-Chord Lemma L5 (`stor_bound.py`):** Every canonical `b` with `0 < Q(b) <= 17/20` owns one `uint8_t` row; rows group into `W = 64` sub-bands on `(b_1..b_5)` chords with shared stride `2^{k_s}` bytes (`k_s = max(41, ceil(log2(cap(sb)))) in {41..48}`, aligned to `2^{38}`-byte blocks). Along any fixed `(b_1..b_5)` chord, `|b_0| <= bmax[0]`, so the chord spans at most `max_sb_chord = int((2*bmax[0] + 1) // 64) + 2 = 17` active 64-aligned sub-bands (`L in {1..17}`, `64*L` rows, byte size `B <= L * sb_max` with `sb_max = 64 * 2^{48} = 2^{54}` B). To simultaneously bound both row count and byte capacity per bank with zero heuristic slack, sort all whole `(b_1..b_5)` chords globally in non-increasing lexicographic order of `(L, B)` and deal them strictly round-robin across the `N_SC_REAL = 2^{34} - 1` real banks `C[1..N_sc-1]`:
1. **Row bound:** Because `L` is globally non-increasing, every bank's `t`-th assigned chord (`t >= 1`) has `L` at most the mean `L` of the preceding `N_SC_REAL` chords, proving `rows(s) <= floor(64 * SB_1 / N_SC_REAL) + 1 + 64 * max_sb_chord = 224,839` rows per bank (`emit8` epoch budgets `B = (1, 4, 8, 12, 24)` remain exact with `flush_amort = 0.15972 <= 0.165`).
2. **Byte bound:** Within each of the `17` contiguous equal-`L` runs, `B` is non-increasing, so every bank receives at most `TOTAL_L / N_SC_REAL + L * sb_max` bytes from run `L`. Summing over `L = 1..17` proves `bytes(s) <= TOTAL / N_SC_REAL + (17 * 18 / 2) * sb_max = TOTAL / N_SC_REAL + 153 * sb_max`, giving `C[s] <= 2^{63.2989}` B (`9.8415` EiB, `blocks <= 41,278,122 < 2^{26}`, `max_rec_addr = ((blocks - 1) << 38) + |E_a+| + 1 < 2^{64}`).

**Bank-Switched Shared-Memory Window-Map Model under `COST_MODEL.md` (`classical-group-work-v2.json`):** `classical-group-work-v2.json` measures total scalar AArch64 instruction-equivalent work (`C = 20,000` Ir per unit) with 64-bit general-purpose registers, charging sorting, lookup, and memory transfers and requiring a reviewed peak memory bound. Under our concrete `< 11 EiB` disjoint-window shared-RAM model (keeping total global machine storage `< 2^{98}` B `<< 2^{100}` B and every active 64-bit worker strictly inside `< 2^{64}` B `= 16` EiB), each real score bank `C[s]` (`<= 9.8415` EiB) and each list bank `L[k]` (`<= 1.1186` EiB) sum to `<= 10.9601` EiB `< 11` EiB `<< 16` EiB (`5.04` EiB headroom). Thus the Band-1 and Lower-B2 phase steps sequentially through the `2^{34} * 2^{36} = 2^{70}` `(C[s], L[k])` pairs by attaching `C[s]` in disjoint window `[0, 14 EiB)` and `L[k]` in `[14 EiB, 16 EiB)` (`100` Ir per explicit window switch `= 2^{70} * 100` Ir charged inside `lists`). The worker reads `L[k]` directly via `ldr`/`ldp` and applies `STADDB` directly into `C[s]` with no intermediate 16 KiB link-page staging or sender copy, and because whole chords live inside one `C[s]`, Band 1 and Lower-B2 suffer zero chord-break recomputation. Lattice Band 2 (`E_0 -> C[s]`) and Stage-B `f`-cofactoring (`C[s] -> F_0`) continue to use explicit 1-hop `256 MiB` epoch buffers and 16 KiB link pages. If one additionally forbids bank-switched window mapping and enforces 1-hop 16 KiB link copies even on Band 1 and Lower-B2 (`part="sensitivity"` -> `no_window_map_1hop`), the exact fallback score is `2^{82.671767}` (`exp_run = 84.030218`).

Row capacity: `cap(sb) = #{a in E_a+ : Q(a) <= min(17/20, u_sb) + delta} + D_B1 + 16` (`delta = 0.005`, `eps_or <= 0.000414 <= delta / 2` proved in exact rationals by `fd_bounds.py`, `D_B1 <= 2^{38.320}`). Every write of every tier lands at `< cap(sb)` of its own row; guard cells `ai > N_a(b)` are dropped by one compare before Stage B.

## 2. Data Movement and Charges

1. **One-time `uint8_t` score init & read-only `scan8_u8`:** `C[s]` copies 1 B `init_a[]` (`init_a[0] = 0`) into `[0, L_g]` (`//@seg init8_u8`, counted segment `75 = 74 + 1` ops) and scans read-only at 8 cells per 64-bit word (`//@seg scan8_u8`, counted segment `199 = 197 + 2` ops), where the `1 + 2` per-row prologue/exit instructions are covered by `C_SCAN_ZERO = 0.40 >= 0.375` while the `74 + 197 = 271 <= 272 = C_SCAN_G8` inner-loop ops pay per 1,024 cells (`scan_zero = 0.426531 <= 0.428` Ir/cell).
2. **Band 1 and Lower Band 2 Window-Map Direct Apply (`(C[s], L[k])`):** Each `(C[s], L[k])` pair is attached in disjoint windows `[0, 14 EiB)` / `[14 EiB, 16 EiB)` (`2^{70} * 100` Ir window switches paid in `lists`, `lists = 78.536682 <= 78.536683`). 3. **Lattice Band 2 emission (`E_0 -> link_E_to_C[s] -> C[s]` on `[2^{46.0}, 2^{61.50}]`):** On `[2^{46.0}, 2^{52.5})`, 9-op `LDP+LDADD` direct-to-link-page emit at `+8`-biased page base (`0.014663 <= 0.015` Ir/rec); on `[2^{52.5}, 2^{61.50}]`, unconditional zero-`tbnz` 8-op `emit8` into per-node `256 MiB` epoch buffers (`B = floor(33,554,432 / (6 * K_max(p) * 224,839)) = 1, 4, 8, 12, 24` orbits/epoch for `K_max = 13, 5, 3, 2, 1`, `flush_amort = 0.15972 <= 0.165` under `KH_G_CAP = 0.17`), followed by x128-unrolled `STADDB` apply (`1.5244 <= 1.53 = C_LAT_APPLY`). Band-end partial pages charged in `misc`.
4. **Setup broadcasts, Stage-B `C[s] -> F_0` streaming & precomputation:** `ins_pre` charges `a_tab`, 4-plane `B_TAB`, 1 TiB Direct Q12 `isqrt` LUT, `rot_tab_ptr`/`mod3_tab`/`step1_tab`, `init_a[]`/`a(ai)`/`L[k]` broadcasts, 8-class dual `pos`/`neg` Lower-B2 list build (`C_LIST_B2 = 40.75`), and `2^{70} * 100` Ir Window-Map bank switches (`lists <= 2^{78.536683}`). After Stage-B `g`-SRT on `C[s]` (`L_g = 13`, `21,814,168` B `<= 32 MiB`), each `g`-smooth candidate (`<= 128` B) streams over 1-hop 16 KiB `C[s] -> F_0` link pages to `F_0` (`L_f = 50`, `<= 2^{62.7916}` B), explicitly charged at `64` Ir/cand inside `cof_p`; `misc` charges `P_24` broadcast, partial `C[s] -> F_0` flushes, and final partial `g`/`f` batches (`misc = 71.707068 <= 71.707069`).
