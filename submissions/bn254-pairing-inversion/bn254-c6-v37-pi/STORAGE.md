# STORAGE.md: Direct Live uint8_t Score Nodes (N_sc = 2^{34}), 1-Hop 16 KiB Link Pages, DF Post-Order Boot Root and the < 2^{98} B Storage Bound

Where the Band 1, Lower Band 2, Lattice Band 2, LA and Boot data lives, how it moves and what moves cost. Every node is a flat 64-bit scalar machine with `< 2^{64}` B of RAM, addressed by unit-cost `ldr/str/ldp/stp/staddb/ldadd` under COST_MODEL.md. Every cross-node byte goes through an explicit 1-hop 16 KiB link page copied by scalar `ldp/stp` (`//@seg x16_bfi_copy`: `130/128 + 59/2046 = 1.0445 <= 1.05` Ir per 8 B word) or, for Band 1 and Lattice Band 2, written directly into the link page by the producer's counted stores (KERNELS.md §1.1, §1.3). Figures are computed in exact rationals by `stor_bound.py` (uniformly up to `R_A_MAX = 589.43 > 575.49`) and checked by `audit_bn_cm.py` (`ram_ok`).

## 1. Node Types and Memory

| Node | Count | Holds | RAM (log2 B) |
|---|---:|---|---:|
| Emitter E_0 | 1 | 16-byte mixed-radix `a_tab = (ai, &B_TAB[k][0])` (`prod_Ma = 79,151,674,016,786,875` entries, `2^{60.136}` B), contiguous 4-plane `B_TAB[0..3]` (`4 * prod_Mb = 1.742e18` 8 B entries, `2^{63.596}` B), 2-op Direct Q12 `isqrt` LUT (`2^{37}` 8 B entries = `1 TiB`, `2^{40}` B), signed-`SXTW` midpoint `rot_tab_ptr` (`2^{27}` 8 B entries = `1 GiB`) + `mod3_tab` (`8 MiB`) + `step1_tab[8192]` (`16 KiB`) + permuted `STEP_K`/`wtab` (`WHEEL_TABS = 2^{31}` B = `2 GiB`), `2^{34}` direct 16 KiB link pages at 32 KiB stride, `ptrs[0..2^{34}-1]`, `E_a+` build arrays | <= 63.723 (emitter_log2: 63.7218; **2.805 EiB headroom**) |
| Score Nodes C[s] | N_sc = 2^{34} | live `uint8_t` (1 byte/cell) score rows of the sub-bands assigned to `s` (`<= avg + 1 sub-band`), `2^{36}` incoming list link pages, 1 incoming emitter link page, `2^{49}` B dummy sink (`> |E_a+|`), `1 B` `init_a[]` + `16 B` `a(ai)` tables (`17 |E_a+|` B), 1.5 MB Stage-B batch | <= 63.391 (score_node_log2: 63.3898; blocks: 43,963,490 < 2^{26}) |
| List Nodes L[k] | N_list = 2^{36} | Band 1 lists (`uint32_t` 1-byte rank delta-packed on `[2^{24}, 2^{29.5})` + 8 B on `[2^{29.5}, 2^{40.5})`) and dual pre-complemented (`pos`/`neg`) aligned-`bfi` Lower Band 2 lists (all lists at 8x `<= 2^{55.3}` B/node, node max `< 2^{58} < 2^{60}` B pool), build scratch (`<= 2^{56}` B), `2^{34}` outgoing link pages (`2^{48}` B) + 16 B stream state, sub-band/line descriptors | <= 60.176 (list_node_log2: 60.1751; model 60.1744) |

Score rows (truncated `E_{12}`: `Q(a) <= 17/20, Q(b) <= 17/20, B_a = 2, BLK = 38`, `uint8_t` 1 byte/cell). Each canonical `b` with `0 < Q(b) <= 17/20` owns one row; rows are grouped in `W = 64` sub-bands on `(b_1..b_5)` chords with shared stride `2^{k_s}` bytes (`k_s in [38, 48]`), aligned to `2^{38}`-byte blocks (`W * 2^{k_s}` alignment for `W in {8, 16}` guarantees bits `[k_s .. k_s + log2(W) - 1] == 0`). Greedy least-loaded assignment guarantees each Score Node holds `<= avg + 64 * 2^{48}` B (`<= 2^{63.3898}` B, `blocks = 43,963,490 < 2^{26}`). `B_TAB[k][pack_b] = (s << 30) | row_block` has 34-bit `s` in `[63:30]`, 4 zero bits `[29:26] = 0000`, and 26-bit `row_block` in `[25:0]`; max record address `((blocks - 1) << 38) + |E_a+| + 1 < 2^{64}`. Out-of-domain `b` maps to `0` (C[0] dummy sink blocks `[0, 2^{11})`, `2^{49}` B `> |E_a+|`, disjoint from real rows).

Row capacity: `cap(sb) = #{a in E_a+ : Q(a) <= min(17/20, u_sb) + delta} + D_B1 + 16` (`delta = 0.005`, `eps_or <= 0.0003844 <= delta / 2` proved in exact rationals by `fd_bounds.py`, `D_B1 <= 2^{38.578}`). Every write of every tier lands at `< cap(sb)` of its own row; guard cells `ai > N_a(b)` are dropped by one compare before Stage B.

## 2. Data Movement and Charges

Serial deterministic 1-hop 16 KiB dual-ported link-page model with per-link doorbells (`<= 20` Ir per side handoff):
1. **One-time `uint8_t` score initialisation & read-only `scan8_u8`:** `C[s]` copies 1-byte `init_a[]` (`init_a[0] = 0`) into `[0, L_g]` (`//@seg init8_u8`, `74` ops/1,024 cells) and scans read-only at 8 cells per 64-bit word (`//@seg scan8_u8`, `197` ops/1,024 cells; total `271/1024 <= 272/1024 = C_SCAN_G8`, single-row tail `0.375 <= 0.40 = C_SCAN_ZERO`, `scan_zero = 0.425437 <= 0.426` Ir/cell, `scan8_u8_errs = 0`).
2. **Lattice Band 2 emission (`E_0 -> link_E_to_C[s] -> C[s]`):** 9-op `LDP+LDADD` direct-to-link-page emit + 8-op `emit_direct_flush` (`0.014663 <= 0.015` Ir/rec) + x128-unrolled `STADDB` apply (`1.5230 <= 1.53 = C_LAT_APPLY`), all executed instruction by instruction by `v25_verify.py lat_apply_e2e` across all 4 contiguous planes at full production width (`ai` up to `2^{48}-1`, `rb = 43,963,489`, `s_max = 2^{34}-1`). Only `6` distinct `w_p in [16..21]` bands on `[2^{45.5}, 2^{61.0}]`; band-end partial pages charged at `4,130` Ir in `misc`.
3. **Band 1 and Lower Band 2 streams (`L[k] -> link_L_to_C[k][s] -> C[s]`):**
   - Band 1 writes 32-bit 1-byte rank delta segments on `[2^{24}, 2^{29.5})` (`delta_b1_copy/apply`, `2.82 + 24*P_ov`) and 8 B records `(row_block << 38) + ai` on `[2^{29.5}, 2^{40.5})` (`C_HIT_LO = 3.5699`, `v25_verify.py` check 2) directly into `link_L_to_C[k][s]`.
   - **Lower Band 2 explicit sender copy + receiver loops (zero accounting gap):** `L[k]` streams pre-complemented `(ai << 4) | j_rel` 8-byte words into `link_L_to_C[k][s]` via `//@seg x16_bfi_copy` (`.rept 64` `ldp/stp`: `130/128 + 59/2046 = 1.0445 <= 1.05` Ir/record incl. flush & bidirectional doorbells). This `1.05` Ir/record sender charge is explicitly added into every Lower Band 2 per-hit/miss price: interior `3.625 + 1.05 = 4.675 <= 4.70 = C_B2_INT_X4`, 1-sided boundary `6.625 + 1.05 = 7.675 <= 7.75` (hit) / `3.625 + 1.05 = 4.675 <= 4.75` (miss), and 2-sided boundary `7.625 + 1.05 = 8.675 <= 8.75` (hit) / `4.625 + 1.05 = 5.675 <= 5.75` (miss), with inline headers inside `C_SB_ENTER_X4 = 20.05` and partial pages charged in `misc` (`misc <= 2^{71.612990}`).
4. **Setup broadcasts & precomputation:** `ins_pre` explicitly charges `4 * prod_Ma` (16-B `a_tab`), `2 * (4 * prod_Mb)` (4-plane `B_TAB`), `16 * 2^{37}` (1 TiB Direct Q12 `isqrt` LUT), and `16 * 2^{27}` (`2^{27}`-entry `rot_tab_ptr` + `mod3_tab` + `step1_tab`) alongside `init_a[]`/`a(ai)`/`L[k]` broadcasts and dual `pos`/`neg` Lower-B2 list build (`lists <= 2^{77.974513}`).

## 3. Other Single-Worker Working Sets (< 2^{64} B)

1. List builders on `L[k]`: Lower-B2 1-prime build `<= 2^{52.302}` B, Band-1 build `<= 2^{51.630}` B (rounded to `2^{56}` B in `stor_bound.py`; with shell arena `<= 2^{57.537}` B).
2. Stage-B `P_min = 24` `g_rec` SRT: `1.5` MB.
3. 1-owner 16-vec `Z[omega]` BW LA (`bw = (768, 40)`): `<= 2^{62.5531}` B `< 2^{64}` B (`2^{59.4469}` B SpMV + `2^{62.3750}` B PM-Basis workspace).
4. 1-owner deterministic `ntt3_F` Bernstein split (`Q = 2^{46}`): `<= 2^{57.0}` B (`SP` prime-tree level `<= 2^{56.0}` B + batch PT/RT workspace `32 * 29 * 2^{46} <= 2^{55.9}` B; rounded up to `2^{58}` B in `stor_bound.py`).
5. **1-owner depth-first post-order all-primes boot root + exact Karatsuba/sequential-NTT3 workspace schedule (`boot = [185, 80, 11, 1], ea = [3, 1185], x_EA = 62.9375, cap = 1.0` ALL rational primes `<= 2^{62.9375}`):**
   - **Retained storage:** ONLY the single root integer `P` (`m_root = ceil(pbits(0, 62.9375, 1.0)/64) = 5.5263 * 2^{55}` 64-bit limbs, `|P| = 8 * m_root = 2^{60.4663}` B = `1.382` EiB). ZERO internal prime-tree levels are retained, and ZERO prime-tree recomputation ever occurs because `gbatch_cost` only reads `P` to reduce `P mod M` at the top of each candidate-batch product tree (wave `|M| <= 2^{53.0}` B `<< |P|`, streaming chunked reduction uses `1.01 * |P|`).
   - **Exact byte-by-byte recursive Karatsuba + sequential 3-prime NTT3 + streaming Garner CRT workspace schedule (matching `M.ntt3_F`'s `m > 2^{55}` recursion threshold):**
     - **Base case (`m <= 2^{55}` limbs):** Transform length `N_ntt = min(2^k, 3*2^{k-2} >= m)` (at `m_3 = 0.6908 * 2^{55}`, `N_ntt = 3 * 2^{53} = 1.0857 * m_3`). The 3 primes `p_1, p_2, p_3` run **sequentially**, reusing TWO in-place NTT buffers `T_A, T_B` (`2 * 8 * N_ntt` B) plus TWO retained residue buffers `R_0, R_1` (`2 * 8 * m` B); prime `p_3` streams Garner CRT word-by-word directly into the caller's output `P_out` (`O(1)` carry registers, no `R_2` buffer). CRT non-overflow holds for all `m <= 2^{55}`: `(m/2)*(2^{64}-1)^2 < 2^{182.0} < 2^{182.696} = p_1*p_2*p_3`. Thus base-case extra scratch is `S_base(m) = 2*8*N_ntt + 2*8*m` (`0.5214 * |P|` at `m_3`).
     - **Karatsuba step (`m > 2^{55}` limbs, `h = ceil(m/2)`):** Writes `z_0 = A_0*B_0` directly into `P_out[0..h-1]` and `z_2 = A_1*B_1` directly into `P_out[h..2h-1]` (zero extra output buffers), then allocates `S_A = A_0+A_1`, `S_B = B_0+B_1`, and `Z_1 = S_A*S_B` (`2 * 8 * (h+2)` B total) and recurses on `h+2`, followed by in-place `Z_1 -= z_0 + z_2`, `P_out[h/2..] += Z_1`, and immediate free. Across the 3 Karatsuba levels (`m_0 -> m_1 -> m_2 -> m_3`), extra scratch sums geometrically: `(1.000 + 0.500 + 0.250 + 0.5214) * |P| = 2.2714 * |P|`.
     - **Peak 1-owner RAM across ALL 61 tree depths (`d = 0..60`):** At depth `d`, pending left-sibling stack is `< (1 - 2^{-d}) * |P|`, inputs + output are `2 * 2^{-d} * |P|`, and scratch is `W(m_d)`. Maximum occurs at `d = 0` (`stack = 0`): `P_L+P_R (1.000) + P_out (1.000) + W(m_0) (2.2714) =` **`4.2714 * |P| = 2^{62.5610}` B = `5.90` EiB `<< 8.0 * |P| = 2^{63.4663}` B = `11.06` EiB `< 2^{64}` B`** (**10.1 EiB headroom**!). Verified live in `v32_verify.py boot_df_tree_ok` both at exact production size across all 61 depths (`boot_df_peak_ratio = 4.2714`, `ntt3_crt_no_ovf = True`) and via bit-exact 3-level Karatsuba + sequential 3-prime NTT3 + streaming Garner CRT execution on a 64-limb product with explicit `alloc`/`free` tracking (`boot_kar_ntt3_live_peak_ratio = 4.8125 < 8.0`, `boot_df_stack_ratio = 0.9991`).
