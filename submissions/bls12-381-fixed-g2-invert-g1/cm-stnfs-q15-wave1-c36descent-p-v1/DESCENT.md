## Lattices

## Targets and Boot

For each target `z in {h, T}` (`h = e(P_0, Q)`, `T = e(P, Q)`), each fresh boot ball draws uniform `e in [0, r-1]` and blinds `z' = z * gamma_0^e in G_T \subset F_{p^12}^* = (F_{p^4}[X]/(X^3 - u omega^2))^*` using the Stage-1 calibrated factor-base generator `gamma_0` with known nonzero `V(gamma_0) = V_0 mod r` (`proof.md` section 1; exact `lambda`-cancellation without `V(g_0)` or a third descent).

- **Exact `F_{p^6}`-Subfield Elimination (`z' -> gamma_z -> L_boot(z')`):** Write `z' = Z_0 + Z_1 X + Z_2 X^2` with `Z_j in F_{p^4}`, and split each `Z_j = e_j + o_j * d` into `F_{p^2}`-even and `F_{p^2}`-odd parts via `Frob^2` (`e_j, o_j in F_{p^2}`, `d = y - Frob^2(y)`). Set `s := c_0 + c_1 X + c_2 X^2 in F_{p^6}^* = (F_{p^2}[X]/(X^3 - u omega^2))^*` with `c_0 = e_1 o_0 - o_1 e_0`, `c_1 = o_2 e_0 - e_2 o_0`, `c_2 = e_2 o_1 - o_2 e_1 in F_{p^2}`. Then `W := s * z' = W_0 + W_1 X + 0 * X^2` has zero `X^2`-coefficient identically (`c_0 e_2 + c_1 e_1 + c_2 e_0 = c_0 o_2 + c_1 o_1 + c_2 o_0 = 0`; degenerate `z' = 1` or `W_1 = 0` occurs with probability `<= 1/r + p^-4 < 2^-254` and simply draws a fresh `e`). Define **`gamma_z := -W_0 * W_1^(-1) in F_{p^4}`** and the 16D boot lattice
  `L_boot(z') := {(a, b) in O_H^2 : phi_4(a) = gamma_z * phi_4(b) in F_{p^4}}`
  (determinant `p^4` in `Z^16`, `log2(p^4) = 1523.988`).
- **Exact Virtual-Logarithm Recovery Identity:** For EVERY `(a, b) in L_boot(z')` with `phi_4(b) != 0`,
  `phi_12(a - b X) = phi_4(b) * (gamma_z - X) = (-phi_4(b) * W_1^(-1)) * s * z'` in `F_{p^12}^*`.
  Since `(-phi_4(b) * W_1^(-1)) in F_{p^4}^*`, `s in F_{p^6}^*`, and **`gcd(r, p^4 - 1) = gcd(r, p^6 - 1) = 1`** with `lcm(p^4 - 1, p^6 - 1) | (p^12 - 1)/r` (ALL asserted LIVE on `4` real 381-bit `G_T` targets in `audit_cm.py` `voronoi_exact`!), both proper-subfield factors vanish identically under `V` (`V(-phi_4(b) W_1^(-1)) = V(s) = 0 mod r`), hence **`V_g(a - b X) = V(z') = V(z) + e * V_0 mod r`** identically!
