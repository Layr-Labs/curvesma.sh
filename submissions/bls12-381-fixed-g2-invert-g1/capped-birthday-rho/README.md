# capped-birthday-rho

Single-trajectory distinguished-point Pollard rho in GT for fixed-G2 pairing
inversion into G1, capped at `ceil(sqrt(r))` walk steps with the certified
`1 - e^{-1/2} = 0.3935` birthday success probability.

- [Argument and cost ledger](proof.md)
- [Submission manifest](submission.json)

Analytic construction; no full-size execution. Memory is reported separately.
