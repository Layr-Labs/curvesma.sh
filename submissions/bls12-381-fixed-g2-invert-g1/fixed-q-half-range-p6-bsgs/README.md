# Half-range BSGS by Frobenius-6 inversion

Deterministic discrete log in `⟨e(P0, Q)⟩` for instance-fixed nonidentity `Q`.
Odd-degree negation is `π^6`, and on GT that map is inversion. Baby width
`M = 2^126`, stride `2(M-1)`, one canonical lookup per giant step.
The score is the first claim in `submission.json`. The accounting is in
`proof.md`.
