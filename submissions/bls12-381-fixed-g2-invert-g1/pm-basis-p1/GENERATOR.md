Use block dimensions m=8192, n=130; n is divisible by five, so all existing five-vector kernels run full batches. Keep the original square sparse-plus-10-dense matrix, three active vector owners, Schirokauer columns and row-tail charge700. No right-hand-side/padded-column matrix reformulation is used. H-X is the same nonzero-minor hypothesis for this chosen block-diagonal X and random Y, now at the stated block sizes; its production truth remains assumed. ## Recursion and correctness

For a k-by-c power-series matrix F and integer shift s, let M(F,l)={v in F_r[x]^(1 by k): vF=0 mod x^l}. A shifted order basis B spans this module and has full-rank shifted leading matrix. Here k=m+n and c<=k. The shifted degree of a row is max_j(deg(v_j)+s_j).

Base l=1: sort rows by (shift,index). In that order Gaussian-eliminate each constant row against previously selected pivot rows, carrying the same operations on an identity matrix. Mark rows that introduce pivots. Multiply each marked transformation row by x; leave the zero-discrepancy rows constant. Constant transformed rows are the kernel of F(0), marked rows form a complementary space; thus these rows span exactly M(F,1). Sorted pivot selection is rank-profile elimination: transformations use only preceding rows of no greater shift. Consequently their shifted leading matrix has full rank and their shifted degrees are minimal. No arbitrary-degree arithmetic is hidden in this base case.

For l>1 put h=floor(l/2). Compute B1=PM(F,h,s), with shifted row degrees t. Form G=(x^-h B1 F) mod x^(l-h). Compute B2=PM(G,l-h,t); return B2 B1 and its row degrees. Since every v in M(F,l) belongs to M(F,h), write v=w B1 uniquely. Its remaining condition is w G=0 mod x^(l-h), so w lies in the module spanned by B2. This proves spanning and independence inductively. Shifted row reduction is preserved: if the shifted leading matrix of B1 is nonsingular, leading coefficients of wB1 have degree exactly the t-shifted degree of w; applying this to the independent leading rows of B2 gives the result. Each entry of a basis at order l has degree<=l, by induction from base degree1; this does not assume balanced shifts.

For the block sequence S_i=X^T A^i Y (m by n), use F=[S^T; I_m], a (n+m)-by-m series, with shift (0 repeated n,1 repeated m). Take the n rows of least shifted degree; their first n entries are denominator relations. If a selected row has degree d and denominator coefficients q_j[a], its order conditions for t>=d give sum_{a,j} S_(t-a)[:,j] q_j[a]=0. Under the inherited H-X observability/nondegeneracy condition, L=ceil((N+10)/m)+ceil((N+10)/n)+2 terms suffice to make this the true relation sum_(a,j) A^(d-a)Y_j q_j[a]=0. This is the same block Wiedemann recovery hypothesis used by the parent, not an unconditional claim for arbitrary sequences.

For completeness, the existing Horner recovery can be expressed directly: form the n-by-n matrix C of the highest-index coefficients q_j[d] of these rows and find a nonzero left nullvector c of C. For each row form v_i=sum_(a<d,j) A^(d-a-1)Y_j q_j[a]. Then A v_i=-Y q[d], hence A(sum_i c_i v_i)=0. Under H-X the resulting vector is nonzero and spans the one-dimensional kernel from H3; otherwise verification detects failure. Horner uses the same block passes and five checkpoint chains as the parent. The toy exercises this complete extraction on 40 diagonal dimension8 matrices (20 dense X,20 shuffled block-diagonal X) with a one-dimensional kernel. Toy success does not establish H-X at production size.

## Scalar polynomial multiplication

Canonical coefficients lie in [0,r), r<2^255. For lengths<=T+1, encode coefficient a_i at bit576i. For T=2^51, every convolution coefficient is <(T+1)r^2<2^562, so slots cannot carry into one another. A single integer multiplication of the encoded operands returns the exact polynomial convolution; extract slots and reduce modulo r. The product uses at most18T+18 64-bit limbs. The inherited H-FFT function F(z)=8.5 z log2(z)^2+1200+504z beyond2^26 limbs is charged for the complete integer product, including its distributed transfers. Per polynomial product add4096T instructions for packing, extracting, nine-limb Barrett reduction, allocation, additions and addressing. Nine-by-four-limb reductions are the same bounded-width operations already priced by the package; 4096 per coefficient is deliberately generous. The optional packing toy compares this representation with independent schoolbook multiplication at the production r, lengths1..128. It proves neither the large-size integer-multiplication price nor that price's extrapolation.

The algorithm processes actual order L, not a series falsely zero-padded to order T; T is only an accounting envelope for its recursion tree. Each internal recursion node of order l has two polynomial matrix multiplications (B1 F and B2 B1), at most2k^3 scalar polynomial products of lengths<=l+1. ## Memory and support

Even storing several full k-by-k degree-L matrices uses <2^90 bytes (k<2^14, L<2^51, 32-byte field coefficients and bounded recursion multiplicity). Distributed arrays use labeled chunks of at most2^60 bytes; charge owner/offset manipulation and copying within the4096-per-coefficient allowance. H-FFT's504-per-limb distributed transfer charge is retained. Krylov/Horner checkpoints grow from4*17 to4*130 vectors, still below2^80 bytes. These bounds fit the inherited total2^105-byte core peak, dominated by descent, and2^106-byte submitted memory bound. Work is summed across all owners.
