## 1. The Three Separated Premises

Let $M_{\mathrm{full}} \in \mathbb{Z}[\omega]^{R \times U'}$ be the raw relation matrix over order-6 $\tau$-orbits ($\tau = \operatorname{Frob}^{10}$, $\chi = p^{10} \bmod r$, $\chi^2 - \chi + 1 \equiv 0 \pmod r$), augmented by $s_{\mathrm{sm}} = 5$ Schirokauer columns $S_{\mathrm{full}} = [W_f(P_\chi \Lambda_f) \mid W_g(P_\chi \Lambda_g)] \in \mathbb{F}_r^{R \times 5}$ ($\alpha^{r^2-1} \bmod r^2$ across all 6 CRT components of $h \bmod r$, $\chi$-eigenspace dims $4$ and $1$, uniform random $W_f \in \mathbb{F}_r^{4 \times 48}, W_g \in \mathbb{F}_r^{1 \times 12}$; under `H-SM`, compression loses rank w.p. $\le 5/r < 2^{-250}$, in `FIX-U`). After singleton/clique purge, degree-preserving excess-row trim with LIFO `repurge_stack` back-sub ($< 2^{55}$ ops in `misc`, **0 post-peel $\le 2^{59}$ cols lost** live), Markowitz merge ($W_{\mathrm{avg}} \le 161.0$), and Boudot order-labeled recorded pivots $L_{\mathrm{rec}}$ (lower-triangular unit diagonal), the surviving live system on $D = N_l + s_{\mathrm{sm}}$ unscreened rows has exact Schur-complement operator
$$M_{\mathrm{prod}} = M_{\mathrm{live}} - E_{\mathrm{live}} L_{\mathrm{rec}}^{-1} B_{\mathrm{rec}}, \qquad S_{\mathrm{prod}} = S_{\mathrm{live}} - E_{\mathrm{live}} L_{\mathrm{rec}}^{-1} S_{\mathrm{rec}}, \qquad A = [M_{\mathrm{prod}} \mid S_{\mathrm{prod}}] \in \mathbb{F}_r^{D \times D},$$
with zero-padded $B = [M_{\mathrm{prod}} \mid 0]$.

1. **Layer (a) — `H-R` (1D Kernel):** $\operatorname{rank}(M_{\mathrm{prod}}) = N_l$ and $\operatorname{rank}(A) = D - 1$, so $V = \operatorname{Im}(A)$ has $\dim V = D - 1$ and $\ker(A) = \operatorname{span}_{\mathbb{F}_r}\{(w_{\mathrm{true}}, c_{\mathrm{true}})\}$ with $c_{\mathrm{true}} \ne 0$ (recorded pivots recovered uniquely via $L_{\mathrm{rec}} w_{\mathrm{rec}} = -(B_{\mathrm{rec}} w_{\mathrm{true}} + S_{\mathrm{rec}} c_{\mathrm{true}})$).
2. **Layer (b) — `H-X` (Padded BW Controllability, Observability, & Shifted $\sigma$-Basis Extraction):**
   Draw dense uniform 64-bit $Z \in \mathbb{F}_r^{N_l \times (n-5)}$, set $Y = [S_1,\dots,S_5, B Z] \in \mathbb{F}_r^{D \times n}$, and let $X \in \mathbb{F}_r^{m \times D}$ have fixed sparse block-diagonal support placing the $5$ pad coords in distinct blocks $0..4$ and partitioning $N_l$ across the $m$ blocks with uniform 64-bit entries. At depths $d = \lceil D/n \rceil + 1 + \lceil D/(128n) \rceil$, $e = \lceil D/m \rceil + 1 + \lceil D/(128m) \rceil$, premises (supported diagnostically by `hx_z6.py`):
   - **Controllability:** $\operatorname{rank}(C_d) = N_l$ for $C_d = [B Z, B Y, \dots, B^d Y]$ ($\operatorname{span}(C_d) = \operatorname{Im}(B)$);
   - **Observability:** $O_e = [X; X B; \dots; X B^{e-1}]$ is injective on $V = \operatorname{Im}(A)$ ($\operatorname{rank}(O_e A) = D - 1$).

   **Recovery Theorem (exact):** Let $R_d = [Y, B Y, \dots, B^d Y]$, $H = [X B^{i+j} Y]_{0 \le i < e,\; 0 \le j \le d} = O_e R_d$.
   - *(Existence)* For $(w, c) \in \ker(A)\setminus\{0\}$, $c \ne 0$ and $S_{\mathrm{prod}} c = -M_{\mathrm{prod}} w \in \operatorname{Im}(B) = \operatorname{span}(C_d)$, so $S_{\mathrm{prod}} c = -B Z e_0 - \sum_{i=1}^d B^i Y f_i$; setting $f_0 = (c, e_0)$ gives $R_d f = 0 \implies H f = 0$ with $f_0[:5] = c \ne 0$.
   - *(Soundness)* Any $f = (f_0,\dots,f_d)$ with $H f = 0$ and $c = f_0[:5] \ne 0$ has $R_d f \in V \cap \ker(O_e) = \{0\}$, hence $\bar{w} = Z e_0 + \sum_{i=1}^d (B^{i-1} Y f_i)[:N_l]$ satisfies $M_{\mathrm{prod}} \bar{w} + S_{\mathrm{prod}} c = 0 \implies (\bar{w}, c) \in \ker(A)$ recovers $(w_{\mathrm{true}}, c_{\mathrm{true}})$ up to scalar.
   - *(Shifted Beckermann–Labahn $\sigma$-Basis Extraction inside `gen_at_cap` + `la`)* Let $L = d + e < L_{\mathrm{cap}}$, $A(z) = \sum_{k=0}^{L-1} A_k z^k \in \mathbb{F}_r[z]^{m \times n}$, $F(z) = [A(z) \mid -I_m] \in \mathbb{F}_r[z]^{m \times (n+m)}$, shift $\vec{s} = (0^n, 1^m)$ ($\vec{s}\text{-deg}(g,q) = \max(\deg g, 1+\deg q)$).
     1. *Kernel equivalence:* For $g(z) = \sum_{j=0}^d f_{d-j} z^j$ and $q(z) = (A(z)g(z)) \bmod z^d$, $[z^{d+i}](A(z)g(z)-q(z)) = (Hf)_i$ ($0 \le i < e$), so $H f = 0 \iff F(z)(g,q)^T \equiv 0 \pmod{z^L}$ with $\vec{s}\text{-deg}(g,q) \le d$.
     2. *Deterministic extraction:* Let $V(z) = [v^{(1)},\dots,v^{(k)}]$ ($k = n+m$, $v^{(\ell)} = (g^{(\ell)}, q^{(\ell)})^T$) be an order-$L$, $\vec{s}$-minimal $\sigma$-basis of $F(z)$ with $\vec{s}$-degrees $\delta_\ell$. Every retained column $\delta_\ell \le d$ gives $z^{d-\delta_\ell} v^{(\ell)}$ with reversed $f^{(\ell)} = ([z^{\delta_\ell}]g^{(\ell)},\dots,[z^0]g^{(\ell)},0,\dots,0) \in \ker(H)$. By Beckermann–Labahn (1994 Thm. 4.1), the Existence vector $w^* = (g^*, q^*)^T$ ($\vec{s}\text{-deg} \le d$, $[z^d]g^*[:5] = c_{\mathrm{true}} \ne 0$) expands as $w^* = \sum_{\delta_\ell \le d} c_\ell(z) v^{(\ell)}(z)$ with $\deg c_\ell \le d - \delta_\ell$. Taking $[z^d]$ on rows $0..4$ gives $c_{\mathrm{true}} = \sum_{\delta_\ell \le d} ([z^{d-\delta_\ell}]c_\ell)([z^{\delta_\ell}]g^{(\ell)}[:5]) \ne 0$, proving **deterministically** that some retained column $\delta_\ell \le d$ has nonzero leading SM block $f^{(\ell)}_0[:5] \ne 0$. Scanning $\le k$ columns ($O(k)$ ops) and evaluating in `la` recovers $(\bar{w}, c)$ with $c \ne 0$ (NO dense fallback).
     3. *Strict `PM-Basis` cost (`gen_at_cap`):* Divide-and-conquer `PM-Basis` (Giorgi–Jeannerod–Villard 2003) runs $\lceil\log_2 L\rceil$ levels ($L < L_{\mathrm{cap}} \approx 2^{38.2}$). Level $t$ runs $2^t$ subproblems of order $s = \lceil L/2^t \rceil$, each costing $< 2 k^3$ $\mathbb{F}_r[z]$ products of length $\le s$. Since $s(r-1)^2 < 2^{38.2+508} = 2^{546.2} < 2^{576} = (2^{64})^9$, 9-limb Kronecker packing maps each product to one length-$18s$ integer convolution (`fft_F(18s)`, zero carry bleed) + unpack & 9-limb Barrett mod-$r$ reduction ($\le 320 \cdot 2s = 640s$ Ir). By superadditivity $2^t \mathrm{fft}_F(18L/2^t) \le \mathrm{fft}_F(18L)$ and scalar base cases ($L \cdot 2mk^2 \cdot 320 \ll k^3 \cdot 640L$), total work $\le (2\lceil\log_2 L\rceil + 1)k^3(\mathrm{fft}_F(18L)+640L) \le 4k^3\log_2(L_{\mathrm{cap}})(\mathrm{fft}_F(18L_{\mathrm{cap}})+640L_{\mathrm{cap}}) = \texttt{gen\_at\_cap}$.
3. **Layer (c) — Conditional Schwartz-Zippel:** Under `H-R` + `H-X`, the product of the nonzero $N_l$-minor of $C_d$ in $Z$ and $(D-1)$-minor of $O_e U$ in $X$ has degree $\le N_l + (D-1) < 4 N_l \le 4 N_{\mathrm{sw,cap}}$ in the 64-bit draws $(X, Z)$, giving failure probability $\le 4 N_{\mathrm{sw,cap}} / 2^{64} = 3.656 \times 10^{-6}$ (`main_matrix` in `FIX-U`).
