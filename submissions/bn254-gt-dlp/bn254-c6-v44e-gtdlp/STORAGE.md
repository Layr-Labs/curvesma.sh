# STORAGE.md: Direct Live uint8_t Score Nodes (N_sc = 2^{34}), 1-Hop 16 KiB Link Pages, 256 MiB Epoch Buffers, DF Post-Order Boot Root and the < 2^{98} B Storage Bound

Where the Band 1, Lower Band 2, Lattice Band 2, LA and Boot data lives, how it moves and what moves cost. Every node is a flat 64-bit scalar machine with `< 2^{64}` B of RAM, addressed by unit-cost `ldr/str/ldp/stp/staddb/ldadd` under COST_MODEL.md. Every cross-node byte goes through an explicit 1-hop 16 KiB link page copied by scalar `ldp/stp` (`//@seg x16_bfi_copy_page + x16_bfi_copy`: `130/128 + (59 + 11)/2046 = 1.04984 <= 1.05` Ir per 8 B word, zero OOB writes across `n in [0, 2,046]`) or, for Band 1 and Lattice Band 2, written directly into the link page by the producer's counted stores (KERNELS.md §1.1, §1.3). Figures are computed in exact rationals by `stor_bound.py` (uniformly up to `R_A_MAX = 572.0 > 568.83`) and checked by `audit_bn_cm.py` (`ram_ok`). All stated `<= 2^{...}` ceilings round UP.

Score rows (truncated `E_{12}`: `Q(a) <= 17/20, Q(b) <= 17/20, B_a = 2, BLK = 38, K_MIN_STRIDE = 41`, `uint8_t` 1 B/cell). Each canonical `b` with `0 < Q(b) <= 17/20` owns one row; rows group in `W = 64` sub-bands on `(b_1..b_5)` chords with shared stride `2^{k_s}` bytes (`k_s = max(41, ceil(log2(cap(sb)))) in {41..48}`, exact 8 stride classes aligned to `2^{38}`-byte blocks). All real rows are assigned exclusively to `C[1..N_sc-1]` (`2^{34} - 1` nodes): per-stratum greedy assignment across each of the 8 stride classes guarantees every real Score Node holds `<= avg + 2 * 64 * 2^{48}` B (`<= 2^{62.9035}` B, `blocks <= 31,382,183 < 2^{25} < 2^{26}`) AND `max_rows_per_Cs <= 224,263` rows (ZERO sink records). `B_TAB[k][pack_b] = (s << 30) | row_block` has 34-bit `s` in `[63:30]`, 4 zero bits `[29:26] = 0000`, and 26-bit `row_block` in `[25:0]`; max record address `((blocks - 1) << 38) + |E_a+| + 1 < 2^{64}`. Out-of-domain `b` maps to `0` (`s = 0`, `C[0]` pure dummy sink holding 0 real rows and `2^{49}` B sink); on `E_0`, `body_2` resets `ptrs[0] = &ep_buf[0][0]` (`ldr x8, [sp, #416]; str x8, [x17]`) before every `k0_body` loop so `ep_buf[0]` holds at most `781 * 909 = 709,929 << 33,554,432` slots (`47.26x` unconditional margin) and is never flushed during `emit8` epochs (`[52.5, 61.50]`; on `emit9` `[44.0, 52.5)`, any filled 16 KiB sink page flushes normally into `C[0]`'s `2^{49}` B sink).

Row capacity: `cap(sb) = #{a in E_a+ : Q(a) <= min(17/20, u_sb) + delta} + D_B1 + 16` (`delta = 0.005`, `eps_or <= 0.000414 <= delta / 2` proved in exact rationals by `fd_bounds.py`, `D_B1 <= 2^{38.320}`). Every write of every tier lands at `< cap(sb)` of its own row; guard cells `ai > N_a(b)` are dropped by one compare before Stage B.

## 2. Data Movement and Charges

Serial deterministic 1-hop 16 KiB dual-ported link-page model with per-link doorbells (`<= 20` Ir per side handoff):
1. **One-time `uint8_t` score init & read-only `scan8_u8`:** `C[s]` copies 1 B `init_a[]` (`init_a[0] = 0`) into `[0, L_g]` (`//@seg init8_u8`, `74` ops/1,024 cells) and scans read-only at 8 cells per 64-bit word (`//@seg scan8_u8`, `197` ops/1,024 cells; total `271/1024 <= 272/1024 = C_SCAN_G8`, single-row tail `0.375 <= 0.40 = C_SCAN_ZERO`, `scan_zero = 0.426531 <= 0.428` Ir/cell).
2. **Lattice Band 2 emission (`E_0 -> link_E_to_C[s] -> C[s]` on `[2^{44.0}, 2^{61.50}]`):** On `[2^{44.0}, 2^{52.5})`, 9-op `LDP+LDADD` direct-to-link-page emit at `+8`-biased page base `pbase = 32,768*s + 8` (`LDADD` returns bit 14 == 1 on record `2,046`; 8-op `emit_direct_flush` resets `ptrs[s] = B+24`, `0.014663 <= 0.015` Ir/rec); on `[2^{52.5}, 2^{61.50}]`, unconditional zero-`tbnz` 8-op `emit8` (`8/8/8/6` ops) into per-node `256 MiB` epoch buffers (`B = floor(33,554,432 / (6 * K_max(p) * 224,263)) = 1, 4, 8, 12, 24` orbits/epoch for `K_max = 13, 5, 3, 2, 1`, proved overflow-free in exact rationals over `Q(a) <= 1 + DELTA`, all 6 signed `S`-rotations, and `ai = 0` by `v39_emit8_ok`) + 10-op `emit8_epoch_flush` (amortization `0.15972 <= 0.165 = EMIT8_FLUSH_AMORT` Ir/leaf under `KH_G_CAP = 0.17`), followed by x128-unrolled `STADDB` apply (`1.5244 <= 1.53 = C_LAT_APPLY`). Band-end partial pages charged at `4,130` Ir in `misc`.
3. **Band 1 and Lower Band 2 streams (`L[k] -> link_L_to_C[k][s] -> C[s]`):** Band 1 writes 32-bit 1-byte rank delta segments on `[2^{24}, 2^{29.5})` (`2.82 + 24*P_ov`) and 8 B direct records `(row_block << 38) + ai` on `[2^{29.5}, 2^{40.0})` (`C_HIT_LO = 3.5704`). Zero-`bfi` 2-band Lower-B2 (`[2^{40.0}, 2^{44.0})`) streams `(j_stored << k_s) | ai` (`k_s in {41..48}`) via `x16_bfi_copy_page+x16_bfi_copy` (`<= n*130/128 + 11`, `0` OOB writes): `<= S` sub-band entries + receiver prologues/tails + sender entries are paid in `C_SB_ENTER_X4 = 42.60`, while `<= P` page-boundary sender calls + flush/doorbells + receiver restarts total `130/128 + (59 + 11 + 22)/2046 = 1.06059` Ir/rec, strictly covered in every receiver price (`3.6856 <= 3.70` interior, `5.6856 <= 5.75` / `3.6856 <= 3.75` bnd1, `7.6856 <= 7.75` / `5.6856 <= 5.75` bnd2). Partial end-of-run pages are charged in `misc` (`misc = 71.799086 <= 71.799087`).
4. **Setup broadcasts, Stage-B `C[s] -> F_0` streaming & precomputation:** `ins_pre` charges `a_tab`, 4-plane `B_TAB`, 1 TiB Direct Q12 `isqrt` LUT, `rot_tab_ptr`/`mod3_tab`/`step1_tab`, `init_a[]`/`a(ai)`/`L[k]` broadcasts, and 8-class dual `pos`/`neg` 2-band Lower-B2 list build (`C_LIST_B2 = 40.75`, `lists <= 2^{77.116037}`). After Stage-B `g`-SRT on `C[s]` (`L_g = 13`, `21,814,168` B `<= 32 MiB`), each `g`-smooth candidate (`<= 128` B) streams over 1-hop 16 KiB `C[s] -> F_0` link pages to `F_0` (`L_f = 50`, `<= 2^{62.7916}` B), explicitly charged at `64` Ir/cand inside `cof_p`; `misc` charges `P_24` broadcast, partial `C[s] -> F_0` flushes, and final partial `g`/`f` batches.

## 5. Patch-Stencil Tables on `E_0` (proof.md §8)
