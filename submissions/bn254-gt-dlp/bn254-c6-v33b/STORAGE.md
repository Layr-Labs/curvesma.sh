# STORAGE.md: Direct Live uint16_t Score Nodes, 1-Hop 16 KiB Link Pages, DF Post-Order Boot Root and the < 2^{100} B Storage Bound

Where the Band 1, Lower Band 2, Lattice Band 2, LA and Boot data lives, how it moves and what moves cost. Every node is a flat 64-bit scalar machine with `< 2^{64}` B of RAM, addressed by unit-cost `ldr/str/ldp/stp/staddh/ldadd` under COST_MODEL.md. Every cross-node byte goes through an explicit 1-hop 16 KiB link page copied by scalar `ldp/stp` (`1.007 <= 1.05` Ir per 8 B word) or, for Band 1 and Lattice Band 2, written directly into the link page by the producer's counted stores (KERNELS.md §1.1, §1.3). Figures are computed in exact rationals by `stor_bound.py` (uniformly up to `R_A_MAX = 589.43 > 575.36`) and checked by `audit_bn_cm.py` (`ram_ok`).

## 1. Node Types and Memory

| Node | Count | Holds | RAM (log2 B) |
|---|---:|---|---:|
| Emitter E_0 | 1 | 16-byte mixed-radix `a_tab = (2*ai, &B_TAB[k][0])` (`prod_Ma = 79,151,674,016,786,875` entries, `2^{60.136}` B), contiguous 4-plane `B_TAB[0..3]` (`4 * prod_Mb = 1.742e18` 8 B entries, `2^{63.596}` B), 2-op Direct Q12 `isqrt` LUT (`2^{37}` 8 B entries = `1 TiB`, `2^{40}` B), wheel/rot/centered-mod3 tables (`rot_tab` 64 MiB + `mod3_tab` 8 MiB + `STEP1_TAB` 128 KiB + permuted `STEP_K`/`wtab`, `< 2^{27}` B), `2^{35}` direct 16 KiB link pages at 32 KiB stride, `ptrs[0..2^{35}-1]`, `E_a+` build arrays | <= 63.723 (emitter_log2: 63.7219; **2.805 EiB headroom**) |
| Score Nodes C[s] | N_sc = 2^{35} | live `uint16_t` (2 bytes/cell) score rows of the sub-bands assigned to `s` (`<= avg + 1 sub-band`), `2^{36}` incoming list link pages, 1 incoming emitter link page, `2^{50}` B dummy sink (`> 2 * |E_a+|`), `2 B` `init_a[]` + `16 B` `a(ai)` tables (`18 |E_a+|` B), 1.5 MB Stage-B batch | <= 63.394 (score_node_log2: 63.3920; blocks: 44,031,851 < 2^{26}) |
| List Nodes L[k] | N_list = 2^{36} | Band 1 lists (`uint32_t` even-byte delta-packed on `[2^{24}, 2^{28.5})` + 8 B on `[2^{28.5}, 2^{40.5})`, mean `<= 2^{53.55}` B/node) and aligned-`bfi` Lower Band 2 lists (all lists at 8x `<= 2^{55.11}` B/node, node max `<= 2^{57.08} < 2^{60}` B pool), build scratch (`<= 2^{56}` B), `2^{35}` outgoing link pages (`2^{49}` B) + 16 B stream state, sub-band/line descriptors | <= 60.176 (list_node_log2: 60.1754; model 60.1747) |

Score rows (truncated `E_{12}`: `Q(a) <= 17/20, Q(b) <= 17/20, B_a = 2, BLK = 38`, `uint16_t` 2 bytes/cell). Each canonical `b` with `0 < Q(b) <= 17/20` owns one row; rows are grouped in `W = 64` sub-bands on `(b_1..b_5)` chords with shared stride `2^{k_s}` bytes (`k_s in [38, 49]`), aligned to `2^{38}`-byte blocks (`W * 2^{k_s}` alignment for `W in {8, 16}` guarantees bits `[k_s .. k_s + log2(W) - 1] == 0`). Greedy least-loaded assignment guarantees each Score Node holds `<= avg + 64 * 2^{49}` B (`<= 2^{63.3920}` B, `blocks = 44,031,851 < 2^{26}`). `B_TAB[k][pack_b] = (s << 29) | row_block` has 35-bit `s` in `[63:29]`, bits `[28:26] = 000`, and 26-bit `row_block` in `[25:0]`; max record address `((blocks - 1) << 38) + 2*(|E_a+| + 1) < 2^{64}`. Out-of-domain `b` maps to `0` (C[0] dummy sink blocks `[0, 2^{12})`, `2^{50}` B `> 2*|E_a+|`, disjoint from real rows).

Row capacity: `cap(sb) = #{a in E_a+ : Q(a) <= min(17/20, u_sb) + delta} + D_B1 + 16` (`delta = 0.005`, `eps_or <= 0.0003844 <= delta / 2` proved in exact rationals by `fd_bounds.py`, `D_B1 <= 2^{38.578}`). Every write of every tier lands at `< cap(sb)` of its own row; guard cells `ai > N_a(b)` are dropped by one compare before Stage B.

## 2. Data Movement and Charges

Serial deterministic 1-hop 16 KiB dual-ported link-page model with per-link doorbells (`<= 20` Ir per side handoff):
1. **One-time `uint16_t` score initialisation & read-only `scan8_u16`:** `C[s]` copies 2-byte `init_a[]` (`init_a[0] = 0`) into `[0, L_g]` and scans read-only at 4 cells per 64-bit word (`C_SCAN_G8 = 550/1024`, `scan_zero = 0.842658 <= 0.843` Ir/cell, `scan_group_overhead = 1.0179 <= 1.05`, `scan8_u16_errs = 0`).
2. **Lattice Band 2 emission (`E_0 -> link_E_to_C[s] -> C[s]`):** 9-op `LDP+LDADD` direct-to-link-page emit + 8-op `emit_direct_flush` (`0.014663 <= 0.015` Ir/rec) + x128-unrolled `STADDH` apply (`1.5230 <= 1.53 = C_LAT_APPLY`), all executed instruction by instruction by `v25_verify.py lat_apply_e2e` across all 4 contiguous planes at full production width (`2*ai` up to `2^{49}-2`, `rb = 44,048,381`). 248 log-p bands on `[2^{45.5}, 2^{61.0}]`; band-end partial pages charged at `4,130` Ir in `misc`.
3. **Band 1 and Lower Band 2 streams (`L[k] -> link_L_to_C[k][s] -> C[s]`):** Band 1 writes 32-bit even-byte delta segments on `[2^{24}, 2^{28.5})` (`delta_b1_copy/apply`, `2.82 + 24*P_ov`) and 8 B records `(row_block << 38) + 2*ai` on `[2^{28.5}, 2^{40.5})` (`C_HIT_LO = 3.5699`, `v25_verify.py` check 2) directly into `link_L_to_C[k][s]`. Lower Band 2 streams `(ai << 5) | j_rel` words at 1.05 Ir/8 B inside `C_B2_INT_X4 = 4.30` and inline headers inside `C_SB_ENTER_X4 = 20.05`. Partial pages charged in `misc` (`misc <= 2^{72.395730}`).
4. **Setup broadcasts & precomputation:** `ins_pre` explicitly charges `4 * prod_Ma` (16-B `a_tab`), `2 * (4 * prod_Mb)` (4-plane `B_TAB`), `16 * 2^{37}` (1 TiB Direct Q12 `isqrt` LUT), and `16 * 2^{27}` (`rot_tab`/`mod3_tab`) alongside `init_a[]`/`a(ai)`/`L[k]` broadcasts (`lists <= 2^{77.905660}`).

## 3. Other Single-Worker Working Sets (< 2^{64} B)

1. List builders on `L[k]`: Lower-B2 1-prime build `<= 2^{52.300}` B, Band-1 build `<= 2^{51.628}` B (rounded to `2^{56}` B in `stor_bound.py`; with shell arena `<= 2^{57.537}` B).
2. Stage-B `P_min = 24` `g_rec` SRT: `1.5` MB.
3. 1-owner 16-vec `Z[omega]` BW LA (`bw = (768, 40)`): `<= 2^{62.7557}` B `< 2^{64}` B (`2^{59.4539}` B SpMV + `2^{62.6015}` B PM-Basis workspace).
4. 1-owner deterministic `ntt3_F` Bernstein split (`Q = 2^{46}`): `<= 2^{57.0}` B (`SP` prime-tree level `<= 2^{56.0}` B + batch PT/RT workspace `32 * 29 * 2^{46} <= 2^{55.9}` B; rounded up to `2^{58}` B in `stor_bound.py`).
5. **1-owner depth-first post-order all-primes boot root (`boot = [185, 80, 11, 1], ea = [3, 1185], x_EA = 62.9375, cap = 1.0` ALL rational primes `<= 2^{62.9375}`):**
   - **Retained storage:** ONLY the single root integer `P` (`|P| = pbits(0, 62.9375, 1.0)/8 = 2^{60.4663}` B = `1.382` EiB). ZERO internal prime-tree levels are retained, and ZERO prime-tree recomputation ever occurs because `gbatch_cost` only reads the single root integer `P` to compute `P mod M` at the top of each candidate-batch product tree (whose wave buffer is `<= 2^{53.0}` B).
   - **Peak 1-owner construction/FFT/Garner workspace:** Evaluating the balanced prime product tree **depth-first post-order** discards both children immediately after each multiplication, keeping the pending left-sibling stack strictly geometric (`< 1.0 * |P|`). Including the two operands (`|P|`) and up to `6 * |P|` scratch for the final top-level 3-prime FFT + Garner multiplication gives peak 1-owner RAM conservatively bounded by **`8 * |P| = 2^{63.4663}` B = `11.06` EiB `< 2^{64}` B** (`4.94` EiB headroom), verified live on a 1,024-leaf tree by `boot_df_tree_ok` in `v32_verify.py` (`boot_df_stack_ratio = 0.9991`, `boot_df_peak_ratio = 7.0 <= 8.0`, vs `11.08` for storing all levels simultaneously) and asserted in `audit_bn_cm.py` `ram_ok`.

## 4. Total Machine Storage (< 2^{100} B, pointwise) and Sensitivity

- Exact-rational `stor_bound.py` certificate: `|E_a+| <= 2^{47.6022}`, sub-bands `<= 2^{46.0185}`, `uint16_t` score rows `<= 2^{98.3870}` B; per Score Node `<= 2^{63.3920}` B (`blocks = 44,031,851 < 2^{26}`); `E_0 <= 2^{63.7219}` B (**2.805 EiB headroom**); `L[k] <= 2^{60.1754}` B; **total machine storage `<= 2^{98.6732}` B `< 2^{100}` B** (`ram_log2 = 98.6732`, `storage_cap_abort = 0.0`).
