# Individual-Logarithm Descent (`Q(zeta_15)`, Certified Single Trial per Slot, Abort-Only Recovery, Fresh-`e` Boot)

`q15_descent16.py` implements the descent model and the shipped `76`-node plan (`PLAN16`, `BOOT16`); `q15_cert16.py` implements the per-lattice yield certificate; `verify_q15_descent.py` (run by `audit_cm.py` as `q15_c36_descent`) evaluates the plan at `MESH = 384`, `TRUNC = 0.0`, re-checks the production certificate archive `q15_cert_prod.b85` and the toy archive `q15_toy_cond.b85`. Every pair `(a, b) in O_H^2` is a vector in `Z^16` in the power basis `1, y, ..., y^7` of `O_H = Z[zeta_15]` (`Phi_15(y) = y^8 - y^7 + y^5 - y^4 + y^3 - y + 1`, `deg_Q(f_9) = 72`, `deg_Q(g_3) = 24`).

## 1. Composite Special-`q` Lattices `L_{Q, p_rand}` & `Q_CM` 2-Phase Bareiss Integer LLL

Every descent node targets a degree-1 special-`q` prime ideal `Q = (q, y - s, x - t)` on side `f` or `g` in one of `38` bins `[68.5, 75), [75, 80), ..., [255, 260)` (`76` `(bin, side)` entries, `LB = LX = 68.5`, `LMAX = 260`). A trial draws one known-log `f_9` prime ideal `p_rand` uniformly from the `4,740` live-counted degree-1 `f_9` ideals with norm in `[2^14, 2^16)` (`579` split primes `p === 1 mod 15`, counted deterministically live in `verify_q15_descent.py`), forming composite index-`(q * p_rand)` sublattices `L_{Q, p_rand}` (`bp = (14.0, 16.0)`):
- Each composite lattice `L_{Q, p_rand}` (and boot lattice `L_boot`, `det = p^4 * 2^168` after `S_boot = 2^21` scaling) is reduced by exact pure-integer 2-phase Bareiss LLL (`11/40` Euclidean -> `99/100` `Q_CM`; uniform bounds derived in `KERNELS.md` §5, zero floating-point LLL) under `Q_CM(a, b) = a^T G_8 a + b^T G_8 b` (`det(G_8) = 3^4 * 5^6`, `lambda_max(G_8) = 15`).
- Search regions are Euclidean radius-`R` half-balls `B_16(R) / {+-1}` in reduced-basis coordinates (`q15_cells16.py` computes exact integer half-counts `C_R`, asserted live at `C_2 = 17,072`, `C_4 = 642,328,192`, `C_8 = 35,245,626,789,232`, `C_256 / Vol = 1 +- 1e-4`).
- `screen_special_q_basis` rejects rank-deficient short-subspace bases (checked live on the `(135, g)` example `q = 81009504249198611324243595142290546015061, t = 5/8 mod q`), and the integer `BOUND_CELL (+6)` routine (`5,000` Ir/cell, `q15_bound_cell.py`, charged on both sieve and direct-ECM branches) caps every processed cell at `(N_f <= 2^{nf_max}, N_g/q <= 2^{ng_max})`.

## 2. Fresh-`e` Boot (`BOOT16 = (230, 312, 15, 2)`, `BALL_PAIR = 0.0`)

For each target `z in {h = e(P_0, Q_0), z_T = e(T, Q_0)}`, each boot draw takes a **fresh uniform blinding exponent `e in [0, r-1]`**, forms `z' = z * gamma_0^e in G_T` using the calibrated Stage-1/2 factor-base blinding generator `gamma_0 := phi_iso^(-1)(a_0 - b_0 X)^{e_cof}` (`e_cof := (p^12 - 1)/r`, `gcd(r, e_cof) == 1` asserted live, known nonzero `V_0 = e_cof * V_g(a_0 - b_0 X) mod r != 0`), lifts `z'` via Guillevic `F_{p^6}`-subfield elimination (`W_1 != 0` proved unconditionally since `gcd(r, lcm(p^4 - 1, p^6 - 1)) == 1`, verified live on `4` real 381-bit `G_T` targets), reduces `L_boot(z')` (`LLL_BOOT = 2^47`), and samples **ONE** uniform half-cell `v ~ Unif(B_16(2)/{+-1})` (`BALL_PAIR = 0.0` exact since `N in {0, 1} => N(N - 1) == 0`).
- **100%-Fresh Production-HNF 16-Cal / 48-Holdout `BOOT_KEEP_FRAC = 0.90 < CP95 LB = 0.9395`:** Any draw with `log2 N_g > m_max = 24 * c_b + log2(U_8) + cal16_cutoff = 2589.79` (`cal16_cutoff = -225.22`) is deterministically discarded; `64` fresh 381-bit `G_T` targets (`1,092,608` exhaustive `R = 2` half-cells; `0/48` holdout target exceedances and `0/819,456` holdout cell exceedances, `CP95 LB = 0.05^(1/48) = 0.93949 > 0.90`) certify `BOOT_KEEP_FRAC = 0.90`.
- **Linear Union-Bound Missing-Leaf Retention:** Any boot or node relation containing a missing factor-base ideal is discarded directly using the **linear Boole union bound `max(0.0, 1.0 - miss)`** (no Poisson `exp(-miss)` step; at `LX = 68.5`, `boot_miss = 0.11281 -> boot_lin_keep = 0.88719`, `max_miss_node = 0.05288`).
- **No descent failure (`p_descent_fail = 0`).** Nothing below the root fails: slots only *abort* to their parent (section 3). A boot relation with an aborting child is skipped and the boot keeps drawing fresh uniform `e`, so a logarithm is always completed; the expected number of boot relations per logarithm is `<= 1/(1 - r_b)`, `r_b = (kA_b + 1) * max A_child = 0.2302`. Every run is cut by the hard meter `T_run = 2^123` u, whose stop probability is bounded by Markov's inequality in `proof.md` section 6.

## 3. Node Procedure, Yield Certificate and Abort Recovery

A slot is one visit of a special-`q` ideal `Q` in plan entry `(bin, side)` with radius `R`, windows `(n, iA, kA, kB)`. It runs:
1. **Draw and reduce.** Draw `p_rand` uniformly from the `4,740`-ideal pool (`q15_cert16.draw_prand`: a uniform index decoded to `(p, s, t)`), form `L = L_{Q, p_rand}`, reduce it (`LLL_NODE = 2^40` Ir).
2. **Certify (`q15_cert16.py`).** Draw `S_CERT = 256` uniform primitive half-cells `c` of `B_16(R)/{+-1}` (fresh coins), compute the exact norms and
   `X_c = s_f(N_f(c)) * s_g(N_g(c)) / m_c`,
   where `s_f, s_g` are the entry's two-window semismooth lower sums (the same `ss_lower2` and windows that price the plan, `q` and `p_rand` removed from their sides) and `m_c` is the exact number of cells of the unit orbit `{eps c}` inside `B_16(R)/{+-1}` (Fincke-Pohst over `eps = sum e_k y^k` in the quadratic form `||sum e_k c Y^k||^2 <= R^2`, `Y` = multiplication by `y` in reduced coordinates; the Gram matrix is integral, its `LDL^T` factors are exact rationals and every enumeration bound is an exact comparison, so the enumeration is complete; kept iff `det(eps) = +-1`). Summing `X_c` over the ball counts each orbit once, so
   `mu(L) = N_prim(R) * E_c[X_c] * det * lin_keep * ret`
   is the expected number of distinct usable relations of the trial (`det`, `lin_keep`, `ret` = the entry's ECM-success, missing-leaf and sieve-retention factors of section 4). The certificate is the layer-cake lower bound `E[X] >= sum_j (x_j - x_{j-1}) P(X >= x_j)` on the `J = 21` levels `x_j = x_plan * 2^{j/2}` (`j = -8..12`, `x_plan` = the plan's per-cell charge); each `P(X >= x_j)` is replaced by its one-sided Clopper-Pearson lower bound at level `(DELTA_CERT / D_MAX) / J`, `DELTA_CERT = 1e-9`, `D_MAX = 64`, the same rule on every draw. The trial is certified iff this bound times `N_prim * det * lin_keep * ret` is `>= MU_CERT = 15`. For every lattice, `P(a draw is certified and mu(L) < 15) <= 1e-9 / 64` over the node's own coins, and a slot makes at most `64` draws, so its sieved lattice has `mu(L) >= 15` except with probability `<= 1e-9`. The certificate applies the search's admission rules exactly (`q15_cert16.cell_weight`): a draw whose reduced basis fails `screen_special_q_basis` is uncertified, and a cell with zero norm, `v_Q(N_side) >= 2`, or a `BOUND_CELL` upper bound above the entry's cap `(nf_max, ng_max)` (with `q` and `p_rand` removed from their sides) gets weight `0`. It reads only norms and orbit sizes, never smoothness outcomes. An uncertified draw is discarded and step 1 repeats; after `D_MAX = 64` uncertified draws the slot **aborts** (below). An ideal is *good* if a draw certifies with probability `>= 1/2` over the node's coins (draws are i.i.d. and identically distributed); a good ideal aborts here with probability `<= 2^-64`. Ideals with structural short vectors, such as the `(135, g)` example `t = 5/8 mod q` whose composite lattices all fail the basis screen, are not good and abort after `64` draws (`2^46` Ir). Cost per draw: `LLL_NODE + CERT_DRAW`, `CERT_DRAW = 2^34` Ir (`256` exact norms, `BOUND_CELL` evaluations, orbit enumerations and the bound), charged as `(LLL_NODE + CERT_DRAW) / CERT_PASS_LO`, `CERT_PASS_LO = 1/2`, plus `P_BAD * 64` draws for ideals that are not good.
3. **Sieve the certified ball once** (`dsieve16`, eager cofactorisation of all survivors, or direct ECM on the five `R = 12` `f` entries) and order its usable relations uniformly at random. Take the first; certify each of its `<= n_ch = 2 (kA + kB)` children (their certified lattices are kept for their own descent) and descend them. If a child aborts, the relation is **rejected** and the next usable relation of the ball is taken.
4. **Abort.** The slot aborts to its parent if its ideal does not certify within `64` draws, if its certified ball has at most `3` usable relations (including none), or if its first `R_ABANDON = 4` usable relations are rejected. Its parent then rejects the relation that produced it. Nothing fails below the root (section 2).

**Abort and work bounds.** Let `A` be a bound on a slot's abort probability and `r = n_ch * max A_child` the chance that one of its relations is rejected (`H6`: children of distinct relations abort independently, each with probability `<= A_child`). By `H6` the ideal is not good with probability `<= P_BAD = 0.01`; by `H5` and the certificate error a certified ball has `<= 3` usable relations with probability `<= P_LOW + 1e-9`, `P_LOW = 0.004`; and the first `4` relations are all rejected with probability `<= r^4`. Hence
    `A = P_BAD + P_LOW + 1e-9 + 2^-64 + r^4`,
and the slot descends at most `1/(1 - r)` relations in expectation, each costing at most the sum of its children's expected work (aborted children included). The recurrence prices one certified sieve trial per slot:
  - `W[b, side] = own_1 + P_BAD * 64 * (LLL_NODE + CERT_DRAW) + (kA * (wmax('f', nA) + wmax('g', nA)) + kB * (wmax('f', n) + wmax('g', n))) / (1 - r)`
  - `A[b, side] = P_BAD + P_LOW + 1e-9 + 2^-64 + r^4`, `r = 2 (kA + kB) * max_{child entries} A`
On the shipped plan `max A = 0.0144` and every `r <= 0.1405`; the boot pays `1/(1 - r_b)` boot relations and child subtrees per completed logarithm, `r_b = 0.2302`.
- **Branch-Tree-Capped `L_min = 2` Geometric-Ladder ECM (`q15_ecm16.py`):** Every cofactorization call uses `tree_branch_caps(nbits, b_min=32, l_min=2)` (exact DP upper bound on `sum L_i^2` and `sum gcd_instr(b_i)` over all active composite-branch partitions with `b_i >= 32` using the `47`-op `mont2_cios` kernel for `L = 2`), a `12`-bit geometric ECM ladder (`ladder_v9_instr` from `16`b up to `fbits`), separation penalty `SEPARATION = 0.5`, explicit failed-replay retry pricing `p_r = 0.0043` paying BOTH `per_curve` and full `replay_1curve`, and `NEWTON_PRECHECK_INSTR = 2^26` Ir.
- **Eager Cofactorization & Uncapped `dsieve16`:** `71` nodes use uncapped `dsieve16` (`SIEVE_HIT = 2,600` Ir, `PAIR_SETUP = 2^35.2`, `LLL_NODE = 2^40.0`, `BOUND_CELL = 5,000` Ir) and `5` high-`f` `R = 12` nodes `[180, 205)` use direct ECM (`ret = counted_fraction = 0.906510`, explicitly charging `BOUND_CELL` on every cell). Every sieve node cofactors all survivors (`cofac_frac = 1.0`, `eager = True`).

## 5. Premises `H5`, `H6` and Evidence

Both premises enter only the **expected work**: with abort-only recovery no descent event can make a run fail (section 2), so the success bound uses neither.

- **`H5` (certified ball).** For a slot with ideal `Q`, the trial lattice `L = L_{Q, p_rand}` is drawn by the algorithm's uniform `p_rand`; once it is certified (`mu(L) >= 15` in the model of section 3), the probability over that draw that its ball holds at most `3` usable relations is at most `P_LOW = 0.004`. Model basis: in the random-integer model that `H1` uses for collection, the usable-relation events of the distinct orbits of the ball are independent with their per-cell probabilities at the cells' norm sizes, giving `P(M <= 3) <= 2.1e-4`. Empirical basis (toy, below): `0` of `830` distinct ideals has any lattice with `mu_L >= 15` and `M <= 3`; counting ideals rather than lattices (the clusters), this bounds the fraction by `0.0036` at `95%`.
- **`H6` (reached ideals).** A reached ideal is *good* (each certificate draw passes with probability `>= 1/2`) except with probability `<= P_BAD = 0.01`, and children of distinct relations abort independently. Basis, in three parts. (i) Goodness is a property of the ideal's own lattice `L_Q`; the known non-good ideals (e.g. the `(135, g)` example, `t = 5/8 mod q`) contain an `O_H`-submodule of rank `8` whose covolume is far below `det(L_Q)^(1/2)`. (ii) Being reached adds one piece of information about a child `Q'`: it divides the norm of a usable cell `w` of its parent's ball, i.e. the rank-`8` submodule `O_H w` lies in `L_{Q'}`. On production lattices of every plan entry (`2` per entry, `uniform` ideals), the `Q_CM`-covolume of `O_H w` exceeds `det(L_{Q'})^(1/2)` at the largest child size the entry allows by `>= 9.4` bits for the shortest reduced vector `w = b_1` and by `>= 44` bits over `2,304` sampled cells of the searched balls; the structure forced by being reached is thus a long submodule, the opposite of the one that makes an ideal non-good (this does not exclude that a child also has a short one, which is what the campaign below measures); apart from it, a child is selected by the smoothness of its cofactor, which `H1` treats as independent of which ideal of norm `q'` divides the cell. Relations are ordered uniformly at random, so the first usable relation is a uniform choice among the usable ones. (iii) The production campaign checks goodness on uniform ideals of each entry at its hardest norms. Children of distinct relations are distinct ideals with disjoint lattices of cells, hence the independence assumption.

- **Toy test of the lattice-conditional law (`q15_toy_cond.b85`, re-checked by the audit).** On `Q(zeta_15)` `16`D `Q_CM`-LLL `q * p_rand` lattices with exact relation detection, each lattice's expected count `mu_L` was computed from its own cells' norms (calibrated relation rate per `2`-bit `(log2 N_f, log2 N_g)` bin, leave-one-ideal-out; for reached children also per `1`-bit `log2 q`, their own large-prime bound, as the production certificate does through each entry's windows). Literal production polynomials `f_9, g_3` (`64` ideals x `24` `p_rand` = `1,536` lattices): dispersion `D = sum (M - mu)^2 / sum mu = 0.90`, empty lattices `9` vs `6.5` predicted by `exp(-mu_L)`, all with `mu_L <= 7.5`. Degree-`(32, 24)` strict-descent parents (`1,536`): `D = 1.02`, `0` empty vs `0.01`. Reached children (`1,536`): `13` empty vs `18.5` predicted, all with `mu_L <= 6.3` (`D = 1.33`). A fourth cohort (`c2big`) runs the literal polynomials on all `900` toy ideals of norm in `[451, 5000]` x `8` `p_rand` draws, to count distinct ideals: dispersion `D = 0.92`, `26` empty lattices vs `34.6` predicted, none with `mu_L >= 10` (`2,585` lattices). Across all four cohorts none of the `5,231` lattices with `mu_L >= 10` is empty. For `P_LOW` the units are ideals: `731` (`c2big`) + `64` (`c1A`) + `35` (`c1C`) = `830` distinct ideals have lattices with `mu_L >= 15`, and none of them has any such lattice with `M <= 3`. Without per-lattice expectations the same counts are strongly overdispersed (raw Fano `2.9`-`10.4`), which is why the production algorithm certifies each lattice.
- **Production campaign with the algorithm's trial law (`q15_cert_prod.b85`; `q15_cert16.certify_entry`).** Uniform `p_rand` from the pool, basis screen, admission rules, exact orbit sizes and the per-draw budget `1e-9 / 64`, exactly as a slot runs them. Each of the `76` plan entries: `600` fresh production ideals at the bin top edge (the hardest norms of the entry), uniform among the degree-`1` ideals of that bit length (`q15_cert16.sample_ideal_uniform`: uniform `q = 1 mod 15`, uniform primitive `s`, the pair kept with probability `#roots / deg`, then a uniform root), one draw each (seed `2031`). All `45,600` draws pass the basis screen and certify; no sampled cell is rejected by the admission rules; the smallest certified value is `78.3`, certified/planned `mu >= 2.62` (median `9.71`). Since every draw follows the same rule, an ideal that is not good fails a given draw with probability `> 1/2`, so `0` failures among an entry's `600` draws bound its fraction of non-good ideals by `2 (1 - 0.05^(1/600)) = 0.00994 <= P_BAD` at `95%` confidence, entry by entry. The audit re-checks every entry; each entry's first record is reproducible from its seed with `q15_cert16.certify_entry`.
- **Shipped plan (`384` mesh).** `76` nodes (`71` sieve + `5` direct-ECM), planned `min_mu = 15.38`, slot abort bound `max A = 0.0144`, boot relation rejection `r_b = 0.2302`, `boot_u = 106.3852`, `sub_u = 105.7947`, **`two_log_units = 107.119924`** core `F_{p^12}` units (`C = 20,000`; charged `107.1360` in `cm_data.json`, `+0.0160`b slack; `x10` for `C = 2,000` G1 units).
