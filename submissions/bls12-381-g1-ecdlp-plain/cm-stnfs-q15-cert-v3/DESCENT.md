# Individual-Logarithm Descent (`Q(zeta_15)`, Certified Single Trial per Slot, Boole over Slots, Fresh-`e` Wald Boot Renewals)

`q15_descent16.py` implements the descent model and the shipped `76`-node plan (`PLAN16`, `BOOT16`); `q15_cert16.py` implements the per-lattice yield certificate; `verify_q15_descent.py` (run by `audit_cm.py` as `q15_c36_descent`) evaluates the plan at `MESH = 384`, `TRUNC = 0.0`, re-checks the production certificate archive `q15_cert_prod.b85` and recomputes two of its lattices live. Every pair `(a, b) in O_H^2` is a vector in `Z^16` in the power basis `1, y, ..., y^7` of `O_H = Z[zeta_15]` (`Phi_15(y) = y^8 - y^7 + y^5 - y^4 + y^3 - y + 1`, `deg_Q(f_9) = 72`, `deg_Q(g_3) = 24`).

## 1. Composite Special-`q` Lattices `L_{Q, p_rand}` & `Q_CM` 2-Phase Bareiss Integer LLL

Every descent node targets a degree-1 special-`q` prime ideal `Q = (q, y - s, x - t)` on side `f` or `g` in one of `38` bins `[68.5, 75), [75, 80), ..., [255, 260)` (`76` `(bin, side)` entries, `LB = LX = 68.5`, `LMAX = 260`). A trial draws one known-log `f_9` prime ideal `p_rand` uniformly from the `4,740` live-counted degree-1 `f_9` ideals with norm in `[2^14, 2^16)` (`579` split primes `p === 1 mod 15`, counted deterministically live in `verify_q15_descent.py`), forming composite index-`(q * p_rand)` sublattices `L_{Q, p_rand}` (`bp = (14.0, 16.0)`):
- Each composite lattice `L_{Q, p_rand}` (and boot lattice `L_boot`, `det = p^4 * 2^168` after `S_boot = 2^21` scaling) is reduced by exact pure-integer 2-phase Bareiss LLL (`11/40` Euclidean -> `99/100` `Q_CM`; uniform bounds derived in `KERNELS.md` §5, zero floating-point LLL) under `Q_CM(a, b) = a^T G_8 a + b^T G_8 b` (`det(G_8) = 3^4 * 5^6`, `lambda_max(G_8) = 15`).
- Search regions are Euclidean radius-`R` half-balls `B_16(R) / {+-1}` in reduced-basis coordinates (`q15_cells16.py` computes exact integer half-counts `C_R`, asserted live at `C_2 = 17,072`, `C_4 = 642,328,192`, `C_8 = 35,245,626,789,232`, `C_256 / Vol = 1 +- 1e-4`).
- `screen_special_q_basis` rejects rank-deficient short-subspace bases (checked live on the `(135, g)` example `q = 81009504249198611324243595142290546015061, t = 5/8 mod q`), and the integer `BOUND_CELL (+6)` routine (`5,000` Ir/cell, `q15_bound_cell.py`, charged on both sieve and direct-ECM branches) caps every processed cell at `(N_f <= 2^{nf_max}, N_g/q <= 2^{ng_max})`.

## 2. Fresh-`e` Wald Boot Renewals (`BOOT16 = (230, 312, 15, 2)`, `BALL_PAIR = 0.0`)

For each target `z in {h = e(P_0, Q_0), z_T = e(T, Q_0)}`, each boot renewal draws a **fresh uniform blinding exponent `e in [0, r-1]`**, forms `z' = z * gamma_0^e in G_T` using the calibrated Stage-1/2 factor-base blinding generator `gamma_0 := phi_iso^(-1)(a_0 - b_0 X)^{e_cof}` (`e_cof := (p^12 - 1)/r`, `gcd(r, e_cof) == 1` asserted live, known nonzero `V_0 = e_cof * V_g(a_0 - b_0 X) mod r != 0`), lifts `z'` via Guillevic `F_{p^6}`-subfield elimination (`W_1 != 0` proved unconditionally since `gcd(r, lcm(p^4 - 1, p^6 - 1)) == 1`, verified live on `4` real 381-bit `G_T` targets), reduces `L_boot(z')` (`LLL_BOOT = 2^47`), and samples **ONE** uniform half-cell `v ~ Unif(B_16(2)/{+-1})` (`BALL_PAIR = 0.0` exact since `N in {0, 1} => N(N - 1) == 0`).
- **100%-Fresh Production-HNF 16-Cal / 48-Holdout `BOOT_KEEP_FRAC = 0.90 < CP95 LB = 0.9395`:** Any draw with `log2 N_g > m_max = 24 * c_b + log2(U_8) + cal16_cutoff = 2589.79` (`cal16_cutoff = -225.22`) is deterministically discarded; `64` fresh 381-bit `G_T` targets (`1,092,608` exhaustive `R = 2` half-cells; `0/48` holdout target exceedances and `0/819,456` holdout cell exceedances, `CP95 LB = 0.05^(1/48) = 0.93949 > 0.90`) certify `BOOT_KEEP_FRAC = 0.90`.
- **Linear Union-Bound Missing-Leaf Retention:** Any boot or node relation containing a missing factor-base ideal is discarded directly using the **linear Boole union bound `max(0.0, 1.0 - miss)`** (no Poisson `exp(-miss)` step; at `LX = 68.5`, `boot_miss = 0.11281 -> boot_lin_keep = 0.88719`, `max_miss_node = 0.05288`).
- **Wald renewal (`p_descent_fail = 0`):** each renewal uses a fresh uniform `e` and fresh descent coins, so renewals are i.i.d. given the factor base; each completes with probability `>= 1 - Phi_tree`, `Phi_tree <= 0.3699347` (section 3: Boole over the expected `3,535.8` slot visits of a tree plus `(kA_b + 1) * P_BAD` for the boot's children). Renewals repeat until one tree completes, so by Wald's identity
  - `E[runs/log] <= 1 / (1 - Phi_tree) = 1.58714`, `one_log = E[runs/log] * (boot_own_1run + sub_w_1run)`;
  - every run is cut by the hard meter `T_run = 2^123` u, whose stop probability is bounded by Markov's inequality in `proof.md` section 6.

## 3. Node Procedure, Yield Certificate and the Slot Failure Bound

A slot is one visit of a special-`q` ideal `Q` in plan entry `(bin, side)` with radius `R`, windows `(n, iA, kA, kB)`. It runs:
1. **Draw and reduce.** Draw `p_rand` (fresh coins), form `L = L_{Q, p_rand}`, reduce it (`LLL_NODE = 2^40` Ir).
2. **Certify (`q15_cert16.py`).** Draw `S_CERT = 256` uniform primitive half-cells `c` of `B_16(R)/{+-1}` (fresh coins), compute the exact norms and
   `X_c = s_f(N_f(c)) * s_g(N_g(c)) / m_c`,
   where `s_f, s_g` are the entry's two-window semismooth lower sums (the same `ss_lower2` and windows that price the plan, `q` and `p_rand` removed from their sides) and `m_c` is the exact number of cells of the unit orbit `{eps c}` inside `B_16(R)/{+-1}` (Fincke-Pohst over `eps = sum e_k y^k` in the quadratic form `||sum e_k c Y^k||^2 <= R^2`, `Y` = multiplication by `y` in reduced coordinates; kept iff `det(eps) = +-1`). Summing `X_c` over the ball counts each orbit once, so
   `mu(L) = N_prim(R) * E_c[X_c] * det * lin_keep * ret`
   is the expected number of distinct usable relations of the trial (`det`, `lin_keep`, `ret` = the entry's ECM-success, missing-leaf and sieve-retention factors of section 4). The certificate is the layer-cake lower bound `E[X] >= sum_j (x_j - x_{j-1}) P(X >= x_j)` on the `J = 21` levels `x_j = x_plan * 2^{j/2}` (`j = -8..12`, `x_plan` = the plan's per-cell charge); on the slot's `i`-th draw each `P(X >= x_j)` is replaced by its one-sided Clopper-Pearson lower bound at level `delta_i / J`, `delta_i = DELTA_CERT / (i (i + 1))`, `DELTA_CERT = 1e-9`. The trial is certified iff this bound times `N_prim * det * lin_keep * ret` is `>= MU_CERT = 15`. For every lattice, `P(draw i is certified and mu(L) < 15) <= delta_i` over the node's own coins; by the union bound over all draws of the slot (`sum_i delta_i = DELTA_CERT`), the lattice the slot finally sieves has `mu(L) >= 15` except with probability `<= 1e-9`, whatever the pass rate (no division by a pass probability). The certificate applies the search's admission rules exactly (`q15_cert16.cell_weight`): a draw whose reduced basis fails `screen_special_q_basis` is uncertified, and a cell with zero norm, `v_Q(N_side) >= 2`, or a `BOUND_CELL` upper bound above the entry's cap `(nf_max, ng_max)` (with `q` and `p_rand` removed from their sides) gets weight `0`. It reads only norms and orbit sizes, never smoothness outcomes. An uncertified draw is discarded and step 1 repeats; after `D_MAX = 64` uncertified draws the slot **aborts** and reports to its parent (recovery below). An ideal is *good* if a draw certifies with probability `>= 1/2` over the node's coins (draws of one slot are i.i.d.); a good ideal aborts with probability `<= 2^-64`, and premise `H6` (section 5) bounds the chance that a reached ideal is not good by `P_BAD = 1e-3`. Ideals with structural short vectors, such as the `(135, g)` example `t = 5/8 mod q` whose composite lattices all fail the basis screen, are not good and abort after `64` draws (`2^46` Ir). Cost per draw: `LLL_NODE + CERT_DRAW`, `CERT_DRAW = 2^34` Ir (`256` exact norms, `BOUND_CELL` evaluations, orbit enumerations and the bound), charged as `(LLL_NODE + CERT_DRAW) / CERT_PASS_LO`, `CERT_PASS_LO = 1/2`.
3. **Sieve the certified ball once** (`dsieve16`, eager cofactorisation of all survivors, or direct ECM on the five `R = 12` `f` entries), take the **first** usable relation and descend each of its `<= 2 (kA + kB)` children once. If the certified ball yields no usable relation, the slot fails and the renewal is abandoned (section 2). **Recovery:** if one of the chosen relation's children aborts, the attempt is abandoned and the slot starts a new attempt at step 1 with a fresh `p_rand`, at most `K_ATT = 6` attempts; children of a new attempt come from a fresh lattice.

**Slot bound.** Let `n_ch = 2 (kA + kB)` be the entry's number of children and `h = n_ch * (P_BAD + 2^-64)` the chance that an attempt is abandoned for an aborting child (`H6`). Under `H5` a certified attempt's ball is empty with probability `<= P_EMPTY = 1e-4`; with the certificate error, every attempt that occurs fails for its own ball with probability `<= P_NODE = P_EMPTY + 1e-9 = 1.00001e-4`. Attempt `j` occurs only if the previous `j - 1` were abandoned, so a reached slot, whatever its history and however `Q` was produced, fails with probability at most
    `sum_j h^(j-1) P_NODE + h^K_ATT <= P_NODE / (1 - h) + h^K_ATT`,
and it visits each child type at most `1/(1 - h)` times in expectation.
**Tree bound (Boole).** `Phi_tree <= E[sum over visited slots of P(slot fails)]`, with no independence across slots. The recurrence prices one certified trial per attempt:
  - `W[b, side] = (own_1 + kA * (wmax('f', nA) + wmax('g', nA)) + kB * (wmax('f', n) + wmax('g', n))) / (1 - h)`
  - `PHI[b, side] = P_NODE / (1 - h) + h^K_ATT + (kA * (phimax('f', nA) + phimax('g', nA)) + kB * (phimax('f', n) + phimax('g', n))) / (1 - h)`
  - `NSL[b, side] = 1 + (kA * (nsmax('f', nA) + nsmax('g', nA)) + kB * (nsmax('f', n) + nsmax('g', n))) / (1 - h)`
- **Branch-Tree-Capped `L_min = 2` Geometric-Ladder ECM (`q15_ecm16.py`):** Every cofactorization call uses `tree_branch_caps(nbits, b_min=32, l_min=2)` (exact DP upper bound on `sum L_i^2` and `sum gcd_instr(b_i)` over all active composite-branch partitions with `b_i >= 32` using the `47`-op `mont2_cios` kernel for `L = 2`), a `12`-bit geometric ECM ladder (`ladder_v9_instr` from `16`b up to `fbits`), separation penalty `SEPARATION = 0.5`, explicit failed-replay retry pricing `p_r = 0.0043` paying BOTH `per_curve` and full `replay_1curve`, and `NEWTON_PRECHECK_INSTR = 2^26` Ir.
- **Eager Cofactorization & Uncapped `dsieve16`:** `71` nodes use uncapped `dsieve16` (`SIEVE_HIT = 2,600` Ir, `PAIR_SETUP = 2^35.2`, `LLL_NODE = 2^40.0`, `BOUND_CELL = 5,000` Ir) and `5` high-`f` `R = 12` nodes `[180, 205)` use direct ECM (`ret = counted_fraction = 0.906510`, explicitly charging `BOUND_CELL` on every cell). Every sieve node cofactors all survivors (`cofac_frac = 1.0`, `eager = True`).

## 5. Premise `H5` and Evidence

- **`H5` (empty certified trial).** For a slot with ideal `Q`, the trial lattice `L = L_{Q, p_rand}` is drawn by the algorithm's uniform `p_rand`; once it is certified (`mu(L) >= 15` in the model of section 3), the probability over that draw that its ball holds no usable relation is at most `P_EMPTY = 1e-4`. Model basis: in the random-integer model that `H1` uses for collection, the usable-relation events of the distinct orbits of the ball are independent with their per-cell probabilities at the cells' norm sizes, which gives `P(empty) <= exp(-mu(L)) <= e^{-15} = 3.1e-7`; `P_EMPTY` charges `300x` that value. The premise concerns one certified lattice; nothing is assumed about earlier failures or dependence across slots (Boole and i.i.d. fresh-`e` renewals handle those); how ideals are reached enters only through `H6`. `H5` is therefore the one place where the descent uses a tail of the smoothness model rather than its mean.
- **Toy test of the lattice-conditional law (`q15_toy_cond.b85`, re-checked by the audit).** On `Q(zeta_15)` `16`D `Q_CM`-LLL `q * p_rand` lattices with exact relation detection, each lattice's expected count `mu_L` was computed from its own cells' norms (calibrated relation rate per `2`-bit `(log2 N_f, log2 N_g)` bin, leave-one-ideal-out; for reached children also per `1`-bit `log2 q`, their own large-prime bound, as the production certificate does through each entry's windows). Literal production polynomials `f_9, g_3` (`64` ideals x `24` `p_rand` = `1,536` lattices): dispersion `D = sum (M - mu)^2 / sum mu = 0.90`, empty lattices `9` vs `6.5` predicted by `exp(-mu_L)`, all with `mu_L <= 7.5`. Degree-`(32, 24)` strict-descent parents (`1,536`): `D = 1.02`, `0` empty vs `0.01`. Reached children (`1,536`): `13` empty vs `18.5` predicted, all with `mu_L <= 6.3` (`D = 1.33`). Across the three cohorts, **none of the `2,646` lattices with `mu_L >= 10` is empty** (`1,163` with `mu_L >= 15`). Without per-lattice expectations the same counts are strongly overdispersed (raw Fano `2.9`-`10.4`), which is why the production algorithm certifies each lattice.
- **`H6` (reached ideals are good except with probability `P_BAD = 1e-3`).** Every degree-1 prime ideal `Q` of norm `q` has index `q`, so it contains a `1/q` fraction of any parent ball's cells; under `H1` the cofactor smoothness of a cell does not depend on which ideal of norm `q` divides it. A reached child is therefore distributed like a uniform degree-1 ideal of its side and norm, and the chance that it is not good is at most the fraction of such ideals that are not good; children of different attempts come from different relations and are fresh draws in the same sense. **Bad-ideal campaign** (`q15_cert_prod.b85`, `bad_campaign`, seed `2027`): `80` fresh production ideals at the bin top edge (the hardest norms of the bin) for each of the `76` entries, one first draw each, plus the `456` ideals below: `6,536` first draws, all pass the basis screen and certify (minimum certified value `82`). A non-good ideal fails its first draw with probability `>= 1/2`, so the fraction of non-good ideals is `<= 2 (1 - 0.05^(1/6536)) = 9.2e-4 <= P_BAD` at `95%` confidence. The audit recomputes the counts and one record from its seed.
- **Production certificate campaign (`q15_cert_prod.b85`; `q15_cert16.certify_entry`, seed `2026`).** For each of the `76` plan entries: `6` production special-`q` ideals at the bin top edge x `2` independent first draws of `p_rand` = `912` lattices of the shipped plan (`R` and windows as in `PLAN16`), `256` cells each, admission rules applied, first-draw budget `delta_1 = 5e-10`. All `912` pass the basis screen and certify; no sampled cell is rejected by the admission rules; the smallest certified value is `108.55` (`7.2x` `MU_CERT`), certified/planned `mu >= 3.29` (median `10.56`), estimated `mu(L)`/planned `mu >= 6.74`. The audit re-checks every record and recomputes entries `(195, f)` (`R = 12`) and `(200, g)` (`R = 32`) from their seeds.
- **Shipped plan (`384` mesh).** `76` nodes (`71` sieve + `5` direct-ECM), planned `min_mu = 15.38`, expected slot visits `3,535.8`, `Phi_tree = 0.3699347`, `E[runs/log] = 1.58714`, `boot_u = 106.6741`, `sub_u = 105.9737`, **`two_log_units = 107.365976`** core `F_{p^12}` units (`C = 20,000`; charged `107.3820` in `cm_data.json`, `+0.0160`b slack; `x10` for `C = 2,000` G1 units).
