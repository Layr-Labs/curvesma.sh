## 1. Reduction (two GT logarithms) and field map


1. Check T (on curve, [r]T = infinity); T = infinity returns x = 0.
2. g = e(P0, Q0), z = e(T, Q0) (pinned pairings, protected encoding).
3. Map g and z into the core's tower (field-map.md).
4. Run the core on (g, z) under its meter and node counter (any failure fails): x = log_g(z) mod r.
5. Verify: return x if [x]P0 = T, otherwise fail.
GT has prime order r; e(., Q0): G1 -> GT is an isomorphism, z = g^x, z = 1 iff T = infinity. Each core target t becomes t^e, e fresh uniform in [1, r) (DESCENT.md), uniform on GT minus {1} for any fixed g, z: the fixed base costs no success; the check rejects wrong outputs.
One relation/LA phase serves log z and log g (section 6; 2/r charged). Wrapper < 2^80 instructions (both pairings, scalar multiplication, check < 2^50, field map < 2^67): 2^65.72 core units, a 2^66 row. Wrapper failure: field map below 2^-48.
