# bls12-381-g1-ecdlp-plain: linear-unit six-class checkpoint rho

Recover \(x\) from \(T=[x]P_0\) in BLS12-381 G1. The search runs on the quotient by the order-6 group generated by negation and the GLV endomorphism. The iteration is an adding walk with a table of \(2^{20}\) jumps. Stored states are distinguished checkpoints only. A repeated checkpoint with dependent coefficients abandons the trail. A repeated checkpoint with independent coefficients solves for \(x\).

The new arithmetic is on the coefficient pair. If the walk state is the canonical point together with \((a,b)\) satisfying
\[
X = [a]P_0 + [b]T,
\]
then replacing \(X\) by \(\varphi^k(\pm X)\) multiplies the unknown scalar by a unit \(\pm\lambda^k\). That multiplication does not use a CIOS product by the 128-bit integer \(\lambda\). It is one of the six maps
\begin{align*}
(a,b) &\mapsto (a,b),\\
(a,b) &\mapsto (-a,-b),\\
(a,b) &\mapsto (-b, a-b),\\
(a,b) &\mapsto (b, b-a),\\
(a,b) &\mapsto (b-a, -a),\\
(a,b) &\mapsto (a-b, a),
\end{align*}
reduced modulo \(r\) by a conditional subtraction. The second identity used each step is \(\beta^2 x = -x-\beta x\) in \(\mathbb{F}_p\), so the three conjugate \(x\)-coordinates cost one base-field multiplication and one six-limb subtraction.

The submitted score is an upper bound on the work of one truncated run. Success probability, under the three heuristics at the end, is at least \(39/100\).

## Parameters

The profile fixes the subgroup order
\[
r = 52435875175126190479447740508185965837690552500527637822603658699938581184513
\]
and the generator \(P_0\). The short GLV eigenvalue
\[
\lambda = 228988810152649578064853576960394133503
\]
satisfies the integer identity \(\lambda^2+\lambda+1 = r\). In particular \(\lambda^2+\lambda+1\equiv 0\pmod r\), so \(\lambda\) is a primitive cube root of unity modulo \(r\) and \(-\lambda\) has order 6. The six units are
\[
\{\pm 1,\pm\lambda,\pm\lambda^2\} = \{\pm 1,\pm\lambda,\pm(1+\lambda)\}
\]
as residues, because \(\lambda^2\equiv -1-\lambda\).

Let \(N=(r-1)/6\). Every non-identity class of the action
\[
Q\mapsto -Q,\qquad Q\mapsto \varphi(Q)=(\beta Q_x, Q_y)
\]
has size 6: the only solutions of \(\lambda k\equiv k\pmod r\) or \(-k\equiv k\pmod r\) are \(k\equiv 0\), and \(r\) is prime. The reference price is \(C=2000\) scalar AArch64 instructions per batched incomplete affine G1 addition. `blst_fp_mul` on the pinned measurement is 383 instructions. Squarings are charged as multiplications. Public constants \(\beta\), \(\lambda\) and \(P_0\) are not advice.

## Linear unit action

Write a scalar as \(a+b\lambda\). Multiplication by \(\lambda\) is
\begin{align*}
\lambda(a+b\lambda)
&= a\lambda + b\lambda^2
= a\lambda + b(r-\lambda-1)
\equiv -b + (a-b)\lambda \pmod r.
\end{align*}
Multiplication by \(-1\) sends \((a,b)\) to \((-a,-b)\). Multiplication by \(\lambda^2=-1-\lambda\) is the composition of those two maps:
\[
\lambda^2(a+b\lambda)\equiv (b-a)+(-a)\lambda\pmod r.
\]
The remaining two units are the negatives of these. Each map is a sum of \(a\), \(b\) and their negations. A 4-limb conditional subtraction of \(r\) brings the coordinates back into \(\{0,\ldots,r-1\}\). No limb of \(\lambda\) is loaded.

`reference.unit_images_match_multiplication` checks the six identities on an explicit grid, including the edge points \((\lambda-1,4)\) and \((17,\lambda-2)\). The experiment calls that check. The identities are polynomial, so the grid is only a regression fence; the expansion above is the proof.

## One multiplication for the canonical \(x\)

Let \(\beta\in\mathbb{F}_p\) be the profile cube root with \(\beta^2+\beta+1=0\) and \(\varphi(x,y)=(\beta x, y)\). Then
\[
\beta^2 x = (-1-\beta)x = -x-\beta x.
\]
The orbit of \(x\)-coordinates of \(\{Q,-Q,\varphi(Q),-\varphi(Q),\varphi^2(Q),-\varphi^2(Q)\}\) is \(\{x,\beta x,\beta^2 x\}\), since negation preserves \(x\) and \(\varphi\) multiplies it by \(\beta\). Computing that set from \((x,y)\) costs one multiplication by the public constant \(\beta\) and one field subtraction. The canonical label is the minimum of the three integers in \(\{0,\ldots,p-1\}\), together with the sign bit that keeps \(y\) or \(-y\), whichever is smaller as an integer. The sign bit is a six-limb comparison of \(y\) with \(p-y\). It composes the unit already chosen with \(-1\), which is the second map above.

The same \(y\) is the \(y\)-coordinate of \(\varphi(Q)\) and of \(\varphi^2(Q)\). The canonical point is assembled by selecting one of the three \(x\)-coordinates and optionally negating \(y\). No second curve addition is required to enter the canonical representative.

## Iteration

Precompute \(R=2^{20}\) jumps. Jump \(j\) is the affine point \(u_j P_0+v_j T\), with \((u_j,v_j)\) a fixed 4-limb counter, not a searched table. Each jump is built by Shamir joint double-and-add in Jacobian coordinates and one Fermat inversion to affine. The 64 starting points are built the same way.

The global step meter runs to
\[
S = s+4+8\cdot 2^{97},
\]
where \(s=\lceil\sqrt{\pi_\star N/2}\rceil\) and \(\pi_\star\) is the Machin upper bound implemented in `reference.pi_upper`. One integer \(S\) is shared by every trail. Work is the sum across trails, not the elapsed time of a lockstep batch.

A step on a state \((X,a,b)\):

1. Replace \(X\) by its canonical image and apply the matching unit map to \((a,b)\).
2. If bits \([20,117)\) of the canonical \(x\) are zero, the point is a checkpoint. Look it up in the open-address table of \(2^{30}\) slots.
3. If the slot is empty, store \((a,b)\). If the slot holds \((a',b')\) with \(b\not\equiv b'\pmod r\), solve
   \[
   x\equiv (a'-a)(b-b')^{-1}\pmod r
   \]
   and verify \([x]P_0=T\). If \(b\equiv b'\), abandon this trail and keep every checkpoint already stored.
4. Otherwise add the jump indexed by the low 20 bits of the canonical \(x\), and add \((u_j,v_j)\) into \((a,b)\).

The identity \(x=0\) is the point at infinity. It is recognised before the canonicalisation step, as in the toy walk, and returned directly. A trail that exhausts \(S\) without an independent collision is a failure of that run. There is no second budget.

## Why an independent collision is the discrete log

Throughout the walk the invariant is \(X=[a]P_0+[b]T\). A jump \(uP_0+vT\) preserves it. A unit map replaces \(X\) by \([u]X\) and \((a,b)\) by the image pair, so the invariant is multiplied by the same unit on both sides and still holds.

Two visits to the same canonical class with pairs \((a,b)\) and \((a',b')\) give
\[
[a]P_0+[b]T = [a']P_0+[b']T,
\]
hence \([a-a']P_0 = [b'-b]T\). If \(b\not\equiv b'\) then \(T=[x]P_0\) for \(x\equiv (a-a')(b'-b)^{-1}\). The verification scalar multiplication either accepts that \(x\) or rejects the state. A dependent pair \(b\equiv b'\) produces the zero relation and is discarded; previously stored checkpoints stay in the table and the meter keeps running on a fresh start.

## Cost

One reference addition per step accounts for the batched incomplete affine addition of the jump. Canonicalisation is not part of that addition, so its field work is charged as instructions. The step instruction ledger is:

| Item | Instructions |
| --- | ---: |
| `blst_fp_mul` by public \(\beta\) | 383 |
| six-limb sum \(x+\beta x\) and subtract from \(p\) | 64 |
| two six-limb comparisons to take the minimum | 64 |
| six-limb sign comparison of \(y\) with \(p-y\) | 24 |
| unit map: negations, one subtraction, reduce mod \(r\) | 64 |
| add \((u_j,v_j)\) and reduce both limbs mod \(r\) | 64 |
| low-20 index, 97-bit window test, pointer | 24 |
| **step total** | **687** |

Per step the charge is \(1+687/2000=2687/2000\) target-group operations. Across the global meter the additions total \(S\).

Jump construction, per jump, is a worst-case Shamir evaluation on a 255-bit pair in Jacobian coordinates with \(a=0\): \(254\) doublings at \(2M+5S\), \(254\) mixed additions at \(7M+4S\), one extra mixed addition, a Fermat inversion (\(381\) squarings and \(381\) multiplications) and \(6M\) to reach affine. At 383 instructions per multiplication that is the integer `JUMP_INS` in `reference.py`. The \(2^{20}\) jumps and the 64 starting points use that cap. Verification of the returned scalar is one 255-bit Jacobian scalar multiplication and an affine fix, `VERIFY_INS`. Lookup is 200 instructions for every one of the \(2^{30}\) allocated slots, occupied or not.

`reference.instruction_numerator` sums these charges. The reduced fraction is
\[
W = \frac{314822849119678901812247063973225341738839}{2000}.
\]
The six-decimal ceiling of the rational upper bound on \(\log_2 W\) produced by `log2_fraction_ceiling_micro` is \(126.887808\). Because that routine ceilings an upper bound, \(\log_2 W\le 126.887808\). The declared score is that ceiling. No term is an expectation, an amortisation over future targets, or a free oracle. Preprocessing, included in \(W\), is the jump table and the 64 starting points,
\[
\frac{26863967764}{25},
\]
whose six-decimal log ceiling is \(30.001098\). Nonuniform advice is 0 bytes: the jumps are computed from a public counter during the attack. \(\beta\), \(\lambda\) and \(P_0\) are profile constants.

The integer \(s\) is the smallest integer with \(s^2\ge \pi_\star N/2\). `bound_holds` proves, as an inequality about the i.i.d. envelope only, that the expectation of that envelope is at most \(s+4\). The detection slack \(8\cdot 2^{97}\) is eight mean geometric gaps at rate \(\theta=2^{-97}\). A geometric random variable exceeds eight means with probability \(<e^{-8}\). Those two statements are unconditional. Carrying them onto the adding walk is heuristic H1 below.

## Heuristics

H1. The adding walk on canonical classes has its first useful repeat inside the budget \(S\) with probability at least \(39/100\). For i.i.d. uniform samples on a set of size \(N\), the collision time \(T\) satisfies \(P(T>k)\le\exp(-k(k-1)/(2N))\), and `bound_holds` puts the expectation of that envelope at most \(s+4\). The Rayleigh mass of the same leading term at the mean is \(1-e^{-\pi/4}\approx 0.544\). The required success probability is \(0.39\), and the gap between those two numbers is the room claimed for the \(O(1)\) slack, the detection delay and the difference between an adding walk and the i.i.d. envelope. Teske's adding walks with at least twenty jumps already track the \(\sqrt{\pi N/2}\) constant; this table has \(2^{20}\) jumps. Flajolet–Odlyzko give the same leading term for a random mapping. Identifying the canonical adding walk with that envelope is a heuristic. It is not the inequality proved in `bound_holds`.

H2. The low 20 bits of the canonical \(x\), and bits \([20,117)\), behave as independent fair bits for a uniform point of a class. The canonical \(x\) is a smooth image of a uniform curve point, \(p\) is odd, and a fixed 117-bit window of a uniform field element is equidistributed up to an error far below \(2^{-200}\). This is what makes the jump index a function of the class and what makes the checkpoint rate \(\theta=2^{-97}\). The walk canonicalises before indexing, so two representatives of one class select the same jump.

H3. A checkpoint collision with \(b\equiv b'\) does not consume the gap between \(0.54\) and \(0.39\). On one functional graph the coefficient relation around a cycle vanishes with probability about \(1/r\). An escape keeps the checkpoints already stored and continues to spend the same global meter. The \(1/r\) losses sit well below \(0.01\).

The budget is not a high-probability bound with a proved random-mapping tail. It is the birthday integer \(s+4\), plus a deterministic detection slack, under H1–H3. No claim is made that the constant is optimal, that memory is practical, or that a production run was executed.

## Experiment

`experiment.py` does three things, none of which is a production cost measurement.

- On the profile generator, \(\varphi(P_0)=[\lambda]P_0\), \(\beta^2+\beta+1=0\), and \(\beta^2 x(P_0)=-x(P_0)-\beta x(P_0)\). The homomorphism property of \(\varphi\) then gives \(\varphi(Q)=[\lambda]Q\) for every \(Q\in G_1\), which is the only extension used above.
- The six linear maps agree with multiplication by the six units on the grid in `unit_images_match_multiplication`.
- On a prime-order toy group of bit length 12, with the same order-6 multiplication action, a checkpoint collision returns the planted scalar inside the scaled budget. The toy coefficient update multiplies by the toy unit in \(\mathbb{Z}/n\mathbb{Z}\). That is the same group action; the production implementation of the action is the linear map, which the integer check covers. The toy prime is not BLS12-381 and its step count is not \(W\).
