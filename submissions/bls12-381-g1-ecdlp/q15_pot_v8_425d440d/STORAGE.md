# Storage and Addressing

Every owner node is a flat 64-bit scalar ARMv8.1-A machine with `< 2^64` bytes (`16.00 EiB`) of RAM, addressed by unit-cost `ldr/str/ldp/stp/ldrh/strh/staddh` under the benchmark's scalar instruction-equivalent cost model (`docs/COST_MODEL.md`); every cross-owner byte passes through an explicit 1-hop `128 KiB` ping-pong shared link page (`x_tx_tbl[0..13]` in Band 2: sender `str` writes pointers directly into the active link page, `rev_b2_flush_sb`/`_last` flips page ownership in `<= 25` sync/ack ops with zero extra bulk copy, and the target slab owner reads directly from that link page via `ldp` in `rev_b1a_apply_f_u32`; and explicit `u32->u4->bin21` burst streaming in Band 1 & LA), fully priced in `KERNELS.md`.
