# Storage and Addressing

Every object is partitioned into abstract 64-bit owner address spaces (`< 2^64` bytes = `16.00 EiB` per owner) with every cross-owner byte transfer explicitly priced in `KERNELS.md`. *(Hardware modeling caveat: physical ARMv8.0-A MMUs cap VA/PA at 48 bits [52-bit from ARMv8.2-A]; direct `ldrh`/`strh` addressing over `8.50–10.32 EiB` owners operates under the abstract 64-bit flat-RAM instruction-count model of this benchmark.)*

## 1. Relation Collection (`Arch2-Prod-ZeroSlice-Buf128K-B2-U32-Bin21-Defer8`, Pure Product `qa <= s_c R2_a` & `qb <= R2_b`, `W_tile = 448 = 7 * 64`, `W_SB = 16`, `P_min = 2^32`, `P_m4s = 2^50.5`, `P_m4 = 2^52.5`, `P_1bs = 2^56.5`, `P_lo = P_f = 2^58.0`, `P_g = 2^63.5`)

- **Canonical `a` packing & exact `2^56` power-of-2 bank stride (`K_a = 1`, `W_SB = 16`, `rec = 64b` with 2 zero guard bits `58..59`):** Continuous 8D ellipsoid volume (`A^2 = 320,500, r_ab = 0.83`) gives `V_a = 2^55.8564 < 0.91 * 2^56` canonical `a`-orbits; `N_a^tbl = 4 V_a = 2^57.8564`. Canonical `a`-entries are partitioned into `3` contiguous static 2-adic classes `c(a) in {0, 1, 2}` with ONE constant `g`-side threshold `T_g[c] = (299, 287, 275)` bits (ZERO `Q_CM(a)` radial shells, ZERO `bgo` norm predictor).
- **Column-slab owner RAM (`28` independent slab owners, `2^63.087 B < 2^64 B` each):** Each of `28` slab owners owns `16` consecutive columns and allocates `uint16_t S_g[16][4][2^56]` (`8.00 EiB`) + single-column `uint16_t S_f[4][1][2^56]` (`0.50 EiB`) + `128 KiB` deferred-flush Band-2 receive buffer (`[0, 64 KiB)` primary + `[64 KiB, 128 KiB)` overrun) = **`2^63.087 B = 8.50 EiB < 16.00 EiB`** (plus two `128 KiB`-aligned discard sinks `sink_lo = x_tx_tbl[-1]` and `sink_hi = x_tx_tbl[28]`, `3.84 MiB` total across all 30 buffers).
- **Sequential `w_lp`-Ordered Deferred-Flush `128 KiB`-Buffered `8 B` Band-2 (`1` Prime Orbit per Build/Replay Owner -> `28` Slab Owners):** Each Band-2 `g`-side prime orbit owns its own dedicated build/replay owner (`<= 14.950 EiB` peak build `2^63.901 B`, `<= 7.475 EiB` max resident `2^62.901 B` + `416 B` row-step state, ZERO cross-owner build transfers). Each row runs `rev_b2_row_k0_step4` (`33/4 = 8.25` Ir/prime/row + `<= 0.339` outer-chord reset `<= 8.60` Ir/prime/row) into `rev_sb_probe_fast` + `rev_b2_sb_wrap` (`25 + 5 = 30.0`, deterministic `<= 64 KiB` tile-bytes guard + `<= 32 KiB` chunked slow path) + `tbnz`-guarded `rev_b2_direct_sb_hdr` (`9 + <= 1 = 10.0`) + flush-free **`8`-op `bfi` `rev_b2_emit_c0/c1`** writing `8 B` `x4` records + `rev_b1a_apply_u32 -> u4 -> bin21` (`3.5625` Ir/hit + `<= 0.01` tail/chunk = **`11.58` Ir/hit**) + `23 * 28 = 644` `w_lp`-class partial drains/row.
- **1-Prime-Per-Owner Local Flat-Array Build (`<= 2^63.901 B < 2^64 B` peak build):** Band-1a `<= 14.950 EiB`, Band-1b `<= 7.667 EiB`, Band-2 `<= 14.950 EiB` peak / `<= 7.475 EiB` resident; explicit pure-scalar 2-pass counting sort (`rev_b2_build_hist_u4` `8.0` + `rev_build_prefix_u4` `3.0 <= 4.0` + `rev_b2_build_scatter_u4` `7.0` -> `c_list_a = 16.0`, `c_lbkt = 4.0`, `build_u = 104.2560 <= 104.2563` u); total replay `a`-table storage **`2^118.320 B < 2^120 B`**.
- **Distributed `2,048`-Owner Product Trees (`P_f = 2^70.79` + `P_g = 2^71.19` + Retained `g`-Batch Candidate Tree):** Partitioned across `2,048` 64-bit owners at **`0.1932 * 2^64 B = 3.091 EiB << 16.00 EiB`** per owner, with ALL THREE `L - 11` local subtrees `<= 1.053 EiB < 2^62 B` asserted live in `audit_cm.py`.

## 2. Linear Algebra Storage — Complete Owner Map Across ALL Phases (All `< 2^64 B = 16.00 EiB`, Conservative `nl_cap = 0.00278`, `sw_cap = 0.00568`, `nonunit_ub = 0.11`, `W_max = 4,096` Guard)

Each Block Wiedemann bundle runs `4` 256-bit vectors (`128 B/slot`) over `N_sw = sw_cap * U' = 0.00568 * 2^62.8277 = 2^55.3678` structured-Gaussian slots and `N = nl_cap * U' = 0.00278 * 2^62.8277 = 2^54.3370` logical columns (`nonunit_ub = 0.11`, mean row size `<= 64 + 201 * 8.11 + 7 = 1,701.11 B`):

- **Krylov sequence owners (`2,048` owners):** `L_bm = 2^47.3539`, `2^63.354 B = 10.224 EiB < 16.00 EiB` per owner (asserted live).
- **PM-Basis generator owners (`2^22` owners + `1` owner for final `F(z)`):** Coeff arrays + 3-plane x 4-prime NTT workspace = **`2^63.108 B = 8.623 EiB < 16.00 EiB`** per owner; final `F(z)` = `2^59.354 B = 0.639 EiB` (asserted live).
- **Mutable filtering owner map (variable-size byte pools prior to finalizing the `16` read-only matrix shards):**
  - **Purge (`2,048` hash-partitioned owners, `<= 6.010 EiB <= 8.0 EiB < 16.00 EiB` each):** Bounded at `<= 40` raw incidences * `16 B` + `128 B` SM + `64 B` header times `1.25x` load factor `= 1,040 B/rel` across deterministically capped `N_rels <= n_rels_upper = 2^63.565` -> **`2^62.587 B = 6.010 EiB`** per owner (asserted live).
  - **Merge (`8,192 = 2^13` hash-partitioned variable-size byte-pool owners, `<= 5.595 EiB <= 8.0 EiB < 16.00 EiB` each):** Sized conservatively against pre-merge peak `nrows_tot <= n_rels_upper`, with aggregate mean payload across live rows + popped `merge_stack` pivots `<= 1,701.11 B` (`64 + 201 * 8.11 + 7`, `nonunit_ub = 0.11`) + `128 B` SM + `32 B` descriptor + `201 * 10 B` incidences = `3,871.11 B/obj` -> **`2^62.484 B = 5.595 EiB`** per owner (asserted live).

- **Explicit aggregate priced cross-owner burst streaming (`u32 -> u4 -> bin21`):** `w_row_avg = 8 + 201 + 201 * 0.11 / 8 + 7/8 = 212.639` words -> `1.0625 * w_row_avg + 24.0 = 249.929 <= 250.0 = c_stream_mat_1vec` Ir/row (1-vec Horner) and `62.482 <= 63.0 = c_stream_mat` Ir/vec-row (4-vec Krylov), asserted live in `audit_cm.py`.
