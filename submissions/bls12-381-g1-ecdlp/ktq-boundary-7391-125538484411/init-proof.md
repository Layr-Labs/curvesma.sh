## 50. Declared256-byte DC ZVA owner initialization


**Machine and review scope.** This revision declares DCZID_EL0.BS=6 (64 words,256bytes) and DZP=0, with MRS DCZID_EL0, DC ZVA and DSB permitted without trapping at the execution exception level. It continues the same flat unsigned64-bit node-address abstraction and C=2000. The only new implementation parameter is the zero-block size. No vector register, SVE operation, width-dependent arithmetic price, throughput, cycle count or change to reference normalization is used. MRS, AND, CMP, conditional branch, MOVZ, ADD, SUBS, DSB and RET are scalar AArch64 instructions. DC ZVA is a system instruction with one64-bit general-purpose address operand; this claim prices each architecturally executed DC ZVA as one scalar instruction, as distinct from pricing it once per64byte sector. The protected model fixes64-bit general-purpose registers and counts scalar instructions, but does not explicitly fix DCZID or normalize variable-size zeroing. Whether this permitted scalar-system-instruction interpretation applies is a material review question; a reviewer requiring64byte-equivalent normalization must not accept the improved bound on this argument. No prior submission acceptance resolves that question.
