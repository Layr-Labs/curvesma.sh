# bls12-381-g1-ecdlp: Cheon's p−1 attack in H/μ6 with fixed-base tables

Claim: for every n with 2^20 ≤ n < r, W(n) ≤ 2^117.724244 target-group-operation
equivalents (C = 2,000), success probability ≥ 0.39 over uniform s. W(n) is
constant in n because only A_1 and A_{2^20} are read. Scored value:
log2 W(2^20) ≤ **117724244/1000000**.

Every number below is recomputed by `production.py` from the protected
constants. `experiment.py` runs this same algorithm end to end on toy j=0 curves.

## 1. Facts about the target (verified in `production.py`)

Let p, r be the protected field and subgroup orders, d = 2^20, ζ = 7 a generator
of F_r^*, ξ = ζ^d, H = ⟨ξ⟩ = (F_r^*)^d of order N = (r−1)/d.

- r − 1 = 2^32 · 3 · 11 · 19 · 10177 · 125527 · 859267 · 906349^2 · 2508409 ·
  2529403 · 52437899 · 254760293^2 (each factor checked prime, product checked).
- 6d | r − 1, so 6 | N. Write N' = N/6; log2 N' = 232.27213.
- μ6 = {±1, ±λ, ±λ^2} is the unique order-6 subgroup of F_r^*, and μ6 ⊂ H
  (checked: (−1)^N = λ^N = 1). It is ⟨ξ^{N'}⟩.
- On G1, [−1](x,y) = (x,−y) and [λ](x,y) = φ(x,y) = (βx, y) with β a primitive
  cube root of unity in F_p; checked on the real P0, including [λ^2]P0 = (β^2 x, y).
  Hence for any point Q ≠ O the six points [μ]Q, μ ∈ μ6, have x-coordinates exactly
  {x, βx, β^2x} = {x, βx, −x−βx}, and two points of G1 \ {O} have the same set
  iff they differ by an element of μ6. Define key(Q) = min{x, βx, −x−βx}.

Consequently key([h]P0) for h ∈ H depends only on the class of h in the cyclic
group H/μ6 of order N', which is generated by the image of ξ.

## 2. Algorithm

Input: A_1 = T = [s]P0 and A_d = [s^d]P0 (array entries A[0] and A[2^20−1]).

Parameters: m = g = ⌈√⌈0.39 N'⌉⌉ = 57012617742321962895928165416718183 (≈ 2^115.457),
so m·g ≥ 0.39 N' and m·g ≤ N'.

1. **Fixed-base tables.** Scalars are held in Montgomery form c̃ = cR mod r
   (R = 2^256, c̃ < r < 2^255), split into three 85-bit windows
   c̃ = w0 + 2^85 w1 + 2^170 w2. For Base ∈ {P0, A_d} and k = 0,1,2 build
   T_k^Base[v] = [v · 2^{85k} · R^{-1} mod r] Base for v < 2^85 by repeated batched
   addition. Then T_0[w0] + T_1[w1] + T_2[w2] = [c̃R^{-1}]Base = [c]Base:
   **two point additions per fixed-base scalar multiplication.**
2. **Baby phase** (j = 0..m−1): c ← ξ^j (one Montgomery multiplication per step,
   by ξR). Compute B_j = [ξ^j]P0 with the P0 tables, insert key(B_j) ↦ j into an
   open-addressing hash table with 2^117 slots (load 0.343, linear probing, full
   384-bit key stored; the table is cleared first, and that is charged). The m classes ξ^j are distinct in H/μ6 because m ≤ N'.
3. **Giant phase** (i = 0..g−1): c ← ξ^{−mi}; G_i = [ξ^{−mi}]A_d = [s^d ξ^{−mi}]P0 with
   the A_d tables; look up key(G_i). On the first hit j, set k = j + m·i and leave the loop.
4. **Resolution.** s = ζ^e with e uniform on [0, r−1), and s^d = ξ^{e mod N}, so the
   class of s^d in H/μ6 is e mod N'. A hit gives e ≡ k (mod N'). Test the
   6d = 6·2^20 candidates e = k + N'u (u < 6d): compute c = ζ^k·ω^u (ω = ζ^{N'}),
   form [c]P0 with the P0 tables and compare it with A_1. Output the c that matches.
   If the giant loop ends without a hit, output failure.

Exceptional additions (a zero window, or operands with equal x) are detected and
sent to a complete-formula slow path.

## 3. Correctness and success probability

Let K = e mod N', which is uniform on [0, N') since N' | r−1 and e is uniform on
Z/(r−1). If K < m·g, write K = mi + j with j < m, i < g. Then
s^d ξ^{−mi} ∈ ξ^j μ6, so key(G_i) = key(B_j) and a hit occurs at giant step i.
Conversely, a hit (i', j') means s^d ξ^{−mi'} ∈ ξ^{j'} μ6, i.e. K = j' + mi'. The
values j + mi are distinct on [0, mg), so the hit is unique and correct. No false
matches can occur, because keys are exact class invariants. In resolution exactly
one candidate e satisfies [ζ^e]P0 = A_1 (P0 has prime order r, and the e < r−1 give
distinct ζ^e). So the algorithm succeeds iff K < m·g, with probability exactly
m·g/N' ≥ 0.39 over the uniform challenge. It uses no algorithm coins and no amplification.

`experiment.py` checks this law trial by trial. It computes K by Pohlig–Hellman
(ground truth only, not part of the attack) and confirms that the run succeeds iff
K < mg. Toy runs (bits/d/trials = 26/16/400, 30/64/300, 36/256/60): 760/760 trials
agree with the rule, 0 wrong outputs, 0 false matches, exactly 2.0 additions per
baby element, and empirical rates 0.405, 0.43, 0.33 against a predicted 0.391.

## 4. Cost ledger (C = 2,000 instructions per unit)

One unit is a batched incomplete affine G1 addition under the 6M convention.
Additions are batched over 2^16 independent elements per level (two levels per
element), which is exactly that reference operation. All other work is charged
in AArch64 instruction equivalents. blst's Fp multiplication costs 383 (organizer measurement).

**Per BSGS element: E = 2 units + 800 instructions = 2.4 units.** The non-reference
work is **measured** (see `kernels/`). Both a full Cheon element and the bare
two-addition pipeline were built against pinned blst and counted with Callgrind, using
the organizer's own image, compiler flags and checkouts. The same rig first reproduced
the organizer's reference totals exactly.

**Preprocessing** (all charged inside W): the P0 tables and the baby phase are
independent of the challenge, ≈ 2^116.73; they are recomputed per instance with
no amortisation. **Advice:** none. **Memory:** hash table 2^117 slots × 80 B, plus
six tables of 2^85 points × 96 B, plus 1 MiB ≈ 2^123.32 bytes (supplementary, not scored).

## 5. Heuristics and limitations

- H1: canonical keys of distinct classes are pseudo-random enough that linear
  probing at load 0.343 matches its random-hashing expectation (≈ 1.66 probes; the measured kernel ran at higher load, 0.25–0.5). The keys are BLS12-381
  x-coordinates of points with algebraically unrelated scalars. A deterministic
  sort-and-merge replacement would cost roughly 115 extra comparisons per element
  and is not used.
- H2: exceptional additions occur at their random-model rate (window value 0 with
  probability 3·2^−85 per element; x-collisions ≈ 2^−250). The total is charged as 2^38 units.
- The per-element instruction count is a Callgrind measurement of a faithful C kernel (`kernels/bls_step.c`, program 1) on random inputs, with reduced table and hash sizes. Instruction counts do not depend on table size apart from address width, which is covered by the allowance. Memory latency is not an instruction and is not charged, in line with the cost model.
- Toy experiments confirm the algorithm, the class-key collision structure and the
  exact success law at small scale only. Production cost is the analytic ledger above.

## 6. Applicability of W(n)

The attack needs 6d | r−1 with d = 2^20, and A_d (so n ≥ 2^20). The rules
confirm that A_{2^20} is supplied at the scoring n. For 2^20 ≤ n < r the same bound
holds unchanged. Smaller n are outside this claim.

References: J. H. Cheon, "Discrete logarithm problems with auxiliary inputs",
J. Cryptology 23 (2010); Gallant–Lambert–Vanstone endomorphism (CRYPTO 2001);
Duursma–Gaudry–Morain, equivalence classes under automorphisms (ASIACRYPT 1999).
The construction above is self-contained.
