## 8. Stratified-serial one-sided early abort: mechanism, expected-work bound and accounting

The baby side emits fully, exactly as in the base schedule. The giant base list is partitioned into L = 2^32 contiguous equal-mass strata served serially in rotated order, with a barrier and full candidate verification after each stratum; the run halts at the first verified-true candidate. Only giant-phase emission work is scored in expectation; every other row is at its maximum (comparisons, candidate rows, sieves, planner, distribution, owner initialisation are unchanged from the base), and every failure path is charged at its maximum with no conditioning on success. No pairwise rotation symmetry is asserted anywhere in this section; emission is serial by construction so no serial-to-parallel translation is needed; post-detection emission is exactly zero by barrier-idle, with no step/round conversion anywhere.

### 8.1 Expected work is the scored metric

rules.md requires charging "all preprocessing, advice construction, trials and failures, randomness, arithmetic, sorting/lookup, transfers, verification, output and amplification" over the stated probability space of uniform challenges and fresh algorithm coins. The "trials and failures" instruction has force only under expectation: it forbids reporting work conditioned on success (the lucky path) and requires the unconditional mean including failure paths. A worst-case-only reading would make that instruction vacuous (a maximum already covers every path) and would contradict the design's mean-based caps (comparison caps at 1.01x the mean, link caps at 2x the mean, pool at 1.29x the mean), whose overflow events are failure-budgeted rather than worst-case-bounded. The base line's full-emission ledger is a valid (loose) upper bound on expected work; this package scores a tighter valid upper bound. The expectation is over uniform t in H and fresh algorithm coins S (below); the emitted baby set B is the fixed challenge-independent set of the base, and the giant set is the same construction in rotated base order.

### 8.2 Mechanism: greedy equal-mass strata, serial rotated service, per-stratum verification

Stratum partition. The planner greedily cuts the giant base list (global order) into L = 2^32 contiguous strata by exact sieve class lengths: with cumulative sizes S_i and b_k = ceil(kN/L), stratum k is the bases (i_{k-1}, i_k] with i_k the first base reaching S_i >= b_k. First-crossing overshoot is below one base size, so each mass m_k lies in [floor(N/L)-EMAX, ceil(N/L)+EMAX] (nonempty; MASS_LO > 0 asserted). The partition is challenge-independent and runtime-computed (one linear pass, d x EMAX x 16 in the planner row); the ledger needs no actual lengths since all bounds are uniform over H2 sizes. Each base carries its stratum id (4 bytes, transfer charged); one uniform S over strata is sampled (128) and distributed (8 bytes per node).

Serial rotated service. Strata are served serially as S, S+1, ... (mod L) with a global barrier between strata (barrier row at E[strata]+3). Within a stratum each node serves its stratum bases sequentially in fixed sublist order, each base exactly per the base schedule (class plan, segment directory, greedy handoff with the listed 16-instruction restart, one gap-table load). Handoffs stay sequential per node (one table at a time; every handoff a genuine restart location). Transport waves run unchanged underneath at no more than the base per-wave rate; nodes without stratum bases idle. Rotated stratum index 8 per stratum; per-base mapping 24 per base. The baby side is untouched.

Per-stratum verification and halt. After each stratum barrier that stratum's candidates are verified: reverse delivery (2^44 cap; base per-link caps; overflow the same budgeted H3 failure), segment re-walk at each generating node (table rebuilt inside the charged re-walk row), scalar tests at the owner. Verification is finite charged work per candidate, so it always completes before the next stratum. The found flag rides in the barrier release word (zero extra); each node checks it once per stratum on wake (signal row). On found, nodes halt instead of resuming, including mid-stratum.

Zero-lag halt. After each stratum barrier nodes wfi-sleep (zero instructions); nodes involved in this stratum's verification wake to run exactly the charged candidate rows, all others sleep until the resume/halt wake in the barrier row -- no spin-wait exists, and verification latency is pure makespan. The resume/halt flag precedes any further emission, so post-detection emission is exactly zero; transport-lag records were emitted pre-barrier inside the batch counts. No step/round conversion is used, and no verification queue can form (arrivals stop at the barrier, so each verification drains fully).

### 8.3 Expected giant emission: E[F] <= 0.81 via the threshold lemma

Fix t with J(t) >= 1 (true pairs over the rotated giant set and full baby set) and take the lexicographically-first true pair (t-measurable; the run stops at the minimum, so no independence is needed). Given t it sits in a fixed stratum s*. Over uniform S, stratum s != s* precedes s* exactly for S in the cyclic interval (s*, s] of delta(s*->s) positions; the L-1 others realise distances {1, ..., L-1} once each (counting, not symmetry). So E_S[preceding | t] = (1/L) SUM_{s != s*} m_s delta_s. Lemma (threshold): for fixed distances 1..L-1 and masses in [a,b], SUM m delta <= f(b/a)(SUM m)(L-1)/2 + (b-a)L with f(R) = 2 sqrt(R)/(sqrt(R)+1): the ratio is maximised at a threshold configuration (exchange argument gives at most one fractional unit, contributing (b-a)L), and the integral thresholds peak at max_{x}(R-(R-1)x^2)/(R-(R-1)x) = 2 sqrt(R)/(sqrt(R)+1) at x = sqrt(R)/(sqrt(R)+1). evidence.py verifies R = MASS_HI/MASS_LO <= ((1+delta)/(1-delta))^2 for delta = 2^-25 over integers, equivalent to f(R) <= 1+delta; hence E_S[preceding | t] <= (1+2^-25)(N-m*)/2 + 2EMAX+2 points, plus the current stratum bounded in full (MASS_HI). The rotated-last base walks the count-prefix window; the set moves by at most 2 x EMAX x N ratios (asserted 2 x EMAX x N x 200 < m), so P(J=0) <= e^-K + 0.0005 + 2^-61 by H1 (0.60996 at KT; realised K >= KT only tightens e^-K). With full emission on J=0: E[F] <= (1+2^-25)(1-P0)/2 + P0 + 2EMAX/N + MASS_HI/N = 0.80499279... plus granularity below 2^-30 (asserted: 2EMAX/N < 2^-56, MASS_HI/N < 2^-31). The ledger claims EFRAC=81/100 with margin above 2^-30 (asserted). Only premises: algorithm coins S, the threshold lemma, H1.

### 8.4 Row-by-row ledger consequences

Emission after the halt signal is exactly zero (barrier-idle), so no overshoot row exists. Per-point rows (records walk part, allowance, head-index) follow the same partition.
