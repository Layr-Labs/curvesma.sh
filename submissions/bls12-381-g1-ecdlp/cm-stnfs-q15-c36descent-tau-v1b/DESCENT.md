## 1. Lattices, Canonical CM Metric `Q_CM`, and Exact 16D Ball Half-Counts
- **Special-`q` Node Lattices (`dim = 16`, `det = q`):** A node is a degree-1 special-`q` prime ideal `(q, y - s, x - t)` on side `f_9` or `g_3` (`l`-bit norm `q`), with 16D lattice `L_q = {(a, b) in O_H^2 : a(s) - t b(s) == 0 mod q}`. - **Exact 16D Ball Half-Counts (`q15_cells16.py`):** Regions are radius-`R` Euclidean balls in reduced-basis coordinates (`||k||_2^2 <= R^2`, one cell per `+-` pair). Exact counts `CELLS_16D[R]` for `R in [2..256]` are computed via Kronecker-packed exact integer `theta_3(q)^16` (`CELLS_16D[2] = 17,072`, `CELLS_16D[4] = 642,328,192`, `CELLS_16D[64] = 2^92.9142`, asymptotic `R=256 / Vol = 1.00006152`).
- **381-bit `G_T` Target-to-Boot Reduction (`dim = 16`, `det = p^4`, Verified Live in `audit_cm.py`):** In the tower `F_{p^{12}} = F_{p^4}[X] / (X^3 - w_pi^2 u)` with `F_{p^4} = F_p[y] / (h_pi(y))` and quadratic subfield `F_{p^2} = F_p(s)` (`s = y + y^{p^2} in F_{p^2} \ F_p`, so `F_{p^4} = F_{p^2} + F_{p^2} y` and `F_{p^6} = F_{p^2}[X] / (X^3 - w_pi^2 u)`), write the randomized target `z' = z * gamma_0^e in G_T` (`e` uniform in `[1, r)`) as `z' = (u_0 + v_0 y) + (u_1 + v_1 y) X + (u_2 + v_2 y) X^2` (`u_i, v_i in F_{p^2}`). Setting the `F_{p^6}` cofactor `c = c_0 + c_1 X + c_2 X^2` with `c_0 = u_1 v_0 - u_0 v_1`, `c_1 = u_0 v_2 - u_2 v_0`, `c_2 = u_2 v_1 - u_1 v_2` annihilates the `X^2` coefficient identically (`c_0 (u_2 + v_2 y) + c_1 (u_1 + v_1 y) + c_2 (u_0 + v_0 y) = 0`), yielding `c * z' = A - B X` with `A, B in F_{p^4}` (if `c = 0` or `B = 0`, probability `< p^{-2}`, redraw `e`). Setting **`gam = A / B in F_{p^4}`** defines the skewed 16D lattice `L_boot = {(a, b) in O_H^2 : a(y) == gam(y) b(y) mod (p, h_pi(y))}` (`S_boot = 2^21 ~= |u|^{1/3}` balancing `|a|^3` against `|u| |b|^3`), reduced by exact 2-phase `(11/40) -> (99/100)` Bareiss LLL (`LLL_BOOT = 2^46.5 > 2^46.45` proved input-uniform). For every `(a, b) in L_boot` with `b(y) != 0 mod (p, h_pi)`, we have the exact identity in `F_{p^{12}}`:
  `a(y) - b(y) X == b(y) (gam(y) - X) == (b(y) B^{-1} c) * z' (mod (p, h_pi(y), X^3 - w_pi^2 u))`.
  Because `b(y) B^{-1} in F_{p^4}^*`, `c in F_{p^6}^*`, and `gcd(r, (p^4 - 1)(p^6 - 1)) = 1`, both subfield factors vanish in the order-`r` quotient: **`log_r(a(y) - b(y) X) == log_r(z') == log_r(z) + e * log_r(gamma_0) (mod r)`**, while the `g`-side ideal `(a - b X)` has norm `N_g(a, b) = N_{H/Q}(a^3 - u w^2 b^3)`. `audit_cm.py` (`voronoi_exact`) executes this exact 381-bit BLS12-381 `G_T` reduction live and asserts `c^{p^6} = c`, `(c * z')_{X^2} = 0`, and `a - b X == (b B^{-1} c) * z'`.
