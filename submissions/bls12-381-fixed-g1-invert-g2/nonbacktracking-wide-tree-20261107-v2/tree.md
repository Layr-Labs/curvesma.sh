# Minimum-degree32 global B-tree and deterministic amortized work

The nonbacktracking transition retains the previous generator, so checkpoint-only cycle detection is not used. Store all visited orbits. Keys are the full320-bit U, viewed as five unsigned64-bit little-indexed limbs. On U equality, compare canonical b exactly and terminate: equal b is an orbit match, different b a fingerprint failure. No unchecked hash acceptance or expected-probe assumption is used.

Use a top-down B-tree of minimum degree32. Nonroot nodes have31..63 keys and32..64 children; root has1..63 keys. An8192-byte node has a64-byte header(nkeys,leaf,reserved),63 slots of64 bytes at64+64i,and64 logical128-bit children at4096+16i. A slot contains U at0..39,zero padding40..47,andthe16-byte payload index at48..63. All paired logical-pointer accesses are16-byte aligned. All pointers are two64-bit logical words,0=nil. Unoccupied slots are zeroed on allocation but never searched.

A512-byte payload contains36 b words at0..287,constantzero288..295,zero alignment296..303,A32 at304,B32 at336,k8 at368,andzero padding through511. Saved full raw points are unnecessary: canonical b plus saved/current k gives the twist. Current raw points remain shared.

Search each node by three-way binary comparison, at most six comparisons for63 keys. Return immediately on U equality. Otherwise choose the child interval. Split a full child around median31 before entering: lower31 stay,upper31 move to a new node,andmedian/payload pointer enters the nonfull parent;children partition accordingly. Compare with the promoted median and choose the subchild. Split a full root first. At a nonfull leaf,write payload,shift slots,insert andincrement count. Store parent logical index/position in bounded shared scratch. Split-related revisits are charged in the separate split budget.

Minimum occupancy gives n>=2*32^h-1 for height h. Since n<=K+1<2^126,at most26 ordinary node visits per descent is conservative. Total nodes<=((n-1)/31)+1<K/31+2<2^122. Each split adds nodes,so total splits<=K/31+2,even if the final duplicate search preemptively splits. Payload keys are moved,never duplicated. Reserve2^122 nodes*8192=2^135 bytes,unchanged total tree capacity from the narrower layout.

Each ordinary node visit costs<=256 instructions: six full320-bit comparisons<=32 each,one selector<=32,andheader/child/logical-path/control<=32. A comparison loads five words from each operand with paired/scalar loads,computes five SUBS/SBCS differences and an ORR zero test,then branches/updates the bounded midpoint. Pointer setup and search control fit32. Thus path work<=26*256=6656 per transition. Key-slot addresses are formed explicitly from index*64;child addresses use a separately computed child-base pointer,so no out-of-range paired immediate is assumed.

Leaf shifts admit a deterministic amortized bound. A new nonroot leaf starts with31 keys after splitting. Before its next split it receives at most32 insertions,with old occupancies31..62. If it receives k<=32 insertions,the total possible shifted slots is at most31k+k(k-1)/2<=46.5k. This holds for every prefix of its lifetime and any insertion order. A root leaf starts smaller and its average occupancy is no larger. Splits start new lifetimes and their own moves are charged separately. No random key-rank assumption is used.

A64-byte backwards slot move uses four LDP/four STP (eight data instructions) andat mosteight pointer/count/branch instructions,at most16 total. Amortized shifts therefore cost<=744 per insertion. At most280 further instructions pay current slot writes,header,loop setup,context andreturn bank selection;retain1024 per transition for the complete leaf insertion. The bound is on total work,not a false per-insertion worst-case claim.

Payload allocation/write<=192 includes two-limb allocation index,selector,initializing512 bytes andcopying b,A,B,k. Split<=16384 includes full child read,old/new8192-byte node writes/initialization,parent read/write,all key/child moves,headers,root change,up to eight selectors andscratch/context. Directly scaling the narrower fixed-array implementation andallowing full-node copies fits comfortably: data copies/moves<12288,selectors/headers/control<4096. This is a fixed finite upper bound,not a free structural primitive. Total split work<=16384(K/31+2),covered by640K plus a cold constant because16384<640*31.

Total dictionary work is6656K+1024K+192K+640K. Exact b verification andscalar recovery occur at most once and are fixed cold work. All arrays are initialized on allocation,all accessed fields are occupied/valid,andall physical capacities are counted in storage.md. There is no free global table build,sorting phase,network transfer,capacity zeroing orwide-word arithmetic.
