## Exact search and its probability

For the supplied nonidentity P compute h=e(P,Q0), with the protected pinned pairing(Q0,P) and standard Q0. Prime order and nondegeneracy make h a generator for every allowed P. Write z=h^a with a uniform on [0,r) for every P. Return a G2 point, never just the exponent.

Set s=2m-1. Canonicalize each t in GT as K(t)=min(t,t^-1) under a consistent full-coefficient lexicographic order, retaining sigma(t) in {+1,-1} with K(t)=t^sigma(t). Break the identity tie with +1. Construct babies (K(h^j),j,sigma_j), 0<=j<m, by successive products with h. Sort them by the explicit merge tree below and populate its separate search tree. Distinct j give distinct orbit keys: j=+k or -k modulo r with j,k<m and 2m<r forces equality, except identity where j=k=0.

For i=0,...,m-1 let c_i=i*s+(m-1). Start v=z*h^(-(m-1)) and update by h^(-s). Search K(v). A match j gives a=c_i+sigma(v)*sigma_j*j. Verify h^a=z, form Q=[a]Q0, check membership and e(P,Q)=z for the exact supplied P, and encode Q canonically. If all queries fail return infinity. Identity targets succeed immediately. All offset/stride exponents, checks and final reconstruction are paid.

A match is equivalent to a-c_i=+j or -j modulo r. The signed candidates for each center fill [i*s,(i+1)*s-1], so the m centers cover exactly [0,L). There is no wraparound because L<r. Every prefix target is found; no outside target can match or succeed via infinity. Thus success is exactly L/r, with unsuccessful executions fully charged. The protected hexadecimal order has leading byte 0x73, so 115*2^248<r<116*2^248. L=3042*2^242-39*2^121<r, and 100L=304200*2^242-3900*2^121>289536*2^242>39r.
