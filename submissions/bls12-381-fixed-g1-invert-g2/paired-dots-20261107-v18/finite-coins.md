# Finite local independence and charged entropy channel

This is a proposed analytic variant,not a practical run or an unconditional hardware entropy claim. It replaces the actual-BLAKE3 finite aggregate transfer hypothesis with exact16-wise table independence plus an explicit bounded entropy-channel cost/admissibility condition R_coin. The protected probability space explicitly includes fresh independent algorithm coins. It does not specify their physical generation instruction cost;therefore R_coin is stated rather than silently assigning an ideal randomness opcode to AArch64.

R_coin: a fresh request tape of at most4438016 independent unbiased bits,independent of the target,is supplied using at most2^100 scalar instruction equivalents in TOTAL,including entropy construction,transfers and failed requests. The source couples to a pre-existing mathematical ideal tape independent of the target;it may fail arbitrarily on at most2^-100 probability mass. No conditioning-on-source-success uniformity is assumed. An unavailable/failed source causes attack failure,with probability at most2^-100. This conditional channel bound is material. No assertion is made that RNDR,a deterministic PRNG or a fixed hash seed implements it. An implementation must justify it;the present claim is conditional on it and the separate bank-window model. No oracle is free:the full2^100 channel budget is charged cold even when fewer bits are consumed. Uniform independent coins are the mathematical random input specified by the protected probability space,not target-dependent advice.

Sampling: reserve sixteen disjoint1024-attempt blocks,255 fair bits per attempt,for c0,...,c15. Interpret each candidate in0..2^255-1;accept iff below full r. First accepted in each block is used;all1024 rejected means failure. Separate two blocks of1024 attempts of127 bits each sample K0,K1 uniformly modulo q=2^127-1. Unused bits are allowed to remain unread;all reserved generation is paid. Total upper bit count is16*1024*255+2*1024*127=4438016<2^23. r>7*2^252 gives scalar reject<1/8;union failure<16*2^-3072=2^-3068. Key union failure<2*2^-130048=2^-130047. Conditioned on successful bounded samplers,the sixteen coefficients and two keys are exactly mutually independent uniform field elements. Sampler block failures are bounded separately;no rejection bias or pseudorandom extrapolation is used.

Let f(X)=sum_{i=0}^{15}ci X^i over full protected Fr. Define v_j=f(j),w_k=f(W+k),0<=j,k<W. Since2W<2^85<r,all2W evaluation arguments are distinct in Fr. For ANY t<=16 distinct arguments,the t-by16 Vandermonde evaluation map has full row rank:its first t columns have nonzero determinant product of pairwise argument differences. Uniform coefficient vectors therefore map to exactly uniform Fr^t. These table values are16-wise independent,not globally independent. No statement of full table independence is needed or claimed.

Every product of at most four useful-collision indicators mentions at most eight sample edges,therefore at most sixteen distinct table vertices. Thus its expectation is EXACTLY the corresponding full-independent-table expectation,by the preceding local joint distribution. Expanding E binom(C,k) as a finite sum for k=1,2,3,4 transfers each full-independent moment argument exactly. Identity per-sample events mention at most two vertices;exact-key pair events at most four. Their union/Markov bounds also transfer exactly. Independent K0,K1 give the same fingerprint root bound conditional on any two unequal exact keys. A global total-abort transfer hypothesis is unnecessary:each union/expectation is directly bounded. The graph cycle/rank/pattern bounds and finite Bonferroni inequalities remain unchanged. The material entropy-cost assumption R_coin replaces the old actual-hash H;this is not an unconditional implementation claim.

Concrete cold polynomial evaluation uses Horner from c15 at each full argument d=j or W+k. Fifteen steps update acc=(acc*d+ci) mod r,keeping all four64-bit limbs. A simple bounded native implementation suffices:modular add loads both four-limb operands,adds with four ADD/ADCS,subtracts all four modulus limbs with SUBS/SBCS,selects the four canonical output limbs with CSEL,and stores. Since r<2^255,the sum is below2^256,so no256-bit overflow is discarded. Allow64 instructions per complete add including loads,stores,args,RET and controller. Multiplication scans all255 bits of d from high to low,start0;double the accumulator each time and conditionally add the multiplicand. Both operands stay below r. Allow two64-instruction additions and64 more for bit extraction,branch,loop,pointer/frame work per bit,plus512 setup/finish:255*192+512<2^16. This is ordinary full-width bit-serial multiplication,not a unit-cost255-bit primitive. Fifteen multiplies plus fifteen adds,initialization,indexconversion and BE scalarcopy fit below2^21 native instructions per record. All prefix transforms,full GT powers,full scalar/canonical arithmetic and memory writes are retained. The samplers inspect all bits/limbs with at most256 instructions per candidate;18*1024 candidates fit below2^23 additional controller instructions. Complete source/retained coin tape is below2^23 bytes including padding,well inside the existing memory envelope.

A record's512 dense references cost10240000 native;Horner<2^21 and all other cold record work<65536. Their sum is below2^25. For2W<2^85 records this is below2^110. These costs include failures.
