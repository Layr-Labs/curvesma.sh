# Initialized dictionary and finite banked storage

This is an explicit storage-only model,not installed VM hardware. Admissibility is a material condition. A noncacheable2^40-byte window starts at native address2^45,shared/code/scratch below2^45. A97-bit logical bank is selected by two64-bit latches and commit;DSB,low/high stores,commit,DSB make data/publication ordering explicit. All pointer/index/arithmetic/control/transfer work is paid. No search/compute/DMA oracle or flat136-bit native pointer is assumed;addresses stay<2^46 within48-bit VA.

Payload logical p>=1 maps q=p-1 to local31 bits,offset local*512,bank q>>31<2^95;0 is nil. Heads index i128 maps local36 bits,offset local*16,bank2^95+(i>>36)<2^96. For table t=0,1,2 and85-bit index k,map local30 bits,offset local*640,and bank2^96+t*2^55+(k>>30)<2^97. The last bank's low latch needs fewer than57 bits,high latch is region bit32. All128/85-bit arithmetic uses pairs of64-bit registers;each selector including its arithmetic/barriers/interface/RET fits32 instructions. Bank ranges are disjoint. Copy T0 raw576 to shared scratch BEFORE switching to T1;consume T1 and T2 inside their respective multiply calls before the next switch. Constants/code/shared buffers are initialized cold.

All2^128 sixteen-byte heads are explicitly zeroed by charged CPU stores. A512-byte payload is entirely zeroed,then stores S192@0,beta32@336,k8@368,U40@384,next128@432;the rest is initialized padding. Three640-byte table records contain raw576 and zeroed64-byte padding. Current raw960 record holds GT576,beta32@608,k8@944;unused scalar-A padding is initialized but NEVER read. In this algorithm A=1 for every sample,not payload index or sample count. Native sampler/counters,full key/hash buffers,1040 NH seed bytes and canonical/Montgomery scratch are initialized shared data.

On a new key,read its head,scan chain for five-word U equality,decrement/check the hard visit counter before EACH visit. If no match,allocate next p,zero/write all512 bytes including next=oldhead,complete writes before switching banks and publish the head. On U match,copy beta/k/key before another switch and compare all24 exactS words;false U match is the fingerprint failure. Exact match terminates;logical p is only an address here. No stored raw point or scalar-A field is inferred. All frames/preservation/arguments,serial two-word head operations and publication are priced.

Conditional on the independent ideal sample path and no fingerprint collision,distinct orbit keys have iid uniform128-bit buckets. Extend the distinct-key prefix to n=L independent dummy bucket values. Let Cb count co-bucket pairs. Then mu=L(L-1)/(2*2^128)<0.105L and Var(Cb)<=mu<L:even overlapping pair indicators have zero covariance. The gap floor(L/8)-mu>0.020L. Chebyshev gives Pr[Cb>floor(L/8)]<1/(0.020^2*L)<2^-100. Distinct insertions require at most Cb visits. The final repeated query REUSES its saved bucket and requires at most Cb+1 additional visits;total<=2Cb+1. A native global cap floor(L/4)+2 therefore suffices except on that bounded event. Prefix counts are monotone,so early exhaustion is included;no fresh-bucket assumption at the repeat is made.

Fixed miss work<=512:three selectors96,full payload zero32 STP,S copies24 LDP/24 STP,beta4/k2/U6/next2 transfers,head loads/stores,128-bit allocation/cap/control and all frame/argument/publication/RET fit with more than200 spare. Each visit<=128 including selector32,all fingerprint comparisons,next128,hard counter and branches. Match/cap paths fit512+128*visits. Total<=512L+128(floor(L/4)+2)<=544L+256. Retain1024L;the256 fixed remainder is cold paid.

Reserve2^126 payloads*512=2^135 bytes,heads2^128*16=2^132,three tables each2^55 banks*2^40=3*2^95 including padding,and shared/code<2^45. Total<2^136. All actually read bytes are initialized;unused capacity/padding supplies no data. Memory is supplementary,not a metric. If the finite banked model is inadmissible,the claim must be rejected;no practical installation is asserted.
