# SHA-512 with one exact precomputed prefix block

Use standard SHA-512 throughout. Keep the16-byte INIT,SCAL,WALK tags defined in proof.md. Set seed=SHA512(INIT||canonical_P||canonical_z), giving64 bytes. Sample each scalar from the low255 bits of SHA512(SCAL||seed||counter_be64), reject if>=r and cap attempts at1024. These88-byte scalar messages fit in one SHA-512 padded block. For walk labels use the low24 bits of SHA512(WALK||seed||zero48||U(X_bytes)), with zero48 exactly48 zero bytes and X_bytes the injective289-byte norm-one encoding. Each domain has a distinct tag and fixed length; counters never repeat. All hashes are actually computed scalar operations. The heuristic now explicitly idealizes these SHA-512 computations, rather than SHA-256. It remains unproved over the enormous production trajectory.
