# Large-table rho with a finite ideal-hash collision bound: 128.539

This cold classical attack claims total computation below2^(128539/1000)=2^128.539 dense-Fp12 reference equivalents at fixed C=20000,success at least0.39 under the sole disclosed SHA-512 random-function heuristic,peak storage below2^35 bytes,and zero nonuniform advice. Preprocessing below2^(128539/1000) equivalents is included. The computation bound is deterministic even if the heuristic fails. The probability argument is rigorous inside the ideal-hash model and is given in collision-proof.md; fixed SHA is not mathematically certified by that model. This is an exploratory heuristic claim,not a practical break or production execution.

## Actual algorithm and one heuristic

Validate the protected full-production inputs and compute h=e(P,Q0) with the pinned pairing(Q0,P),standard profile Q0,and supplied nonidentity P. Nondegeneracy and prime order make h generate GT for every such P. For z=1 return infinity. Otherwise z=h^a uniquely for a in[0,r). The answer is a G2 point Q=[a]Q0 for this exact P,never just a scalar or a substituted pairing input.

Use the16-byte ASCII tags FAPI-RHO-INIT-v1,FAPI-RHO-SCAL-v1,FAPI-RHO-WALK-v1,called INIT,SCAL,WALK. Encode P as its canonical two48-byte coordinates and input z as its twelve canonical48-byte polynomial coefficients. Compute the64-byte seed=SHA512(INIT||P_bytes||z_bytes). There are no external random coins or uncharged entropy service. The actual implementation is deterministic on its uniform challenge and computes every hash as scalar code.

Initialize the five uniform compression keys using the separate16-byte tag FAPI-RHO-UKEY-v1 as described in universal-proof.md. Initialize w=16777216 jump pairs(u_j,v_j). A scalar candidate is the lower255 bits of SHA512(SCAL||seed||counter_be64),with a globally increasing counter. Accept if<r,with at most1024 trials per scalar. If any sampler exhausts its limit return failure/infinity. Store M_j=h^u_j*z^v_j and the coefficients. Finally generate alpha0 by the same method and start state(X,A,B)=(h^alpha0,alpha0,0). The main scalar count is2w+1=33554433, plus five separately sampled compression keys;the counter never reaches2^36 and fits the stated eight bytes.

Each step selects j as the low24 bits of SHA512(WALK||seed||zero48||U(X_bytes)),then updates X<-X*M_j,A<-A+u_j mod r,B<-B+v_j mod r. X_bytes is the injective289-byte norm-one encoding proved in compression-proof.md:the six canonical Montgomery coefficients of b in X=a+bw,and one lexicographic sign bit of a. It depends on the group element alone,not its coefficient history. Here zero48 is exactly48 zero bytes. The168-byte walk message begins with a fixed128-byte prefix; its first SHA-512 compression block is computed once in setup, and only one remaining padded block is computed per transition. U is a charged40-byte independently keyed polynomial compressor. universal-proof.md gives its exact algorithm, scalar cost and finite adaptive-walk collision bound. SHA hashing uses standard padding and the original message length1344 bits. Full576-byte state storage and equality checks remain. Thus the step is a deterministic function on GT and preserves X=h^A*z^B.

Use 62 equally spaced checkpoint intervals. Set R=ceil(sqrt(r)), L=ceil(1070R/1000), s=ceil(L/62), and K=L+s. Initialize current=(h^alpha0,alpha0,0), save it at index zero, and maintain saved records in insertion order plus a sorted array of pointers ordered lexicographically by the 72 canonical 64-bit words of each complete GT element. For every t=1,...,K advance once, then binary-search the pointer array for the complete current element. On the first equality recover the exponent using that saved record exactly as below; a zero denominator fails immediately. Verify h^a=z, construct [a]Q0 and verify subgroup and pinned pairing equality. If no equality and t is one of s,2s,...,62s, save the complete 640-byte current record and insert its pointer at the binary-search insertion position. Never search a checkpoint created at the current index. At K without a relation fail. There are at most 63 saved records. Searches use group elements alone, never coefficient histories. checkpoint-proof.md proves deterministic detection, the unchanged conditional relation argument, and complete instruction bounds.

The sole computational heuristic H is that,for average-case success over the protected independently uniform P and z,the domain-separated actual SHA-512 computations can be analyzed as independent random functions on their distinct input domains. This is the familiar hash idealization used for rho partitions and initialization,not an actual supplied oracle. Actual hashes are fully computed and charged. H is unproved for fixed SHA at this enormous scale and may fail;no unconditional fixed-SHA success theorem is asserted. In particular we do not assume the adding walk itself is a uniform random mapping or assume an unproved mean-collision bound. The finite proof below handles its correlations.

Relevant context: Bos et al.,section3.1/Table1,describe adding walks and scalar recovery,and report32-adding means close to their birthday heuristic on sampled32-bit groups. They warn that the original squaring-walk proof does not automatically transfer to adding walks. We do not import a255-bit running-time guarantee from those observations. Source:https://www.joppebos.com/files/noan112.pdf . The Fourier/Cayley approach is standard in additive-rho analyses,including Bos,Dudeanu,Jetchev:https://eprint.iacr.org/2012/087.pdf ;their asymptotic bounds are not used as the finite constants here. ## Finite success argument

collision-proof.md is part of this claim. Under H,initialization rejection produces independent uniform residues modulo r. Since r>2^254,a255-bit candidate is accepted with probability>1/2. Across33554433 scalars,the probability of any1024-attempt failure is below2^-990. The jump group elements are independent uniform GT values,including possible duplicates. A Hoeffding/character union bound gives probability below2^-100 that any nontrivial Cayley eigenvalue has modulus>1/128. The algorithm need not identify or verify a good table and charges all tables' work.

On a good table,Fourier inversion and Parseval bound the d-step transition error in both sup and unweighted l2 norm by(1/128)^d. A first/second-moment calculation with the integer-valued Bonferroni inequality over all collision intervals of length at least271 proves probability>0.3904 of a repeat by L=ceil(1070ceil(sqrt(r))/1000). It explicitly includes nested/crossing interval correlations. Coupling to independent-index transitions is used only until the first repeat or a distinct-state compression collision; the extra loss is less than2^-13 by universal-proof.md. The deterministic checkpoint lemma in checkpoint-proof.md converts a first repeat by L into a detected equality by K.

Condition on the jump group values,partition and initial group value. Every v_j remains independent uniform since each v_j fixes exactly one u_j for given M_j and z=h^a. At a checkpoint equality,the coefficient difference is a linear form in v_j whose nonnegative counts sum to the positive number d of trajectory steps since anchor. Since d<=K<r,some count is nonzero modulo r. Thus D is uniform and zero with probability1/r even conditional on the observed trajectory. No extra collision-relation heuristic is introduced. For D!=0,the maintained invariant gives the unique target exponent and the verified G2 output solves the supplied-P input exactly.

Subtracting sampling,bad-table,singular-denominator and compression failures (the last below2^-13) from0.3904 leaves ideal-hash success>0.39. The declared success lower bound is the more conservative0.39,conditional only on H's bridge to actual SHA on uniform challenges. Identity targets succeed deterministically. These are algorithmic probabilities,not reviewer confidence or measured production success. This submission declares only bounded arithmetic fixtures, not production cryptanalytic execution.

We use the pinned blst_fp12_mul implementation and its canonical Montgomery tower representation Fp2(u^2=-1), Fp6(v^3=u+1), Fp12(w^2=v). It is the exact operation calibrated by scripts/reference_costs/fp12.c and measurement.json. This does not replace C=20000 with a measured or candidate-selected price. We count the complete reference multiplication once and do not additionally charge its internal base-field implementation.

The other scalar work per step is 4096 for universal compression, 8832 for SHA-512 including all message preparation, 512 for the equivalent sign schedule, 5888 for sorted-checkpoint/scalar/lookup bookkeeping, and 384 extra for reference-call pointer preparation, state-buffer selection and all remaining interface control. Sum R_step=19712. The complete reference routine writes to the next state's 576-byte buffer directly; its inputs point to current state and the selected table record. No dense-product scratch frame or tower-formula dispatch is needed outside the reference operation. Three pointer arguments, each at most two scalar instructions, and BL cost at most seven; the 384 interface allowance also covers a preserved current/next buffer-pointer swap and leaves ample margin. Full state copies when saving a checkpoint remain in the 5888 allowance. All loads/stores are charged by instruction count, not treated as free transfers.

Thus each step costs 1+19712/20000=39712/20000 reference equivalents. No arithmetic price is inferred from timing. The 8832 SHA schedule and 512 sign schedule are proved in prefix-audit.md and compression-proof.md. The group trajectory and labels are identical to the inherited walk.
