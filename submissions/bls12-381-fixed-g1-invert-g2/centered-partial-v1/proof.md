## Exact key and local cost

Use the native reference tower Fp2=Fp[u]/(u^2+1), Fp6=Fp2[v]/(v^3-u-1), Fp12=Fp6[w]/(w^2-v). Write X=A+B*w with A,B in Fp6. The nontrivial Fp6 automorphism sends X to bar(X)=A-B*w. It equals p^6-Frobenius, since this is a quadratic field extension. The protected integers satisfy p^6=-1 modulo r (checkable by six modular multiplications), so every order-r element satisfies bar(X)=X^(-1). This includes identity. Neither a subgroup reduction nor a replacement challenge point is being made.

All tower coordinates use canonical six-limb Montgomery residues. The scale and field basis are fixed and invertible. Define K(X) to be the lexicographic minimum of the full 72-word arrays for X and bar(X). Then K(X)=K(Y) if and only if Y=X or Y=X^(-1). This follows because the two-element sets are either disjoint or identical; selecting one member cannot identify distinct such sets. No hashing, lossy fingerprint or heuristic collision claim is present.

Compute bar(X) by negating exactly the six base-field coordinates in B, preserving A. For one canonical Montgomery residue t, use p-t if t is nonzero and zero otherwise. Six-limb subtraction, zero testing and conditional selection fit below 128 scalar instructions per coefficient, including loads and stores. Six such negations, a full 72-word comparison and full record movement use below 8192 instructions. Charge 8192 instructions for this local key computation, within the generation and giant local budgets below; it needs no dense multiplication or inverse exponentiation. Keep the raw X separately in local scratch so canonicalization does not change the iterated walk value. Copies and all zero cases are paid. Fixed conversion of the public inputs to/from the native tower is setup, not a per-sample operation.

## Partial centered algorithm and complete probability argument

Validate canonical P,z including subgroup membership and P!=infinity. If z=1, return canonical G2 infinity after exact verification. Otherwise set h=pairing(Q0,P) in the pinned G2-first calling convention. Nondegeneracy and prime subgroup order make h a generator of GT for every permitted supplied P. Conditional on any such P, the independent uniform target z has unique exponent a in [0,r), uniformly distributed. The algorithm never sees that exponent or the challenge sampling coins.

Define K=ceil(391*r/1000), t=floor(134*K/2016), m=isqrt(t)+1, S=2m-1, H=ceil(K/S). This fixes m by public integer arithmetic; it is not searched advice. For the protected r, m=36915586649293397092516781056760671371, m<2^125, H=277693368227520479621320263471751915977<2^128. The rounded K and m are also computed cold in setup. Let L=ceil(log2(m))=125.

Generate raw h^j for j=0,...,m-1 by one dense multiplication per record from identity. Store 80-word initialized records with 72 words of exact K(h^j), two words j and six zero padding words. The letter K in K(X) denotes the canonical key function, while integer K without an argument denotes the coverage threshold. Preserve the raw element for the next multiplication. Keys are unique: a repeated inverse-orbit key requires j=k or j+k=0 modulo r; because 0<=j,k<m<r/2 only j=k=0 permits the second relation.

Sort with two arrays and 125 bottom-up merge passes. The non-power-of-two last run is copied as an incomplete run; each pass still has at most m comparisons and at most 2m moves. Run endpoints use exact three-limb arithmetic; clipped right endpoints are min(start+width,m). No uninitialized padding record is ever read.

Set c_i=m-1+iS, gamma=z*h^(-(m-1)), D=h^(-S). For i=0,...,H-1, binary-search K(gamma). On a match j, test x=(c_i+j) mod r and x=(c_i-j) mod r against h^x=z. For a verified x, construct Q=[x]Q0, check the G2 curve and subgroup, verify pairing(Q,P)=z for the exact supplied P and serialize. Otherwise update gamma=gamma*D. If all H searches end with no match, report algorithmic failure; this is explicitly permitted by the success-probability claim. It is not silently retried, amplified or amortized. All failures consume at most the stated worst-case budget.

For fixed i, exponents c_i+-j with 0<=j<m are exactly every integer in [iS,(i+1)S-1]. Thus the H adjacent blocks cover [0,HS-1], with no holes. Exact protected-integer checks give K<=HS<r, so there is no wraparound in the covered interval. For every a there, gamma=h^(+-j) at its block and its exact inverse-orbit key matches; one tested scalar is correct. For any verified match, bilinearity proves the required supplied-P pairing equation. Returning infinity for a=0 is included in this coverage. Hence for each P separately, success is at least HS/r >=K/r >=391/1000>0.39. Averaging over the uniform nonidentity P preserves this lower bound. There are no random coins, so no unproved ideal randomness assumption. Reviewer confidence is unrelated to this algorithmic success probability.

Targets outside the interval may fail and are not claimed solved. Every such failure is charged H iterations. Only the target exponent is restricted in the success analysis; the challenge distribution remains independently uniform over the full production GT, and the algorithm receives no special-format input.

## Finite storage and transfer convention

The storage requirement is enormous and cannot be allocated on this VM. The challenge permits analytic arguments for exponentially large attacks. This is a finite abstract classical computation, not a claim that the current physical machine has the attack's storage. In particular, a 64-bit register is never assumed to hold a 140-bit address.

Each logical address has three 64-bit limbs. Realize storage as a binary tree of routing controllers and leaf banks. A leaf bank holds at most 2^30 bytes with ordinary 64-bit offsets. Both arrays together contain 1280*2^125 <2^136 bytes (and in particular <2^138); fewer than 2^108 leaf banks suffice after rounding. Choose a padded complete tree with 2^108 leaves and depth 108. Reserve code, controller state and messages separately below. Controllers route one bounded record or comparison request down and back along its three-limb address. Only a constant number of requests need be in flight, as the whole algorithm can be serialized. Work is summed over all controllers; distributed storage does not give free computation or a parallel speedup.

For one complete record move or a comparison of two remote records, charge T=2^19 scalar instructions. For a comparison between a root-resident query and one remote record, charge B=2^18. A message header is at most 16 words; a complete record plus header is at most 96 words. Each hop is charged 16 instructions per word for loads, stores, addressing, link/control and acknowledgments. A header path of depth 108 therefore costs 108*16*16=27648 instructions. A record path costs 108*96*16=165888. All messages are bounded and all routing work is included in these word costs. No physical-distance or elapsed-time discount is used.

A record read consists of a header request going down and a record coming up: 193536 instructions. A record write sends a record down and receives a header acknowledgment: another 193536. Together, reading a source and writing a destination cost 387072 instructions; 10000 additional endpoint instructions for local copying, address calculation and control leave 397072<524288=T. A comparison of two remote records can instead read both to the root (also 387072) and compare there, within the same T. Sorting may use this fully paid conservative path.

A giant-search comparison starts with its query already resident at the root. Send that complete query to the selected leaf, compare its full 72-word key locally, and return a result plus header (at most 17 words). The path work is 108*(96*16+17*16)=195264. Adding 10000 endpoint instructions gives 205264<262144=B. The leaf need not return its complete record merely to report order or equality. On the one successful match the exponent retrieval uses the separate T allowance within the giant budget. Sorting, however, is not charged the cheaper B for two operands that are both remote.

Initialization, clearing message buffers and endpoint comparison/copy work are covered by the 10000 endpoint reserve and separate tree construction allowance. Header and full-record costs are counted even for losing comparisons; no early-out savings are assumed. Leaf-resident data accesses stay within 64-bit offsets. Three-limb global addresses are routed explicitly.

This is a conventional finite word/message-storage model, not a measured device implementation. Its material limitation is physical realizability at this scale. The argument assumes links transmit a bounded word with bounded scalar work as above, with no additional distance-dependent energy or latency objective. Latency is not the score. If the normative instruction model disallows any such banked storage, this candidate should be rejected rather than silently treating addresses as single words. The claimed bound includes the concrete routing depth instead of asserting free memory switches.

This extremely conservative bound is justified by elementary bit arithmetic: at most 381-bit base residues, at most 4572-bit field exponents, 12-coefficient polynomial arithmetic and standard projective or affine curve formulas. A 384-bit modular multiplication implemented by shift/add with one bit per byte uses fewer than 2^32 scalar instructions; exponentiation uses fewer than 2^14 such multiplications for the exponents here. Polynomial convolution uses 144 base products and fewer than 256 additions per extension multiplication. G2 uses quadratic arithmetic with u^2=-1. An affine inverse uses binary powering by p-2; a scalar multiplication has at most 510 additions/doublings.
