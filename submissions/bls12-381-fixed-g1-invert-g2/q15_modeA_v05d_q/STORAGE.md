# Storage and Addressing

Every object is partitioned into abstract 64-bit owner address spaces (`< 2^64` bytes = `16.00 EiB` per owner) with every cross-owner byte transfer explicitly priced in `KERNELS.md`. *(Hardware modeling caveat: physical ARMv8.0-A MMUs cap VA/PA at 48 bits [52-bit from ARMv8.2-A]; direct `ldrh`/`strh` addressing over `4.09–8.50 EiB` owners operates under the abstract 64-bit flat-RAM instruction-count model of this benchmark.)*

## 1. Relation Collection (`Arch2-Prod-ZeroSlice-Buf64K-B2-U32-Orb1b`, Pure Product `qa <= s_c R2_a` & `qb <= R2_b`, `W_tile = 448 = 7 * 64`, `W_SB = 16`, `P_min = 2^32`, `P_m4s = 2^50.5`, `P_m4 = 2^52.0`, `P_1bs = 2^55.5`, `P_lo = P_f = 2^58.0`, `P_g = 2^63.5`)

- **Canonical `a` packing & exact `2^56` power-of-2 bank stride (`K_a = 1`, `W_SB = 16`, `rec = 64b` with 2 zero guard bits `58..59`):** Continuous 8D ellipsoid volume (`A^2 = 320,500, r_ab = 0.83`) gives `V_a = 2^55.8564 < 0.91 * 2^56` canonical `a`-orbits; `N_a^tbl = 4 V_a = 2^57.8564`. Canonical `a`-entries are partitioned into `3` contiguous static 2-adic classes `c(a) in {0, 1, 2}` with ONE constant `g`-side threshold `T_g[c] = (299, 287, 275)` bits (ZERO `Q_CM(a)` radial shells, ZERO `bgo` norm predictor).
- **Column-slab owner RAM (`28` independent slab owners, `2^63.087 B < 2^64 B` each):** Each of `28` slab owners owns `16` consecutive columns and allocates `uint16_t S_g[16][4][2^56]` (`8.00 EiB`) + single-column `uint16_t S_f[4][1][2^56]` (`0.50 EiB`) + `64 KiB` Band-2 receive buffer = **`2^63.087 B = 8.50 EiB < 16.00 EiB`** (plus two `64 KiB`-aligned discard sinks `sink_lo = x_tx_tbl[-1]` and `sink_hi = x_tx_tbl[28]`).
- **Sequential `w_lp`-Ordered `64 KiB`-Buffered `8 B` Band-2 (`1` Prime Orbit per Build/Replay Owner, `~2^56.05` Owners -> `28` Slab Owners):** Each Band-2 `g`-side prime orbit owns its own dedicated build/replay owner (`<= 14.950 EiB` peak build `2^63.901 B`, `<= 7.475 EiB` max resident `2^62.901 B` + `416 B` row-step state, ZERO cross-owner build transfers). Each row runs `rev_b2_row_k0_step4` (`33/4 = 8.25` Ir/prime/row + `<= 1.354` outer-chord reset `<= 9.65` Ir/prime/row) into `rev_sb_probe_fast` (`22 <= 23.0`) + rolling-cursor `rev_b2_direct_sb_hdr` (`<= 10.0`) + symmetric `10`-op `bfi` `rev_b2_emit_c0/c1` writing `8 B` `x4` records (`8,192 = 256 * 32` records per `64 KiB` buffer) + `rev_b1a_apply_u32` (`3.5625` Ir/hit, ZERO tail on full drains) + `0.002` flush = `13.565 <= 13.60` Ir/hit + `23 * 28 = 644` `w_lp`-class partial drains/row.
- **1-Prime-Per-Owner Local Flat-Array Build (`<= 2^63.901 B < 2^64 B` peak build):** Band-1a `<= 14.950 EiB`, Band-1b `<= 7.667 EiB`, Band-2 `<= 14.950 EiB` peak / `<= 7.475 EiB` resident; total replay `a`-table storage **`2^118.320 B < 2^120 B`**.
- **Distributed `2,048`-Owner Product Trees (`P_f = 2^70.79` + `P_g = 2^71.19` + Retained `g`-Batch Candidate Tree):** Partitioned across `2,048` 64-bit owners at **`0.1932 * 2^64 B = 3.091 EiB << 16.00 EiB`** per owner, with ALL THREE `L - 11` local subtrees `<= 1.053 EiB < 2^62 B` asserted live in `audit_cm.py`.

## 2. Linear Algebra Storage — Complete Owner Map Across ALL Phases (All `< 2^64 B = 16.00 EiB`, Conservative `2.52x`-Headroom `nl_cap = 0.00125`, `sw_cap = 0.00225`, `nonunit_ub = 0.11`, `W_max = 4,096` Guard)

  - **Purge (`2,048` hash-partitioned owners, `<= 6.008 EiB <= 8.0 EiB < 16.00 EiB` each):** Bounded at `<= 40` raw incidences * `16 B` + `128 B` SM + `64 B` header times `1.25x` load factor `= 1,040 B/rel` across deterministically capped `N_rels <= n_rels_upper = 2^63.565` -> **`2^62.587 B = 6.008 EiB`** per owner (asserted live).
