## Actual algorithm and one heuristic

Validate the protected full-production inputs and compute h=e(P,Q0) with the pinned pairing(Q0,P),standard profile Q0,and supplied nonidentity P. Nondegeneracy and prime order make h generate GT for every such P. For z=1 return infinity. Otherwise z=h^a uniquely for a in[0,r). The answer is a G2 point Q=[a]Q0 for this exact P,never just a scalar or a substituted pairing input.

Use the16-byte ASCII tags FAPI-RHO-INIT-v1,FAPI-RHO-SCAL-v1,FAPI-RHO-WALK-v1,called INIT,SCAL,WALK. Encode P as its canonical two48-byte coordinates and input z as its twelve canonical48-byte polynomial coefficients. Compute seed=SHA256(INIT||P_bytes||z_bytes). There are no external random coins or uncharged entropy service. The actual implementation is deterministic on its uniform challenge and computes every hash as scalar code.

Initialize w=65536 jump pairs(u_j,v_j). A scalar candidate is the lower255 bits of SHA256(SCAL||seed||counter_be64),with a globally increasing counter. Accept if<r,with at most1024 trials per scalar. If any sampler exhausts its limit return failure/infinity. Store M_j=h^u_j*z^v_j and the coefficients. Finally generate alpha0 by the same method and start state(X,A,B)=(h^alpha0,alpha0,0). The scalar count is2w+1=131073;the counter never reaches2^28 and fits the stated eight bytes.

Each step selects j as the low16 bits of SHA256(WALK||seed||X_bytes),then updates X<-X*M_j,A<-A+u_j mod r,B<-B+v_j mod r. X_bytes is the injective289-byte norm-one encoding proved in compression-proof.md:the six canonical Montgomery coefficients of b in X=a+bw,and one lexicographic sign bit of a. It depends on the group element alone,not its coefficient history. The walk message is337 bytes. Full576-byte state storage and equality checks remain. Thus the step is a deterministic function on GT and preserves X=h^A*z^B.

Initialize slow and fast to the same state. For t=1,...,L, R=ceil(sqrt(r)), L=ceil(24R/5),advance slow once and fast twice and compare all twelve canonical coefficients. At a match compute D=B_fast-B_slow mod r. If D=0 return failure;else a=(A_slow-A_fast)/D mod r. Verify h^a=z,construct[a]Q0,check subgroup and exact pinned pairing equality,encode and return Q. If no meeting occurs by L return infinity. There are no restarts,parallel processors,large visited-state tables,or amortization over future targets. All failure paths consume a bounded,fully charged budget.

The sole computational heuristic H is that,for average-case success over the protected independently uniform P and z,the domain-separated actual SHA-256 computations can be analyzed as independent random functions on their distinct input domains. This is the familiar hash idealization used for rho partitions and initialization,not an actual supplied oracle. Actual hashes are fully computed and charged. H is unproved for fixed SHA at this enormous scale and may fail;no unconditional fixed-SHA success theorem is asserted. In particular we do not assume the adding walk itself is a uniform random mapping or assume an unproved mean-collision bound. The finite proof below handles its correlations.

## Finite success argument

collision-proof.md is part of this claim. Under H,initialization rejection produces independent uniform residues modulo r. Since r>2^254,a255-bit candidate is accepted with probability>1/2. Across131073 scalars,the probability of any1024-attempt failure is below2^-1000. The jump group elements are independent uniform GT values,including possible duplicates. A Hoeffding/character union bound gives probability below2^-5000 that any nontrivial Cayley eigenvalue has modulus>1/2. The algorithm need not identify or verify a good table and charges all tables' work.

On a good table,Fourier inversion and Parseval bound the d-step transition error in both sup and unweighted l2 norm by2^-d. A second-moment calculation over all collision intervals of length at least271 proves probability>132/330=0.4 of a repeat by L=ceil(24ceil(sqrt(r))/5). It explicitly includes nested/crossing interval correlations. Coupling to independent-index transitions is used only until the first repeat. Floyd then meets no later than that repeat index for the actual deterministic map.

Condition on the jump group values,partition and starting group value. Each v_j stays independent uniform because for a fixed M_j=h^u_j*z^v_j and z=h^a,every v_j fixes exactly one u_j. At a meeting t<=L<r,the coefficient difference D is a linear form in v_j with nonnegative jump-count coefficients summing to t. Some count is nonzero mod the prime r,so D is uniform and zero with probability1/r. Otherwise the recovered exponent and returned point solve the original input exactly. This proof does not add a separate uniform-collision-relation heuristic and does not use an automorphism/negation map.

Subtracting sampling,bad-table and singular-denominator failures from0.4 leaves ideal-hash success>0.399. The declared success lower bound is the more conservative0.395,conditional only on H's bridge to actual SHA on uniform challenges. Identity targets succeed deterministically. These are algorithmic probabilities,not reviewer confidence or measured production success. The optional small-field experiment checks recurrence/recovery and public numerical inequalities,not the truth of H for BLS12-381.
