# Deterministic fixed checkpoint detection

For any deterministic map on a finite set, let trajectory X_0,X_1,... have tail length mu and cycle length lambda>=1. Its first repeat index is tau=mu+lambda. Suppose tau<=L. Then mu<=L-1, so the saved checkpoint X_(L-1) lies in the cycle. Since lambda<=L, the L following comparisons include X_(L-1+lambda)=X_(L-1). Hence equality is detected by index2L-1. The algorithm does not need to know mu or lambda, find the cycle entry, or inspect a visited dictionary. It computes L-1 transitions, copies one state, and compares the next L states. Each of its at most2L-1 steps is paid for at the full scalar allowance, even when no comparison is required.

If d is the positive number of steps since the saved checkpoint at an equality, then1<=d<=L<r. The coefficient difference is the sum of jump coefficient vectors on that contiguous trajectory segment. Conditional on all jump group values, initialization group value and partition, the v_j are independent uniform residues. The jump counts n_j are nonnegative and sum to d, so at least one n_j is nonzero modulo prime r. Consequently D=sum n_j*v_j is uniform modulo r, including conditional on the detection event. If D=0 the algorithm fails, with probability1/r; otherwise invariant equality gives the unique target exponent. This is exactly the inherited conditional coefficient argument, applied to the new fixed saved index rather than power-of-two checkpoints. It needs no extra randomness or relation-recovery oracle.

Memory contains the jump table, current state and saved state. No restarts, extra tail finding, or second search phase occurs. Failed runs still execute no more than the charged K transitions. Boundary cases mu=0,lambda=1,tau=L and lambda=L all satisfy the same lemma.
