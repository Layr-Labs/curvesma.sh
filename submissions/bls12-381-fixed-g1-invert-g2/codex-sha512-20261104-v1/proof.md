# Large-table rho with a finite ideal-hash collision bound: 129.9

This cold classical attack claims total computation below2^(1299/10)=2^129.9 dense-Fp12 reference equivalents at fixed C=20000,success at least0.395 under the sole disclosed SHA-512 random-function heuristic,peak storage below2^35 bytes,and zero nonuniform advice. Preprocessing below2^(1299/10) equivalents is included. The computation bound is deterministic even if the heuristic fails. The probability argument is rigorous inside the ideal-hash model and is given in collision-proof.md; fixed SHA is not mathematically certified by that model. This is an exploratory heuristic claim,not a practical break or production execution.

## Actual algorithm and one heuristic

Validate the protected full-production inputs and compute h=e(P,Q0) with the pinned pairing(Q0,P),standard profile Q0,and supplied nonidentity P. Nondegeneracy and prime order make h generate GT for every such P. For z=1 return infinity. Otherwise z=h^a uniquely for a in[0,r). The answer is a G2 point Q=[a]Q0 for this exact P,never just a scalar or a substituted pairing input.

Use the16-byte ASCII tags FAPI-RHO-INIT-v1,FAPI-RHO-SCAL-v1,FAPI-RHO-WALK-v1,called INIT,SCAL,WALK. Encode P as its canonical two48-byte coordinates and input z as its twelve canonical48-byte polynomial coefficients. Compute the64-byte seed=SHA512(INIT||P_bytes||z_bytes). There are no external random coins or uncharged entropy service. The actual implementation is deterministic on its uniform challenge and computes every hash as scalar code.

Initialize w=16777216 jump pairs(u_j,v_j). A scalar candidate is the lower255 bits of SHA512(SCAL||seed||counter_be64),with a globally increasing counter. Accept if<r,with at most1024 trials per scalar. If any sampler exhausts its limit return failure/infinity. Store M_j=h^u_j*z^v_j and the coefficients. Finally generate alpha0 by the same method and start state(X,A,B)=(h^alpha0,alpha0,0). The scalar count is2w+1=33554433;the counter never reaches2^36 and fits the stated eight bytes.

Each step selects j as the low24 bits of SHA512(WALK||seed||zero48||X_bytes),then updates X<-X*M_j,A<-A+u_j mod r,B<-B+v_j mod r. X_bytes is the injective289-byte norm-one encoding proved in compression-proof.md:the six canonical Montgomery coefficients of b in X=a+bw,and one lexicographic sign bit of a. It depends on the group element alone,not its coefficient history. Here zero48 is exactly48 zero bytes. The417-byte walk message begins with a fixed128-byte prefix; its first SHA-512 compression block is computed once in setup, and only the remaining three padded blocks are computed per transition, preserving the standard SHA-512 output exactly. See prefix-audit.md. Full576-byte state storage and equality checks remain. Thus the step is a deterministic function on GT and preserves X=h^A*z^B.

Use eight equally spaced checkpoint intervals. Set R=ceil(sqrt(r)), L=ceil(119R/100), s=ceil(L/8), and K=L+s. Initialize current=(h^alpha0,alpha0,0), save it in checkpoint slot0, and set the next saving index to s. For each index t=1,...,K, advance current once. Compare its full group element against every valid saved checkpoint, in increasing checkpoint index order. On the first equality use that checkpoint's complete coefficient state: D=B_current-B_checkpoint mod r. If D=0 return failure. Otherwise recover a=(A_checkpoint-A_current)/D mod r, verify h^a=z, construct[a]Q0, verify subgroup and exact pinned pairing equality, and return that G2 point. If no equality and t is one of s,2s,...,8s, save current in the corresponding slot. Never compare a state with a checkpoint saved at that same index. At K without a valid relation return failure/infinity. Only9 checkpoint slots exist, including index0. All transitions, comparisons, copies, failures and finishing work are charged. checkpoint-proof.md proves detection and conditional relation recovery.

The sole computational heuristic H is that,for average-case success over the protected independently uniform P and z,the domain-separated actual SHA-512 computations can be analyzed as independent random functions on their distinct input domains. This is the familiar hash idealization used for rho partitions and initialization,not an actual supplied oracle. Actual hashes are fully computed and charged. H is unproved for fixed SHA at this enormous scale and may fail;no unconditional fixed-SHA success theorem is asserted. In particular we do not assume the adding walk itself is a uniform random mapping or assume an unproved mean-collision bound. The finite proof below handles its correlations.

Relevant context: Bos et al.,section3.1/Table1,describe adding walks and scalar recovery,and report32-adding means close to their birthday heuristic on sampled32-bit groups. They warn that the original squaring-walk proof does not automatically transfer to adding walks. We do not import a255-bit running-time guarantee from those observations. Source:https://www.joppebos.com/files/noan112.pdf . The Fourier/Cayley approach is standard in additive-rho analyses,including Bos,Dudeanu,Jetchev:https://eprint.iacr.org/2012/087.pdf ;their asymptotic bounds are not used as the finite constants here. ## Finite success argument

collision-proof.md is part of this claim. Under H,initialization rejection produces independent uniform residues modulo r. Since r>2^254,a255-bit candidate is accepted with probability>1/2. Across33554433 scalars,the probability of any1024-attempt failure is below2^-990. The jump group elements are independent uniform GT values,including possible duplicates. A Hoeffding/character union bound gives probability below2^-100 that any nontrivial Cayley eigenvalue has modulus>1/128. The algorithm need not identify or verify a good table and charges all tables' work.

On a good table,Fourier inversion and Parseval bound the d-step transition error in both sup and unweighted l2 norm by(1/128)^d. A second-moment calculation over all collision intervals of length at least271 proves probability>0.3995 of a repeat by L=ceil(119ceil(sqrt(r))/100). It explicitly includes nested/crossing interval correlations. Coupling to independent-index transitions is used only until the first repeat. The deterministic checkpoint lemma in checkpoint-proof.md converts a first repeat by L into a detected equality by K.

Condition on the jump group values,partition and initial group value. Every v_j remains independent uniform since each v_j fixes exactly one u_j for given M_j and z=h^a. At a checkpoint equality,the coefficient difference is a linear form in v_j whose nonnegative counts sum to the positive number d of trajectory steps since anchor. Since d<=K<r,some count is nonzero modulo r. Thus D is uniform and zero with probability1/r even conditional on the observed trajectory. No extra collision-relation heuristic is introduced. For D!=0,the maintained invariant gives the unique target exponent and the verified G2 output solves the supplied-P input exactly.

Subtracting sampling,bad-table and singular-denominator failures from0.3995 leaves ideal-hash success>0.399. The declared success lower bound is the more conservative0.395,conditional only on H's bridge to actual SHA on uniform challenges. Identity targets succeed deterministically. These are algorithmic probabilities,not reviewer confidence or measured production success. This submission is analytic and declares no executable experiments.
