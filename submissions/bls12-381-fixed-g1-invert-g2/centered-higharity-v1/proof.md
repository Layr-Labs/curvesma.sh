## Exact half-trace key and local cost

Use the native reference tower Fp2=Fp[u]/(u^2+1), Fp6=Fp2[v]/(v^3-u-1), Fp12=Fp6[w]/(w^2-v). Every element has a unique X=A+B*w with A,B in Fp6. The nontrivial Fp6 automorphism is bar(X)=A-B*w and equals p^6-Frobenius. The protected p,r satisfy p^6=-1 modulo r. Thus every GT element has bar(X)=X^(-1), including identity, and X*bar(X)=A^2-v*B^2=1.

Define the exact key J(X)=A, the first Fp6 half of the native representation. There is no need to compute a trace, negate B, select a sign or multiply by 2: A is already stored as six canonical base-field coordinates (36 words). It is half the trace, since X+bar(X)=2A. Copying this half needs at most 16*36+128=704 scalar instructions; reserve 1024, including initialized output bookkeeping. Preserve the entire raw X separately in local scratch for the dense update.

The fibers of J on GT are exactly {X,X^(-1)}. To prove this, suppose X=A+B*w and Y=A+C*w share J. Both have norm 1, so v*B^2=v*C^2. As v is nonzero and Fp6 is a field of odd characteristic, (B-C)(B+C)=0 implies C=B or C=-B. Hence Y=X or Y=bar(X)=X^(-1). Conversely inversion preserves A. For B=0 the two elements coincide; the proof still holds. This is an exact equality argument in the full production field, not a hash or statistical collision model. Every element generated and looked up belongs to GT because input validation establishes it and only GT operations follow.

Coordinates use canonical six-limb Montgomery residues with one fixed scale and basis. Equality of all 36 words is exactly equality of A. Multiplication remains a dense Fp12 reference operation on the full raw element. Input/output polynomial-to-tower conversion is fixed setup only. The half key does not need raw reconstruction or orientation recovery: the two scalar candidates in the centered algorithm below exhaust its proven two-element fiber.

## Partial centered algorithm and complete probability argument

Validate canonical P,z including subgroup membership and P!=infinity. If z=1, return canonical G2 infinity after exact verification. Otherwise set h=pairing(Q0,P) in the pinned G2-first calling convention. Nondegeneracy and prime subgroup order make h a generator of GT for every permitted supplied P. Conditional on any such P, the independent uniform target z has unique exponent a in [0,r), uniformly distributed. The algorithm never sees that exponent or the challenge sampling coins.

Define K=ceil(391*r/1000), t=floor(134*K/2016), m=isqrt(t)+1, S=2m-1, H=ceil(K/S). This fixes m by public integer arithmetic; it is not searched advice. For the protected r, m=36915586649293397092516781056760671371, m<2^125, H=277693368227520479621320263471751915977<2^128. The rounded K and m are also computed cold in setup. Let L=ceil(log2(m))=125.

Generate raw h^j for j=0,...,m-1 by one dense multiplication per record from identity. Store 40-word initialized records with 36 words of exact J(h^j), two words j and two zero padding words (320 bytes total). The integer K denotes only the coverage threshold; J denotes the exact Fp6 key. Preserve the raw element for the next multiplication. Keys are unique: a repeated inverse-orbit key requires j=k or j+k=0 modulo r; because 0<=j,k<m<r/2 only j=k=0 permits the second relation.

Sort with two arrays and 125 bottom-up merge passes. The non-power-of-two last run is copied as an incomplete run; each pass still has at most m comparisons and at most 2m moves. Run endpoints use exact three-limb arithmetic; clipped right endpoints are min(start+width,m). No uninitialized padding record is ever read.

Set c_i=m-1+iS, gamma=z*h^(-(m-1)), D=h^(-S). For i=0,...,H-1, binary-search J(gamma). On a match j, test x=(c_i+j) mod r and x=(c_i-j) mod r against h^x=z. For a verified x, construct Q=[x]Q0, check the G2 curve and subgroup, verify pairing(Q,P)=z for the exact supplied P and serialize. Otherwise update gamma=gamma*D. If all H searches end with no match, report algorithmic failure; this is explicitly permitted by the success-probability claim. It is not silently retried, amplified or amortized. All failures consume at most the stated worst-case budget.

For fixed i, exponents c_i+-j with 0<=j<m are exactly every integer in [iS,(i+1)S-1]. Thus the H adjacent blocks cover [0,HS-1], with no holes. Exact protected-integer checks give K<=HS<r, so there is no wraparound in the covered interval. For every a there, gamma=h^(+-j) at its block and its exact inverse-orbit key matches; one tested scalar is correct. For any verified match, bilinearity proves the required supplied-P pairing equation. Returning infinity for a=0 is included in this coverage. Hence for each P separately, success is at least HS/r >=K/r >=391/1000>0.39. Averaging over the uniform nonidentity P preserves this lower bound. There are no random coins, so no unproved ideal randomness assumption. Reviewer confidence is unrelated to this algorithmic success probability.

Targets outside the interval may fail and are not claimed solved. Every such failure is charged H iterations. Only the target exponent is restricted in the success analysis; the challenge distribution remains independently uniform over the full production GT, and the algorithm receives no special-format input.

## Finite five-level storage and transfer convention

The computation remains finite and analytic. It does not allocate the production attack's exponential storage on this VM. A logical address has three 64-bit limbs; no scalar instruction holds a 138-bit physical address. All processor work is summed. There is no elapsed-time, physical-distance or energy objective. The material storage assumption remains a word/message graph with bounded scalar work to transmit a word over a selected local link. This assumption must be judged, not silently treated as a real deployment demonstration.

Use 2^108 leaves, each with up to 2^30 data bytes addressed by an ordinary local offset, plus bounded code/message scratch. Number leaves by 108 bits. Split their ID into a 12-bit initial digit followed by four 24-bit digits. A root with 2^12 children, followed by four levels of fanout 2^24, routes every address in exactly five hops. Level sizes are 1,2^12,2^36,2^60,2^84,2^108; total nodes <2^109. The graph is a tree, not a free dictionary or remote-address instruction.

Each internal node stores an actual 32-byte descriptor for every child. The descriptor contains a three-limb child ID and one word of local port/control data. At most 2^24 descriptors occupy 2^29 bytes, so the entire child table fits within a 1-GiB local bank with ordinary scalar addressing. The root table is smaller. Extract the appropriate 24-bit or 12-bit digit, shift it left five bits for the descriptor byte offset, load its four words and forward the packet to that link. This uses ordinary 64-bit register operations. Multiword global address decoding, level state, port selection, local descriptor loads and per-hop control fit the charged word-message envelope below; there is no uncharged lookup oracle. Child descriptors are structurally enumerated in cold preprocessing, not searched advice.

The graph has fewer than 2^109 links/descriptors, occupying <2^114 bytes. Code and local scratch are bounded by 2^20 bytes per node (<2^129 in total). Even provisioning the entire 2^30-byte data capacity of every leaf costs 2^138 bytes; with descriptors, code and coordinator state the total is <2^139 and thus below the submitted 2^145 bound. All of this is counted even though the arrays actually occupy <640*2^125<2^135 bytes. This explicitly avoids treating high fanout as free storage.

A 40-word record plus 16-word header has at most 56 words. Charge 16 scalar instructions per word per hop, including data loads/stores, local port and descriptor selection, route/control, buffer clearing and acknowledgments. A 16-word header supplies a 256-instruction envelope per hop; extracting one digit, calculating its 29-bit offset, loading four descriptor words and ordinary bounded route-state control fit well below 128. The data-word envelopes separately pay every transferred word. Links and their descriptors are initialized cold below.

A complete record read and write use two header paths and two record paths. At depth five their summed cost is 2*5*(16*16+56*16)=11520 instructions. Endpoint copying a 40-word record costs <=768, and local three-limb address/frame/operation control <=1024; reserve 2048 total. Hence a record move costs <=13568<16384=T=2^14. Reading two remote records to the root for a comparison has the same path cost; a complete 36-word comparison costs <=704 and endpoint control <=1024, also within the 2048 reserve and T. No early comparison exit is needed.

For a root-resident giant query, send at most 56 words down, compare all 36 key words at the leaf and return at most 17 words for result plus header. This is 5*(56*16+17*16)=5840 path instructions, plus 2048 endpoint work =7888<8192=B=2^13. Sorting is not charged this cheaper rate when both operands are remote. A successful match retrieves the scalar index separately within the giant budget. Canonical key extraction and preserving the full raw GT state remain locally charged; only keys and records cross links.

All packets, including failures, padding and losing comparisons, are paid. The wider fanout changes local graph topology, not the target or the primitive instruction price. If the normative machine forbids the finite indexed-neighbor message model, this is a material objection and the claim should be rejected rather than silently granting a wide global load. There is no claim that 2^24 physical ports per controller have been engineered on the current VM. The allowance is analytical scalar work, as in the earlier binary model, with all static graph state and setup now enumerated explicitly.

## Setup, representation, output, bank construction

Charge 2^100 scalar instructions for all fixed-size field conversions, canonical encoding validation, P and z subgroup tests, the initial pairing h, stride inversion, final scalar multiplication in G2, output subgroup test, final pairing and serialization, as well as code and constant construction. This extremely conservative bound is justified by elementary bit arithmetic: at most 381-bit base residues, at most 4572-bit field exponents, 12-coefficient polynomial arithmetic and standard projective or affine curve formulas. A 384-bit modular multiplication implemented by shift/add with one bit per byte uses fewer than 2^32 scalar instructions; exponentiation uses fewer than 2^14 such multiplications for the exponents here. Polynomial convolution uses 144 base products and fewer than 256 additions per extension multiplication. G2 uses quadratic arithmetic with u^2=-1. An affine inverse uses binary powering by p-2; a scalar multiplication has at most 510 additions/doublings. A Miller pairing has fewer than 128 loop iterations, each expressible with fewer than 2^16 base/extension operations, and final exponentiation fewer than 2^14 extension multiplications. Even multiplying all these loose upper bounds is below 2^100. Exceptional curve additions test infinity, opposite points and zero doubling denominator before division. These are fixed bounded computations, not exponentially repeated setup hidden under an asymptotic symbol.

For cold memory construction, explicitly zero every leaf's full 2^30-byte data capacity, not merely the used arrays. The 2^138 bytes contain 2^135 words, each initialized with at most 32 scalar instructions, for <=2^140 instructions. Every one of <2^109 nodes receives at most 2^20 instructions for code, local message/scratch initialization and control, totaling <2^129. Every child descriptor is written by structural enumeration with <=2^12 instructions, including multiword IDs, local indices and link setup; <2^109 descriptors therefore cost <2^121 instructions. These three terms sum to <2^141, the exact initialization term in N. Nothing is amortized across targets or treated as a free high-fanout fabric.

All fixed-size setup and final checks fit 2^100 scalar instructions as derived above. Peak storage, including full unused leaf capacity, is <2^139 bytes, so memory_log2_bytes=145 remains a safe declared bound. Every table and graph is built cold. Nonuniform advice is zero bytes. Preprocessing is a subset of N/20000, hence preprocessing_log2=134.625 is a valid inclusive upper bound. The submitted score is the unchanged rational 1077/8, not a request for automatic tightening.
