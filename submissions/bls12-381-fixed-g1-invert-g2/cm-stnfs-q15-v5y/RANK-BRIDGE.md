# Finite Relation Rank (`H-R`), Concrete Schirokauer Compression, and Padded Block Wiedemann (`H-X`)

This document separates finite-instance relation rank (`H-R`), concrete production Schirokauer compression (`W_f, W_g`), and Block Wiedemann controllability/observability (`H-X`) for the fixed BLS12-381 `Z[zeta_12]` product-form system (`D = N + 4`, `s_sm = 4`).

## 1. Concrete Production Schirokauer Compression (`W_f`, `W_g`) & `H-R`

- **Concrete data-oblivious Schirokauer columns (`<= 4/r < 2^(-252)` union-bound failure):** The `chi`-projected Schirokauer maps `P_chi Lambda_f` and `P_chi Lambda_g` have ambient `F_r`-dimensions `6` (on `K_f`) and `2` (on `K_g`), containing the `chi`-unit images of dimensions `3` and `1` respectively. At the start of the run (fresh run coins, **before** collection), draw uniform random `3 x 6` `W_f` and `1 x 2` `W_g` over `F_r` (and `n - 4 = 106` random columns `Z` in §2) via bounded-retry rejection sampling on **`255`-bit words** (`0..2^255 - 1`, since `r < 2^255` with `1 - r/2^255 = 0.0942 < 0.10`) capped at **`K_rej = 64` draws/entry**: per-entry failure is `(1 - r/2^255)^64 < 2^(-218)`, so the union bound across all `20 + 106 (N_cap + 4) < 2^62` entries of `(W_f, W_g, Z)` is **`p_rej_fr < 2^(-156) << 2^(-80)`** (computed directly from `r, K_rej = 64, N_cap` in 80-digit `Decimal` inside `audit_cm.py`, included explicitly in `fail_core`, and exercised live via capped `bit_length()` rejection sampling in `toy_e2e_dlp` & `unplanted_two_sided_bw`). The `4` production Schirokauer columns of `S` are **`W_f (P_chi Lambda_f)` (`3` cols)** and **`W_g (P_chi Lambda_g)` (`1` col)**. Under `H-SM` (`P_chi Lambda_f, P_chi Lambda_g` injective on the 3D/1D `chi`-unit images), failure of `(W_f, W_g)` to preserve injectivity on those subspaces is `<= (1 - (1 - r^(-1))(1 - r^(-2))(1 - r^(-3))) + 1/r < 4/r < 2^(-252)` (explicitly included in Section 6's 80-digit union bound; verified live with pre-collection random `W_f, W_g` in `audit_cm.py`: `toy_e2e_dlp`).
- **`H-R` (Finite Relation Spanning — Declared Fixed-Instance Premise):** Collection's region, polynomials, and public ECM seed are challenge- and coin-independent, so the collected, `tau`-quotiented, and filtered relation matrix `A = [M | S]` over `F_r` (`D = N + 4` live rows, `N = N_l` live orbit columns, `4` compressed Schirokauer columns) is fixed given `(W_f, W_g)`. **`H-R`** assumes for this actual finite matrix that **`rank(M) = N`** and **`rank(A) = D - 1`**, so `ker(A)` is the one-dimensional line spanned by the virtual-log vector `(w, c)` with `c != 0`. Counting smooth relations, `r !| h(K_f), h(K_g)`, and Schirokauer injectivity do **not** prove `H-R`; if `H-R` fails, randomized Block Wiedemann cannot supply missing relations (final verification detects failure).

## 2. `H-X` (Finite Block Controllability & Observability) and Conditional Schwartz-Zippel

Let `B = [M | 0]` (`D x D`), so `Im(B) = Im(M)` has dimension `N` and `V = Im(B) + span(S)` has dimension `D - 1` under `H-R`. Form `Y = [S_1, ..., S_4, B Z]` with `n - 4 = 106` independent random columns `Z` over `F_r`. Fix the coordinate partition publicly before sampling weights: the `4` pad coordinates occupy `4` distinct projection blocks of `X`, and the `N` non-pad coordinates are partitioned into `m = 8192` balanced blocks; each coordinate gets one independent uniform `>= 2^128`-support entry on its assigned block (`0` elsewhere).

**`H-X` (declared premise):** At the finite block lengths `d = ceil(D/n) + 1 + ceil(D/(128 n))` and `e = ceil(D/m) + 1 + ceil(D/(128 m))` used by the solver, two specific minors are nonzero polynomials:
1. An `N x N` minor of `C_d = [B Z, B Y, B^2 Y, ..., B^d Y]` (degree `<= N` in `Z`), and
2. A `(D - 1) x (D - 1)` minor of `O_e U`, where `O_e` stacks `X^T, X^T B, ..., X^T B^(e-1)` and `U` is a fixed basis of `V` determined solely by `A` (degree `<= D - 1 = N + 3` in `X`).

**Conditional Schwartz-Zippel theorem (proved given `H-R` and `H-X`):** The product of these two nonzero minors has total degree `<= 2 N + 3 < 4 N`. Sampling independent entries uniformly from supports of size `>= 2^128` yields simultaneous control/observation failure **`<= 4 N_cap / 2^128 < 2^(-66)`**, strictly **conditional on `H-R` and `H-X`** (not a probability that `H-R` or `H-X` hold).
