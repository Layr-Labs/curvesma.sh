# Argument: fixed-G1 pairing inversion at 2^125.79 (windowless)

Package `gt-rho-stationary-40pct-v10f`, revision v10f of the Recover-Q line on
`bls12-381-fixed-g1-invert-g2`. Every number below is regenerated by
`verify_certificate.py` from the shipped raw evidence JSONs (`c-*.json` census,
`d-*.json` faithful sweep, `a-*.json` audits, `v10e-model.json`) and from the exact

## 1. Reduction

P is a fixed nonidentity point of BLS12-381 G1 of prime order r; z is uniform in the
order-r subgroup of GT. With g = e(P,Q0) a generator by non-degeneracy, z = g^a for a
unique a mod r, and Q = [a]Q0 gives e(P,Q) = z by bilinearity. `part_a.py` checks the
algebra on the real curve with a planted pairing instance (24 checks, all PASS).

## 2. Step, fold, selector, and the absence of an escape

The walk runs on the N = (r-1)/12 = 2^251.2721269 Frobenius classes. Step mixture
f = 3/8 squarings, 5/8 dense multiplies, selected by routing bits of the class key.

Three-multiply selector (verified, not assumed): `gamma = g0*(1-u)`, so
`d = gamma0*a + gamma1*b = g0*(a-b)` is one multiply and the twelve keys cost three;
`part_a.py` asserts `gamma1 = -gamma0`, `g0^6 = -1/8`, `zeta = 2 g0^2` and the
three-multiply form on 200 random pairs.

**No window, no checkpoint, no escape.** v10b's 24-key window is deleted with its
130-instruction row: b68a086c voided it (confounded A/B, and a per-trail history
window breaks coalescence — two trails at a common class carry different windows and
diverge, which is the merging lemma the model needs). The step is now a stationary
function of the class key alone, so equal class implies equal next class for ever;
`routing.py` has no checkpoint field and `constants.WINDOW = 0`, asserted in cert.

## 4. Success model at production

One DP store, T = 4 continuous trails of w = max(S/4, 8 theta) = 2^123.81064 steps;
a trail walks its whole length (no restart at a report), and a repeat of a stored
class with different labels is the merge. Coalescence is a property of the orbits,
not of the records, so the birthday term is

    Lambda = 4*C(w,2)/N + C(4,2)*w^2/N = 8w^2/N = S^2/(2N) = 0.6369029082

| term | value | why |
| --- | ---: | --- |
| Lambda = S^2/(2N) | 0.6369029082 | self (4 trails) + cross (6 pairs) coalescence |
| P(exists coalescence) = 1-e^-Lambda | 0.4710720 | birthday over positions; exact bound Lambda - Lambda^2/2 >= 0.4340802 |
| P(DP in shared suffix) = 1-e^-(E[L]/theta) | >= 1-2^-42 | E[L] = w/3 = 2^122.226 steps, /2^80 = 2^42.23 |
| P(solve given repeat) | 1 - 1/r | measured 5251/5251 in the toy, 0 degenerate denominators |
| **P(success)** | **0.4710720** | |

w/sqrt(N) = 0.2821575. The floor 0.39 is 17.21 per cent below the model (10.15 per
cent below the exact series bound): the reserve is declared, not spent. A
6,400-group measurement at this same w/sqrt(N) in the lane's predecessor instrument
returned 0.4017 with exact one-sided CP-95 floor 0.3915, so 0.39 also sits below the
measured end; that instrument was retired by b68a086c, it is not shipped here, and it
is context only — the shipped support is §5.

Cycle stranding is not an extra term at production: a trail repeats a class only at
the birthday scale, so a self-repeat *is* the self-coalescence already in Lambda, and
an identical-label repeat needs both labels to coincide (<= 12/r).

**The 2^-5 cell, honestly.** Collisions are universal (1597/1600 = 0.9981) and
recovery is 547 against 564 collisions whose shared suffix carries a DP: the gap is 17
stored-label coincidences. The closed form misses that cell (1.0000 against 0.3419)
and fits 2^-7..2^-11 (1.0000 against 0.95-0.996). A channel explains it: self-merges
are exactly absent at 2^-5 (0 against 4,905 / 4,813 / 1,364 at 2^-7/9/11), because a
4.7-report trail at N = 785 never revisits a stored class, so all of its recovery is
cross-trail and detection-limited. That channel is worth nothing in production, where
a trail emits 2^45.81 reports, 2^45.6 times the toy's DP count: 2^-5 is the toy's
regime boundary, not a statement about production.

**Regime declaration.** The toy never sits at production's point: toy w/sqrt(N) =
2.286 against 0.2822, and 4.7-12.6 reports per trail against 2^45.81. What transports
is the event chain (coalescence -> DP on the shared class -> report -> solve), which
the toy exercises end to end; what does not is its absolute collision level, so no toy
success number is quoted as the production floor.

## 6. Storage, cap, and the non-step work

Records are 96 bytes: 32-byte class key plus two full 32-byte exponent limbs (v10b's
48-byte record's two 8-byte limbs cannot carry a 255-bit (a,b)). Expected reports S/theta = 2^45.81, so at most 2^46.0 records =
2^52.6 bytes; cap (11/10) S theta + 2^25 with refusal on overflow and a Chernoff
debit of 1e-20; the table is 2^14 x 12 dense cells. Peak memory below 2^53 bytes,
reported, unscored.

Non-step rows, exact, each below 2^-60 of W_stress: table build 2^17.585,
trail starts 2^2.000, report writes 2^38.693, exponent solve 2^9.000, verification
2^9.000. Nothing is amortised over processors.

## 7. Scope

No production run and no unconditional theorem is claimed; the model is conditional
on three disclosed hypotheses — the class walk is a random map to within the 10 per
cent allowance already in the budget, the routing fields are pseudorandom, the coins
are ideal. The toy is a real-tower toy at N <= 50,178, not production.
