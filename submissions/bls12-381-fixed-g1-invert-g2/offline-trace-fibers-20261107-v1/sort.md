# Deterministic radix work and explicit finite storage

Record layout is256 bytes:S192@0,beta32@192,U20@224,zero12@244. Every field and padding byte is initialized before writing. Two buffers reserve2^127 records each;L<2^127. Sort U as any fixed unsigned160-bit order. Native little-endian16-bit digits at U offsets0,2,...18 are processed low to high. Equality groups are independent of that order's endian convention.

For EACH of ten stable radix passes:
1. Zero65536 native128-bit counts with paid stores. Scan every record and increment its digit count using two64-bit limbs.
2. Compute exact128-bit prefix sums to initialize separate next-position counters. Their sums are<=L<2^127.
3. Scan source records in order. Read its digit,fetch and increment next[digit],and scatter the ENTIRE256-byte record to that unique output position. Copy through initialized shared scratch before switching the native bank. Swap buffer roles.
This is standard stable counting radix sort;all associated S/beta/padding move with U. No sorting oracle,comparison-free memory transfer or free zeroing is assumed. Ten passes sort all160 bits and make equal fingerprints contiguous,including true and false collisions.

Per record per pass retain64 instructions for the counting scan:selector/interface<=32,digit load1,count address/128-bit load/add/store<=5,all index/loop/control/preservation fit the remainder. Retain160 for scatter:source selector32,source-to-shared256 copy16LDP/16STP=32,digit/counter address/load/increment/store<=8,destination selector32,shared-to-destination copy32,and<=24 for every argument/index/loop/control. Thus ten passes cost<=2240L. Zeroing/prefix work on ten65536-entry count arrays is finite fixed work<2^30 instructions,explicitly in coldD,not hidden per record.

Scan final records for equal-U group boundaries,retained128 instructions per record including selector,all fingerprint words/comparisons,128-bit indices/group bounds and state preservation. Singleton groups need no confirmations. Enumerate each larger group's unordered pairs. Each check costs<=512 including both selectors,query S/beta copy through shared scratch,all24 exactS word comparisons,four beta comparisons,128-bit loop/cap counters/branches and interfaces. Cap total confirmations at Q=floor(L/16),abort BEFORE an unbudgeted comparison. The possible final cap check is fixed cold work. Group call/return setup is within that512 allowance;every non-singleton group has a pair. Hence confirmations cost<=32L plus fixed work. No expensive raw reconstruction occurs on ignored repeats or fingerprint collisions.

The storage-only banked model is a material admissibility condition,not installed VM hardware. A noncacheable2^40-byte window starts at2^45;all shared code/data is below2^45,all native addresses<2^46. Select a97-bit bank via two ordinary64-bit latches and commit,using DSB/low/high/commit/DSB. All selector arithmetic,arguments,loads/stores and barriers fit the retained32. No flat137-bit pointer,search/compute/DMA oracle or atomic128 memory operation is used.

Shifts/masks/subtractions use two native64-bit limbs;every offset/base is encodable. The count/next arrays are shared:2*65536*16=2^21 bytes,so accesses use ordinary64-bit pointers and digit<<4 addressing. All scratch/code/constants/controllers are initialized and every bank pointer consumed before a switch.
