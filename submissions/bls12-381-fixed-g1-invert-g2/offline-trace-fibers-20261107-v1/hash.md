# Actual standard hashes and exact-confirmed NH160

Premise H is material and explicit:for average uniform protected challenges,the named actual full standard unkeyed BLAKE3-256 domain calls behave as independent uniform outputs at this algorithm's full query scale. This is a cryptographic heuristic supported by the full standard seven-round construction/domain separation,not a fixed-function theorem. All actual evaluations are computed/charged. No other random-mapping,mixing,collision-independence or uniform-denominator premise is used.

BLAKE3 compression state is CV8||IVfirst4||counter_lo||counter_hi||block_len||flags. IV=[6a09e667,bb67ae85,3c6ef372,a54ff53a,510e527f,9b05688c,1f83d9ab,5be0cd19];unkeyed initial CV=IV. G(a,b,c,d,x,y),modulo2^32,is:
a=a+b+x;d=ROR(d xor a,16);c=c+d;b=ROR(b xor c,12);a=a+b+y;d=ROR(d xor a,8);c=c+d;b=ROR(b xor c,7).
Each round uses columns(0,4,8,12),(1,5,9,13),(2,6,10,14),(3,7,11,15),then diagonals(0,5,10,15),(1,6,11,12),(2,7,8,13),(3,4,9,14),with consecutive message pairs. Apply permutation[2,6,3,10,7,0,4,13,1,11,12,5,9,14,15,8] between rounds. ALL seven rounds/56 G execute. First32 output bytes are the eight little-endian words v_i xor v_(i+8),used both as chaining CV and standard root digest. All used messages fit one1024-byte chunk,so compression counter is0. Flags CHUNK_START1,CHUNK_END2,ROOT8 give the lengths/flags below. This is the pinned primary standard:https://github.com/BLAKE3-team/BLAKE3/blob/f55849f89cd85083c1c9daa2c5de20766f309c00/reference_impl/reference_impl.rs .

A scalar implementation fits2048 instructions per ordinary64-byte compression:56 G*(14 arithmetic/rotate+2 message loads)=896,plus512 for every CV/IV/input/state/pointer/callee frame/flags/output/feed-forward/RET operation. State uses w0..w15,messages w16/w17,pointers in saved x19..x22;x18 untouched. Fixed public message offsets implement permutations without hidden runtime work. Caller message construction/arguments are charged in main640. No reduced rounds or free hash oracle is substituted.

Exact16-byte ASCII INIT,SCAL,PAIR tags are FAPI-RHO-INIT-v1,FAPI-RHO-SCAL-v1,FAPI-RHO-PAIR-v1. Seed=B3(INIT||P96||z576),with P canonical x||y each48-byte BE,z twelve canonical48-byte BE field coefficients in pinned order. SCAL message=SCAL||seed32||attempt128_BE16,len64 flags11,counter0. Interpret digest BE,take low255 bits,accept iff<actual r. Increment the global128-bit SCAL counter on EVERY attempt. Sample2W=2^93 accepted table scalars,at most1024 attempts per scalar. Since r>7*2^252,rejection<1/8 and cap failure<2^-970 by a finite union. Attempts<2^103 fit128 bits. All accepted values are independent uniform Fr in H;every rejection/hash/control/encoding is paid cold.

PAIR sample t uses PAIR||seed32||t128_BE16,len64 flags11,counter0. Increment t once per generated sample,L<2^127. Interpret digest little-endian:low92 bits choose j,next92 choose k,discard high72. Indices are exactly iid uniform under H,independent of table values and NH seeds. No rejection or key-dependent index selection exists.

For each192-byte S key,view all24 native64-bit words. Three independent NH128 lanes sum twelve products((m2i+k2i)mod2^64)*((m2i+1+k2i+1)mod2^64) modulo2^128. For every fixed unequal equal-length key pair,NH collision<=2^-64 (Black/Halevi/Krawczyk/Krovetz/Rogaway,UMAC1999,Theorem4.2,https://www.cs.ucdavis.edu/~rogaway/umac/umac_full.pdf). For each lane,independently multiply its128-bit result by a uniform odd128-bit A modulo2^128. Keep high64 bits in lanes0/1 and high32 bits in lane2;serialize BE to U20.

Compression lemma:for distinct x,y,write x-y=2^s*d with d odd. Uniform odd A makes A(x-y) uniform over all128-bit values of valuation s. Equal high b bits require circular distance from0<2^(128-b). This is impossible if s>=128-b;otherwise counting valuation-s residues in that interval gives probability<=2^(1-b). Add NH's2^-64 collision. Thus full lanes collide<=3*2^-64 and the32-bit lane<=3*2^-32. Three independent lanes yield delta<=27*2^-160. No marginal uniformity or higher-order NH independence is assumed.

Derive36 NH seed pairs and3 multipliers with39 actual full B3 calls:tag16||seed32||index64_BE8||zero8,len64 flags11,counter0. Tags are FAPI-NH-K-v1 and FAPI-NH-C-v1 each padded with four zero bytes to16. K index=3*i+lane,0<=i<12,0<=lane<3;first16 digest bytes LE give two64-bit keys. C index=lane;first16 bytes LE give128-bit A,force bit0=1. All624 seed bytes are initialized/paid cold. Each lane uses scalar MUL/UMULH plus two-limb carry accumulation. High64 compression is UMULH(lo,a0)+hi*a0+lo*a1 mod2^64 (one UMULH,two MADD);the third result is shifted32 and serialized. Entire fingerprint<=36*16+256=832 instructions;retain2048 including all loads/addresses/frames/output/RET.

The extended table/PAIR group-key sequence is independent of NH seeds. For every fixed unequal key pair,the bound delta therefore applies;linearity bounds expected false fingerprint pairs even though there may be many actual collisions. Sorting and ALL full-key confirmations handle them exactly. No fingerprint collision is accepted as key equality;the only statistical failure is the explicit work cap proved in proof.md. No ordinary bucket hash or hidden lookup oracle exists.
