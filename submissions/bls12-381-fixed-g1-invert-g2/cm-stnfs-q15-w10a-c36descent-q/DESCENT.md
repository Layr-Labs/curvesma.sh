## 1. Lattices and Reduction (`Q_CM` Bareiss Integer LLL)

- `Q_CM(a, b) = a^T G_8 a + b^T G_8 b`, where `G_8[i, j] = Tr_{Q(zeta_15)/Q}(y^{i-j})` (`8` on diagonal, `-4` if `gcd(15, i-j) = 5`, `-2` if `gcd = 3`, `1` if `gcd = 1`).
- For boot lattices, the `b`-block is scaled by `S_boot = 2^21` so `|a|^2` balances `|u|^{2/3} |b|^2` on the `g`-side norm `N_g(a, b) = |N_{Q(zeta_15)/Q}(a^3 - u w^2 b^3)|`.
- Search regions are Euclidean radius-`R` balls `B_16(R) / {+-1}` in reduced-basis coordinates (`q15_cells16.py` computes exact integer half-counts `C_R`, asserted live at `C_2 = 17,072`, `C_4 = 642,328,192`, `C_8 = 35,245,626,789,232`, and `C_256 / Vol = 1 +- 1e-4`).

## 2. Targets and Calibrated `gamma_0`-Blinded Whole-Ball Renewal Boot (`BOOT_RELS = 18`, `R_boot = 2`)

For each of the two target logarithms `z in {h = e(P, Q_0), T = e(P, Q)}`, each boot ball draws a fresh uniform blinding exponent `e in [0, r-1]` and forms `z' = z * gamma_0^e in G_T` using the calibrated Stage-1/2 factor-base blinding generator `gamma_0 := phi_iso^(-1)(a_0 - b_0 X)^(e_cof)` (`e_cof := (p^12 - 1)/r`) with known virtual log `V_0 = e_cof * V_g(a_0 - b_0 X) mod r != 0` (`RANK-BRIDGE.md` §5; `gcd(r, e_cof) == 1` asserted LIVE in `audit_cm.py`; `2/r` charged for rare `z' = 1` degeneracies plus `4/r` for Schirokauer compression -> `6/r` total).

**Exact `F_(p^12) -> F_(p^4)` boot lift deriving `(A, B)` from `z' in G_T \ {1}` and converting `V_g(a - b X)` to `V(z')`:**
Write `z' = z_0 + z_1 X + z_2 X^2` in `F_(p^12) = F_(p^4)[X]/(X^3 - u w^2)` (`F_(p^4) = F_p[y]/(h_pi(y))`). Because `p == 7 == 1 (mod 3)`, `w = y^5 in F_p` and `X^p = w^2 X`, hence `X^(p^3) = w^6 X = X` and `F_(p^6) = F_(p^2) + F_(p^2) X + F_(p^2) X^2`, where `F_(p^2) = F_p + F_p * (y + y^4)` is fixed by `sigma^2(y) = y^4 = y^(p^2)`. Solving the single linear equation
`z_2 u_0 + z_1 u_1 + z_0 u_2 = 0` in `F_(p^4)` (`4` homogeneous linear equations in `6` `F_p`-unknowns `(u_0, u_1, u_2) in F_(p^2)^3`, rank-nullity `>= 2 >= 1`, `< 2^15` Ir inside `LLL_BOOT = 2^47`)
gives a nonzero `c_6 = u_0 + u_1 X + u_2 X^2 in F_(p^6)^*` whose product `z' * c_6 = A - B X` has zero `X^2`-coefficient (`A, B in F_(p^4)`). Because `e_cof = (p^12 - 1)/r` is an exact integer multiple of BOTH `(p^4 - 1)` and `(p^6 - 1)` and `gcd(r, e_cof) = 1` (asserted LIVE on BLS12-381), `G_T cap F_(p^6) = {1}`, so `B != 0` unconditionally for every `z' in G_T \ {1}`. Setting `gamma := A * B^(-1) in F_(p^4)`, the boot lattice is
`L_boot(z') = {(a, b) in O_H^2 : a B - b A == 0 in F_(p^4)} = {(a, b) in O_H^2 : a == gamma * b (mod pi)}` (`det = p^4`, `log2(p^4) = 1522.802686`, asserted LIVE against `4 log2(P_BLS)`).
For EVERY `(a, b) in L_boot(z')` with `b != 0 (mod pi)`, `phi_pi(a - b X) = b * (gamma - X) = (b / B) * (A - B X) = (b / B) * c_6 * z'` in `F_(p^12)^*`. Raising both sides to `e_cof` annihilates `(b / B) in F_(p^4)^*` and `c_6 in F_(p^6)^*`, yielding the **exact `G_T` identity**
`phi_pi(a - b X)^(e_cof) == (z')^(e_cof)` in `G_T`,
and hence `V_g(a - b X) == V(z') == V(z) + e * V_0 (mod r)` (where `V(t) = lambda * log_g0(t^(e_cof)) mod r`). Unblinding gives `V(z) = V_g(a - b X) - e * V_0 = e_cof * lambda * log_g0(z) (mod r)`, and `x = V(T) * V(h)^(-1) mod r` cancels `e_cof * lambda` identically without `V(g_0)` or a third descent. Verified **LIVE** both on real 381-bit `BLS12-381` in `audit_cm.py` (`algebra_bls12.bls12_boot_lift_exact = True`) and end-to-end without any BSGS oracle on arbitrary `h = G_gen, T = h^47` in `w8_verifiers.py` (`e2e_boot_lift_x_recovered = 47`).

Each boot ball enumerates all `C_2 = 17,072` half-cells in `B_16(2)/{+-1}`, computes exact `g`-side norms `N_g(a, b)`, and runs the `q15_ecm16` Suyama-Montgomery schedule (`n1 = 261`, `nA = 237.25` [`iA = 336/384`], `kA = 14`, `kB = 1`, `m_max = 2589.19` bits). **Whole-ball renewal (`BOOT_RELS = 18`, `BALL_PAIR = 2^24`):** Each ball is charged in full (`LLL_BOOT = 2^47` + `17,072 * trial`); its distinct relations are descended one by one up to `BOOT_RELS = 18` total (boot failure `phi_boot = psi_boot^18 = 2.570e-08`, `psi_boot = 0.37873`). ## 3. Uncapped Special-`q` Nodes, `BOUND_CELL` Live Yield Certificate, & 100% Eager Cofactorization

A node is a degree-1 special-`q` prime ideal `Q = (q, y - s, x - t)` on side `f` or `g` in one of `38` five-bit bins `[71, 76), [76, 81), ..., [256, 261)` (`76` nodes total, `LB = LX = 71.0`, `LMAX = 261`, all `76/76` use uncapped `dsieve16` with `R in [16..64]`):

- **`BOUND_CELL` live certificate (`3,600` Ir/cell):** Every primitive cell receives an outward-rounded certified upper bound on both `log2 N_f` and `log2 N_g` (`3,408 <= 3,600` Ir in `KERNELS.md` §5; verified live in `verify_q15_descent.py` `[11]` on real `Q(zeta_15)` lattice cells with `gap >= -1e-9` bits). During the bound pass, the node accumulates the certified mean `ss_f * ss_g` over primitive cells (with `q` removed); any node whose certified mean falls below its bin's charged `pr` is discarded as a failure *before* cofactorization (`DISC = 0.001`), so every used node has `H1` yield `>=` the charged one. Cells with residual mass `<= T = kA * nA + kB * n + 96` on both sides survive to exact `NORMS`, `TDIV`, `q15_ecm16`, `PRIME`, `IDEAL`.
- **100% Eager Cofactorization (`frac = 1.0`, ZERO lazy-fraction product-of-averages assumption):** Every sieve node charges **100% of all survivors** eagerly (`own = LLL_NODE + sieve + survivors * surv_cost`, `frac = 1.0`) before descending distinct relations one by one until one succeeds. Because `frac = 1.0` is deterministic and independent of the relation count `M`, no joint bound or independence between survivor count `s` and relation count `M` is ever required!
