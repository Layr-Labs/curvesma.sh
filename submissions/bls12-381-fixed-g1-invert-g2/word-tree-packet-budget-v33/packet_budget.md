# Standalone Root packet construction and endpoint budget

Each actual packet requires at most64 scalar instructions at Root for request formation: two-word ID and ordinal arithmetic, masks/shifts, leaf-local offset, fixed opcode/length, child index, MOV49152/MADD port pointer, four-word header initialization and argument/pending-continuation state. Header pair writes are ordinary STP; all64-bit operations and carry words included. The transport separately pays each sender/receiver header and payload copy along three edges each way, plus all forwarding/handshake/control. Resident source/destination application loads/stores are separately in phase budgets. There is no device that accepts an uncharged arbitrary-width address.

The complete base phase budgets below reserve instruction counts for actual Root formation. These are accounting slots, not old bank-controller instructions executed or credited. All other listed operations use ordinary local Root/leaf pointers. All comparisons and counters are full width.
