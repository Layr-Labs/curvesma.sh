# Fully initialized global dictionary and explicit finite memory

This is an explicit storage-only model,not installed attack-scale VM hardware. Its admissibility is a material condition. Use a noncacheable2^40-byte native window at base2^45,shared image below2^45,and a97-bit logical bank selector exposed through two ordinary64-bit latches plus commit. Selecting a bank requires DSB,low/high stores,commit store,DSB;all arithmetic/address/data transfers are counted. There is no arithmetic/search/allocator oracle,flat136-bit native pointer or unpriced DMA. Native addresses stay below2^46,within48-bit VA.

Payload logical p starts at1;0 is nil. Map q=p-1 to local low31 bits,offset local*512,bank q>>31 (<2^95). Head index i is128 bits:local low36 bits,offset local*16,bank2^95+(i>>36)<2^96. Jump index j is94 bits:local low30 bits,offset local*640,bank2^96+(j>>30)<2^97. These bank ranges are disjoint. Implement128-bit shifts/subtractions in two64-bit registers;each selector including pointer/barriers/RET fits32 instructions. Initialize the latch address,all code/constants and every shared buffer cold. No physical atomic128 store is assumed:serial head reads/writes are two64 words,with explicit barriers before bank changes/publication.

Use2^128 sixteen-byte heads,ALL initially zero by charged native stores. Every payload is512 bytes,entirely zeroed before use. Store exactS192@0,B32@336,k8@368,U40@384,next128@432;all remaining bytes are initialized padding. Jump640 records contain rawM576,initialized A1 padding32,and v32. Two raw960-byte shared records store fullGT576,B32@608,k8@944;unused scalar-A metadata576..607 is initialized padding and never read. Key/hash/controller buffers are shared/disjoint,including a128-bit accepted counter,capK,next payload index and remaining visits. Canonical scratch below4096 bytes and every constant/seed/code byte is initialized/paid. No lazy parity or minimum caps exist.

On each query,load the bucket head and follow its chain,checking the five U words at each node. A match returns p/native payload immediately;the terminal handler copies p,B,k and exact key before any bank switch. Confirm all24 exactS words;false U match is the separately charged NH collision event. Otherwise recover savedA=p,currentA=t+1 and proceed with verified extraction. For a new key,allocate next p,increment it128-bit,zero/write the entire payload with next=oldhead,complete writes before switching back and publish the new head. Initial time0 allocates1;every earlier transition allocates exactly once,so p is exactly savedtime+1. No scalar-A slot is read.

For cap proof,extend distinct-key buckets to n=K+1 independent uniform128-bit values conditional on ideal group path/indices,as in hash.md. Let Cb be their co-bucket pair count. Its mean mu=n(n-1)/(2*2^128)<0.105K. Pair indicators,including overlapping pairs,have zero covariance,hence Var(Cb)<=mu<K. The gap floor(K/8)-mu exceeds0.020K. Chebyshev gives Pr[Cb>floor(K/8)]<1/(0.020^2*K)<2^-100. Earlier distinct insertions cost at most Cb visits;the terminal reused-bucket query costs at most Cb+1,so total<=2Cb+1. Set the native global hard visit cap floor(K/4)+2,decrement/check before each visit,abort on exhaustion. This includes the actual repeated bucket rather than treating it as fresh. Prefix abort is included by the extended count. No failure independence is assumed.

Complete fixed miss work fits512 instructions:three selectors<=96;full payload zeroing32STP;S copies24LDP/24STP;B4,k2,U6,next2 word-transfer instructions;head loads/stores,128-bit allocation/visit checks,all arguments/address/publication/control and frame/RET leave more than200 spare within512. A visit fits128 including selector32,all five U loads/comparisons,next128,hard counter and branches. Match/cap exits fit the same512+128*visits bound. Thus total<=512(K+1)+128(floor(K/4)+2)<=544K+768. Retain1024K and pay768 cold. Every physical selection/transfer and full initialized record is included.

Peak storage:2^126 payload slots*512=2^135;heads2^128*16=2^132;2^64 jump banks*2^40=2^104 including padding;shared/code/scratch<2^45. Total<2^136 bytes. Cold construction and ALL head zeroing are in cold-construction.md. If this finite banked storage model is inadmissible,the claim must be rejected;no practical hardware installation is asserted. Memory is supplementary and creates no new score/objective.
