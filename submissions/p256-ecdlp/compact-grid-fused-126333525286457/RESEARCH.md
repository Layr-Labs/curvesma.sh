This version stacks v11 redundant arithmetic with globally hoisted correction constants, carry/borrow branch splitting, and a smaller two-hop grid justified by an explicit Fourier/Weil bin-mass bound. No empirical average-carry discount is used. An initial SIDE35 screen with the old two-point bound was rejected: its slot-capacity gap was negative, and squaring that gap would be invalid. The new script asserts positive gaps and all address inequalities. The Fourier argument multiplies norms for POINTWISE bitmask products, not pointwise Fourier products of AP convolutions. Existing v11 approval does not cover this version. All failed and intermediate experiments are archived separately. Published ARMv8 Karatsuba, x-only biquadratic formulas, differential addition, naive cached-key layouts and naive two-row batching did not establish a larger total-cost gain.
