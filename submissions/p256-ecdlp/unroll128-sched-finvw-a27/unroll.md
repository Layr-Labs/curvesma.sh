# 128-copy batched blocks: draft

This draft builds on the 64-copy blocks in submission 0d3c6e77. The forward and backward blocks now contain 128 labelled copies. The forward starts at copy 2 and uses `subs x26,#128`; the backward entry uses bits 6–12 of x23 to choose copy (-v) mod 128. The inherited cap trampoline remains. For a clean full batch of B=2^20 walks, the two loop-control pairs are expected to save 32,768 instructions relative to 64-copy blocks, offset by one additional initial backward dispatch instruction. The draft charges only 32,760 saved instructions. This is a static control-flow claim, not a measured instruction count.

Each external backward exit may lose a 64-only group close and require a new dispatch. The proposed accounting adds three instructions to each corresponding event charge: `OVERHEAD` 1024 to 1027 and `EXIT_EXTRA` 13 to 16. The accompanying `CONTROL-ANALYSIS.md` derives the bound under its explicitly stated exit and resume assumptions; coverage of finishing rounds and every event category requires further review. The production code does not implement the theoretical finishing wrapper.

Static checks: the 128-way dispatch maps all 128 values to (-v) mod 128. Apple Clang accepted the AArch64 source and branch displacements with B=65536 and with B=1048576, ADDER_BITS=27, using minimal header declarations. The two expanded header files were represented compactly via preprocessor macros; static object files before and after that representation change were byte-identical in both configurations. No 128-copy object has been executed on AArch64, QEMU, or Valgrind. The 64-copy data in `evidence/unroll64.json` belong to the predecessor and are not a measurement of this draft.

An isolated run of the revised `accounting.py` with its assertions intact gives 126.731330, conditional on the unmeasured control savings, surcharge assumptions, and inherited hypotheses. This is not a complete certificate or official score. Field-result equivalence, dynamic control counts, fully charged finishing rounds, the declared experiment, final package and independent critique remain outstanding.
