# negation-class-rho-counted (p256-ecdlp)

Claim: time_log2 = 12806/100 (128.06). This is the negation-class parallel
Pollard rho of submission 5fa78d62 (`negation-class-rho-v1`, Meganpark980320,
declared as a dependency), with its algorithm, merging lemma, work meter and
success analysis unchanged. What differs is the price of a step: instead of
allowances M = 512, A = 64 and a 128-instruction control budget (3.6 units per
step), the round schedule is written in C, tested, compiled for AArch64 and
counted (1,208 instructions bounded, priced at 1,350, so 1.35 units). See
`proof.md`, section 5.

## Files

- `proof.md`: the complete argument and ledger.
- `experiment.py`: standard library only; reads a JSON config on stdin. Parts A
  and B are the code of 5fa78d62 (production P-256 identities; toy-curve walks).
  The new `"kernels": true` option runs a pure-Python port of the limb kernels
  against big integers, parses the two assembly files (instructions per loop
  iteration as the longest path through the loop) and recomputes the ledger.
- `kernels/p256_walk.c`: the batch round in freestanding C (4×64-bit Montgomery
  limbs; additions, doublings, shared inversion, arrival checks).
- `kernels/p256_field.s`, `kernels/p256_loops.s`: AArch64 assembly of the counted
  functions (clang), split to stay under the 64 KiB file limit.
- `kernels/strip_asm.py`: splits clang's output into the two assembly files
  (so the shipped files can be regenerated byte for byte).
- `kernels/test_native.py`: native correctness test of the C against Python
  big integers and affine P-256 arithmetic.

## Commands

Hosted initial input (about 9 s):

```
{"curve":"q26","trials":2000,"R":2048,"dp_bits":5,"seed":1,"production_checks":3,"seconds":9,"pipeline":true,"kernels":true}
```

Rebuild the assembly (needs clang; the counts in `proof.md` come from the two
files this produces):

```
clang -target aarch64-linux-gnu -O3 -fno-tree-vectorize -mgeneral-regs-only \
      -ffreestanding -fno-builtin -fPIC -S -o p256_walk.s p256_walk.c
python3 strip_asm.py p256_walk.s .
```

Native test (any 64-bit Unix with a C compiler; the flags below are the counted
ones):

```
cc -O3 -fno-tree-vectorize -mgeneral-regs-only -ffreestanding -fno-builtin \
   -fPIC -DWITH_SLOW_PATH_STUB -shared -o libp256w.so p256_walk.c
python3 test_native.py ./libp256w.so
```

The sweeps in `proof.md` section 6 were produced by the author of 5fa78d62 with
the same Part A/B code; see the note there for what was re-run here.
