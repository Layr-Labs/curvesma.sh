## 1–2. Algorithm, pairwise-disjoint 52-bit-VA machine, and run gate

One coordinator (generator `0`) executes `gate` (`subs xzr, x0, x2; sbcs xzr, x1, x3; cset x0, lo; ret`, `4` instructions, `GATE_INSNS = 256` charged unconditionally on every run covering `2 * 64` `RNDR` coin instructions + constant loads + compare + branch) on two fresh 64-bit `RNDR` words `u in [0, 2^128)`: if `u >= K_GATE`, it halts immediately with no output and no other processor executes an instruction; if `u < K_GATE` (`p_gate = K_GATE / 2^128 = 0.390896426`), three scalar AArch64 roles (`NODES = 2^68` generators, `N_REL = 2^42` relays, `N_HOME = 2^84` homes) execute Phases 0–5 (`FEAT_LVA` 52-bit VAs with `TTBR0` `[0, 2^52)` and `TTBR1` `[2^64 - 2^52, 2^64)`, `FEAT_D128` 56-bit PAs with max per-node storage `<= 2^52.9996` B `< 2^56` B, `FEAT_LSE` atomics, `DC ZVA` `DCZID_EL0.BS = 6` 256-byte Normal-memory zeroing, `FEAT_LS64` `LD64B`/`ST64B` on Normal Non-cacheable tables/buffers/R2 and Device link windows `LINK = 4,095 TiB`, `LINK_GEN = 34 TiB`, `PORTY = 34 TiB + 0xb000`, `STLR`/`STLUR` + `DMB ISH` completion ordering, and two-wave completion barriers `NBAR_COUNT = 29,193 <= 30,000`):

- **Phase 0 (Opened-run preprocessing + transversal birthday X-pair mining, `E_PRE <= 2^117.2303` units):**
  - *Transversal pool mining (`kernels/xmine.s`, `E_mine <= 2^124.1591` instructions):* Generator `g = 1024 c + m` (`0 <= c < 2^58`, `0 <= m < 1,024`) belongs to `pool(g) = 32 m + (c mod 32) < 2^15` (`K_GEN = 2^53` generators/pool; all `1,024` generators in Y-cluster `c` have distinct `m`, hence distinct pools). Each generator draws uniform `b_g in [0, r)` (`R_g = [b_g]Q`) and runs `NBATCH_MINE = 2^32` chains of `32,768` points (`P_0 = R_g + [c_(g,b)]P`, `Q_j = [j * s_(g,b)]P` for `1 <= j <= 16,384`, `xmine_fwd + fe_inv + xmine_bwd` computing `A = x(P_0 +- Q_j)^3 + 7 mod p` in `<= 963` hot instructions/pair plus `20` fixup allowance and `32` emit instructions), routing 256-bit records `(pool_id, A >> 63, g // 2^15, b)` (`15 + 193 + 53 + 32 = 293` bits: `42` implicit in `d1` on Hop 1 leaving `251 <= 256` bits, `84` implicit at Home) through the `2^84` Homes (`2^31` records/Home, heads re-zeroed afterward). Each pool collects its first `8` distinct-`A` bucket collisions (`0` triples and `>= 8` cross-chain hits across all `2^15` pools with probability `>= 1 - 2^-47.21`, `success.md` §6.1), recomputes the `16` winning chains to extract `(X_(p, 0), ..., X_(p, 15))` ordered with `0 < A_(p, 2q+1) - A_(p, 2q) = delta_A_(p, q) < 2^63` (`0 <= q < 8`), and broadcasts those `16` points + scalars `(b_(h(p,j)), alpha_(p,j))` (`X_(p,j) = [alpha_(p,j)]P + [b_(h(p,j))]Q`) to its `2^53` pool members.
  - *Table & state setup (`kernels/route.s` `tbld`):* each generator builds `40` `44-TiB` paired `(37,37,37,37,36,36,36)`-bit X-tables (`tbld` with bitmask `x6` selecting `x3 = 2^36` vs `x2 = 2^37`), pair-entry words `[EB_START, EB_END)` (`EB_END = 33 TiB + 2^34`, `EB_START = EB_END - 512 * Q2`, `Q2 = 16 * 2,097,117 = 33,553,872`), and 7-slot 43-bit `BT` (`x6 = 1 << 5`); relays and homes run `init3`, `tinit`, `dlvh0`, and `zero16384` over `2^47` head words.
- **Phases 1–5 (`G = 1536` groups, `m_g = floor(q1 * (g/1536)^(28/32))`, `q1 = 8,700,000,000`):** In each group `g` (after testing the latched stop flag), Y-cluster `c`'s `1,024` generators generate `cdiv(q_g, 1024)` Y-chains of `L_chain = 63,549 * 33 = 2,097,117` affine points `Y_(c,k,u) = [c_(c,k) + delta_u s_(c,k)]P` (`secp_fe.s` `yround` writing `offs7_44` + `b` limbs `1..3` at `+376, +496, +504` + `y_Y` rows + `B, B^2, b^4, -T(b), -T(beta b)`), streamed round-robin around the `1,024`-node cluster ring (`ysnd = 24`, `ydlv = 32`, `ydlve = 23` copying `+64..+511` into `YR_c`). On each batch `k` (`0 <= k < q1 <= 2^34`), each generator runs `fwd + fe_inv + bwd + keys + fin1` (`6 * Q2` leaves/batch; `w2 = (g_id & (2^42 - 1)) | ((g_id >> 42) << 42)` and `w3` packs `68` node bits + `26` `(2*l + s)` bits (`2 * Q2 = 67,107,744 < 2^26`) + `34` `(k - 1)` bits = `128` tag bits across `w2, w3`). Relays forward 16-record Hop-1 blocks (`h2s = 95`) and `fin` into cumulative Hop-2 slots (`K2B = 16`); Homes run `dlvh` (`DLVHB = 31`, `HB = 47`) to append into signed-VA `R2` and hash-join unjoined records (`4`/rec + `4`/visit, out-of-line K3-hit blocks `.pushsection .text.hit`, `CAND_CAP = 2^27`). In Phase 4 (`reqh, fwdq, sendr, fwdr`, caps `REQ_CAP = 49 * 2^33`, `RELAY_CAP = 2^40`), each Home requests the colliding leaf scalars `(mu, nu)` (`L = [mu]P + [nu]Q`) from both source generators, tests all `9` `(t, t')` pairs for `L' = u L` (`u in {+-1, +-lambda, +-lambda^2}`), and when `nu' - u nu != 0 (mod r)` verifies `[x]P == Q` for `x = (u mu - mu') * (nu' - u nu)^(-1) mod r`, latching the stop flag broadcast before the next group.

## 3. Leaf kernels, convex `44-TiB` tables, and class labels (`kernels/leaf.s`, `sites.py`)
