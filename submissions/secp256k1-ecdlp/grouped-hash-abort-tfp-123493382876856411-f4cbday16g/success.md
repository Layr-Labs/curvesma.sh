# Success and Expected-Work Bound, section 6 of proof.md

### 6.1 Phase-0 transversal birthday X-pair mining, scalar hiding, and Y-cluster coin model

All algorithm coins — the 128-bit coordinator gate coin `u in [0, 2^128)` (§6.7), Phase-0 coins `(b_g, c_(g,b), s_(g,b), rho)`, and Phase 1–3 coins `(c_(c,k), s_(c,k), rho_(g,k))` — are independent and uniform; `Q = [x]P` is uniform on `G` (`|G| = r` prime). Sections 6.1–6.6 establish the conditional success lower bound `lo_run` and conditional expected instruction count `E_run` of an **opened run** (given `u < K_GATE`); §6.7 combines them unconditionally with `p_gate = K_GATE / 2^128`.

The `NODES = 2^68` generators are partitioned into `N_CLUST = 2^58` Y-ring clusters `C_c` (`g = 1024 c + m`, `0 <= m < 1,024`) and orthogonally into `N_POOLS = 2^15 = 32,768` transversal X-pools `P_p` via `pool(1024 c + m) = 32 m + (c mod 32)` (`K_GEN = 2^53` generators/pool; every two generators in the same Y-cluster `C_c` have distinct `m`, hence distinct pools, and every two generators in the same pool `P_p` belong to distinct Y-clusters).

**Phase-0 pool collision bound (`P_FAIL_ALL_POOLS < 2^-47.21`).** In pool `P_p`, each generator `g` draws uniform `b_g in [0, r)` (`R_g = [b_g]Q`) and runs `NBATCH_MINE = 2^32` independent chains (`c_(g,b) in [0, r)`, `s_(g,b) in [1, r)`), generating `PTS_MINE_CHAIN = 32,768` points `P_(g,b,j,+-) = R_g + [c_(g,b) +- j * s_(g,b)]P` (`1 <= j <= 16,384`, `2^47` points/generator, `M_POOL = 2^100` points/pool) and hashing `A(P') = x(P')^3 + 7 mod p` into `N_B = 2^193` fixed buckets `A >> 63` (`((p - 1) >> 63) + 1 = 2^193` exact):
1. **Pigeonhole bucket cap (`<= 6 * 2^63` curve points/bucket):** Each bucket `[b * 2^63, (b + 1) * 2^63)` contains at most `2^63` integers `A`, and on `y^2 = x^3 + 7` at most `6` curve points share a given `A`, so every bucket holds at most `6 * 2^63` points (`P_BUCKET_MAX = 6 * 2^63 / (r - 1)`). By pairwise uniformity within each chain (`2 * 16,384 < r`), the expected number of same-chain bucket hits in `P_p` is at most `P_SAME_CHAIN_POOL = 2^85 * C(32768, 2) * P_BUCKET_MAX < 2^-76.4`.
2. **Cauchy–Schwarz lower bound on cross-chain distinct-`A` bucket hits (`MU_POOL_LO > 63.99`):** Let `n_b` be the number of attained `A`-values (`mu_6`-classes) in bucket `b`, so `sum_(b=0)^(2^193 - 1) n_b = (r - 1)/6`. Any two points from distinct chains are independent uniform on `G` (outside the `<= 2^-185` event `R_g = O` charged in `glob`), hitting the same bucket `b` with distinct `A` (`0 < |A_2 - A_1| < 2^63`) with probability `sum_b (6 n_b)(6 n_b - 6) / (r - 1)^2 >= 1 / 2^193 - 6 / (r - 1) = P_BDAY_HIT_MIN` by Cauchy–Schwarz. Over all `GAMMA_MINE_CROSS` cross-chain pairs in `P_p`, `mu_pool = E[W_pool] >= GAMMA_MINE_CROSS * P_BDAY_HIT_MIN = MU_POOL_LO > 63.99`.
3. **Chen–Stein total variation & no-3-collision matching:** Each cross-chain indicator depends only on its two chains (`|B_alpha| <= 2 * 32,768 * M_POOL`), with pairwise co-occurrence `<= P_BUCKET_MAX^2` by chain independence and pigeonhole, so Arratia–Goldstein–Gordon Theorem 1 gives `d_TV(W_pool, Pois(mu_pool)) <= CS_POOL < 2^-64.8`. Since `P(Pois(mu) <= 7)` is strictly decreasing in `mu > 0`, `P(W_pool <= 7) <= P(Pois(MU_POOL_LO) <= 7) + CS_POOL < 2^-62.4`. Expected same-bucket triples across distinct chains are `<= C(M_POOL, 3) * P_BUCKET_MAX^2 < 2^-83.3`. Outside `P_SAME_CHAIN_POOL + P_TRIPLE_POOL + P(W_pool <= 7)`, no bucket has `>= 3` points, so all `>= 8` pairs in `W_pool` are vertex-disjoint and satisfy `0 < A_(p,2q+1) - A_(p,2q) = delta_A < 2^63` (and `a_(p,2q+1)^3 - a_(p,2q)^3 = delta_A` on `y^2 = x^3 + 7`). Unioning over `2^15` pools gives `P_FAIL_ALL_POOLS < 2^-47.21` (charged in `glob`).
4. **Exact scalar hiding given Phase-0 points:** Conditional on all Phase-0 curve points `(P_(g,b,j,+-))` and steps `(s_(g,b))` (which deterministically fix `(X_(p, 0), ..., X_(p, 15))` and their mining generators `h(p, j) in P_p`), for every `(b_g)_(g < 2^68) in [0, r)^(2^68)` there is a unique tuple `(c_(g,b))` producing those exact curve points (`c_(g,b) = dlog_P(P_(g,b,0)) - b_g * x mod r`). Thus `(b_g)_(g < 2^68)` remain i.i.d. uniform on `[0, r)` given all Phase-0 points.

### 6.2–6.4 Good-class Chen–Stein on cross-pool & cross-cluster pairs, Usefulness, and Lemmas L & C

For any prefix of `q1p` batches (`n0p = 6 * q1p * Q2`, `Sp = 2^68 * n0p`), let `Gamma(q1p)` be the set of unordered leaf pairs `{L, L'}` from **distinct pools (`p != p'`) and distinct clusters (`c != c'`)**: `|Gamma(q1p)| = (Sp^2 - 2^15 * (2^53 * n0p)^2 - 2^58 * (1024 * n0p)^2) / 2`. Because `D_sym = [-389, 264]^3` and `W` are `mu_6`-class-invariant (`L' in class(L) => (L in W U D_sym <=> L' in W U D_sym)`), the good-collision indicator `J_alpha = 1[L' in class(L) and L not in W U D_sym]` for `alpha = {L, L'} in Gamma(q1p)` has expectation `P1_GOOD = (6(r - 1)/r^2) * (1 - D_WJ - D_LAB_SYM)` (`D_LAB_SYM = (2/(r - 1)) * 1959 * 2^(128 + PART)`), giving `mu(q1p) = |Gamma(q1p)| * P1_GOOD` (`6.917177811` at `q1 = 8,700,000,000`).

Each pool point `X_(p, j)` participates in `6 * K_GEN * n_Y` leaves (`n_Y = q1p * L_chain`) and each cluster Y-chain participates in `CLUST_BATCH = 6 * M_G * Q2` leaves, so the dependency neighborhood in `Gamma(q1p)` has size `|B_alpha| <= 12(K_GEN * n_Y + M_G * Q2) * Sp`. For `beta != alpha` in `B_alpha` (`beta in Gamma`, so its two leaves lie in distinct clusters), either `beta` has a fresh cluster Y-chain (`E[J_alpha J_beta] <= P1^2`) or shares `(c, k)` and `(c', k')` (`E[J_alpha J_beta] <= 36/(r - 1)^2` by Pairwise Chain Uniformity `0 < |delta_v - delta_u| < 2^22 < r` over `(c_(c,k), s_(c,k), c'_(c',k'), s'_(c',k'))` conditional on `X`), so Arratia–Goldstein–Gordon Theorem 1 bounds `P(sum_(alpha in Gamma) J_alpha == 0) <= exp(-mu) + cs` with `cs < 2^-10.42`.

On `I_alpha = 1` (`p != p'`), `h(p, j) != h(p', j')` lie in disjoint pools, so by §6.1(4) `b_(h(p,j))` and `b_(h(p',j'))` are independent uniform on `[0, r)` given all curve points, making `nu' == u nu (mod r)` occur with exact probability `1/r`. Conditioning on the two cluster-batches `(c_0, k_0), (c'_0, k'_0)` of `alpha` (`FIXED_LEAVES = 2 * CLUST_BATCH`) leaves all other cluster-batches' translations `c_(c, k)` independent uniform (up to `RHO = (r/(r - 1))^2` coin-rejection factor), yielding the certified Markov/Chebyshev failure rows in `certificate.py`: `d_batch < 2^-126.8`, `d_f < 2^-18.33`, `d_p2 < 2^-35.99`, `d_cl < 2^-18.62`, `d_rq < 2^-15.82`, `d_rl < 2^-27.45`, `lam_int < 2^-38.81`, and whole-run `glob < 2^-25.81`. By union bound over `alpha in Gamma(q1p)`, an opened run resolves `x` within the first `q1p` batches with probability at least `lo(q1p) = 1 - exp(-mu(q1p)) - cs(q1p) - rows(q1p) - glob(q1p)`.

### 6.5–6.7 Grouped early-abort expected work (`PHI[g]`) and 128-bit coordinator run gate

Let `T_stop in {1, ..., G, inf}` be the index of the first group `g` (`1 <= g <= G = 1536`, cumulative batches `MQ1[g] = floor(q1 * (g/1536)^(28/32))`) that resolves `x` (`T_stop = inf` if none resolves). Group `g` (`0`-indexed `0 <= g < 1536`) executes only on `{T_stop > g}`, which has probability `P_open(T_stop > 0) = 1` and `P_open(T_stop > g) <= 1 - lo(MQ1[g]) <= PHI[g]` for `g >= 1` (`PHI[g]` rounded upward to `2^-256` in `certificate.py`). For every non-negative group-local work term `W_g` (leaf kernels, Y-chains, routing, group hash-joins, non-defective walks, key paths, and Phase-4 count exchanges) whose conditional expectation given `{T_stop > g}` is bounded by `WG[g]` (since conditioning on points/coins of groups `<= g` never alters the fresh independent coins of group `g + 1`, and prior Home chain lengths are bounded by unconditional counts), linearity of expectation gives:
`E_open[R] <= E_SHARED_REST + E_FIX_WORK + E_CAND_WORK + E_REQ_WORK + sum_(g=0)^(1535) PHI[g] * WG[g] + SXV + EK2 * HCHG_VER + ELIST * HCHG_LS1 + DEFV + DEFK2 + DEFL + DEFJ + SXK2 * HCHG_VER = E_RUN <= 2^134.814309` instructions.

At `q1 = 8,700,000,000`, `lo_run = lo(q1) >= 0.997962564363`. Before Phase 0, the coordinator draws uniform `u in [0, 2^128)` (`GATE_INSNS = 256` instructions executed on every run) and runs Phases 0–5 iff `u < K_GATE = 133015161165470784583994612803444211703` (`p_gate = K_GATE / 2^128 = 0.390896426`), which is independent of `Q` and all Phase 0–5 coins:
- **Unconditional single-run success:** `P(recover x) = P(u < K_GATE) * P_open(recover x) >= (K_GATE / 2^128) * lo_run >= 0.390100000000 > 0.39` (`(K_GATE - 1)/2^128 * lo_run < 0.3901` verified in `certificate.py`).
- **Unconditional expected work:** By the law of total expectation over `u` and algorithm/challenge coins (`rules.md`: total classical computation over uniform challenges and fresh algorithm coins, `C = 1000` scalar AArch64 instructions per unit), `E[R] = E[R_gate] + P(u < K_GATE) * E_open[R] <= 256 + (K_GATE / 2^128) * E_RUN = E_TOTAL <= 2^133.459168` instructions, so `W_E = E_TOTAL / 1000 <= 2^123.493382876856411` units, and every run uses `R <= 256 + R_WORST_OPEN <= 2^179.732087` instructions.
