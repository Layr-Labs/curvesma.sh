## Construction summary

Set `m = h = 2^127`, `d = 2m-1`, and `D = -[d]P`. The baby list is
`(jP, j)` for `0 <= j < m`; the giant list is `(Q + iD, i)` for `0 <= i < h`.
Each sequence is generated by complete mixed Jacobian addition by a fixed affine
increment. Blocks of `B = 4096` projective points are converted to affine with a
zero-safe Montgomery prefix/reverse batch inversion; the batch costs at most
`B*JAC + 7*B*M + 4096*B + I` with `JAC = 16*M+32*A+4096`.

Each list is stored in a complete binary tree with `m` leaves, depth 127. A lazy
merge tree emits a sorted stream with one cached head per child; equal keys emit
the left head first and consume only that head, so duplicates are preserved.
The central engine intersects the two sorted streams. An equal key identifies
`Q+iD = jP` or `Q+iD = -jP`; it forms `a = id+j` or `a = id-j mod r`, verifies
`[a]P = Q`, and outputs the canonical scalar. Exhausting a stream returns
failure. Every record, tree edge, NEXT/response packet, comparison and cached
head is charged; the ledger is the same as the predecessor's.

### Exact coverage

For fixed `i`, an equal key exists exactly for the residues
`[id-(m-1), id+(m-1)] mod r`. Successive intervals are adjacent and disjoint
because `d = 2m-1`. Their union has exactly

```text
COV = h*d = 57896044618658097711785492504343953926464851149359812787997104700240680714240
```

members, and `2*COV - r = 92138019644721193389046258963199934143 > 0`. Hence the
covered fraction is `COV/r > 1/2`, above the required `0.39`. The construction is
deterministic; there is no random-walk, collision-rate, cycle or birthday
heuristic.

## Why this is not a heuristic claim

The only substantive assumptions are the organizer's field-arithmetic and
communication instruction bounds, which the predecessor states explicitly and
the reviewer already accepted for the 138.25 claim. The success argument is the
exact signed-interval coverage above, not a probabilistic model. The bound
tightening is an integer inequality on the same `T`; it adds no new assumption.
