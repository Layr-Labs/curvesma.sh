Peak memory <= 2^137.0002 bytes; opened-run preprocessing <= 2^117.0429 units (included in E_run); no advice or cross-challenge amortization. certificate.py (outward-rounded intervals) checks the VA registry, the 26-cell ledger, the 5.1 itemizations, each stated rate bound and the census counts.

## 1. Overview

On secp256k1 (y^2 = x^3 + 7 over F_p, p = 2^256 - 2^32 - 977, prime order r, phi(x,y) = (beta x, y) = [lambda](x,y)), after the gate opens six leaves x(phi^t(X) +- Y) (t = 0,1,2) are labelled per pair from one batched inverse of D = y_Y^2 - y_X^2 via Fourier components (Ew - b) + beta^t(Fw - a) + beta^(2t) Gw. Records travel in two hops from 2^68 generators through 2^42 relays to 2^84 homes, joining arrival-order hash chains (HB = 47) over G = 1536 groups.

## 2. Algorithm and 52-bit-VA machine

Premises (all scalar): 52-bit VAs (FEAT_LVA, valid in [0,2^52)/[2^64-2^52,2^64), asserted by a64.py) onto 56-bit PAs (FEAT_D128); DC ZVA (BS=6); FEAT_LS64 (LD64B/ST64B, 64-B aligned, single-copy atomic on Device-nGnRE windows, which support exclusives and WFE events, 2 KiB granule); store-release links with DMB ISH; 128-bit/STADDL counters, two-wave barriers (acyclic); FEAT_RNG (RNDR premised uniform, never reporting failure; coin sampler 5.1); a main processor and a delivery processor per message kind (Y kinds on the generator's main processor), with a link that queues each kind's messages and presents them one at a time (5.1 Waits); translation tables built by each node (5.1). A 32-byte record [K2,K3,w2,w3] carries w2 = g mod 2^64, w3 = (g>>64) | ((2l+s)<<4) | ((k-1)<<30) (4+26+34 = 64 bits); relay d1 = low 42 bits of label part 1, home d2 = K2 mod 2^42, bucket K3 mod 2^47, verified d4 = K2>>42 (170 label bits). **Gate** (GATE = 256 >= 2 COIN_SCALAR + 8 + 3 + 4: two RNDR words, K_GATE into x2, x3 by MOVZ + 3 MOVK each, BL, CBZ, halt, route.s gate 4): u < K_GATE. **Preprocessing** (E_PRE <= 2^117.0429 units, in E_run): the ledger's (P) rows. **Phases 1-5**: Y-ring + per-batch kernels, relay h2s+fin, home dlvh, phase-4 resolution (caps count entries, a cursor stepping one entry up to base + cap entries: CAND_CAP = 2^27 16-B candidate pairs, `REQ_CAP = 49*2^33` and RELAY_CAP = 2^40 64-B requests), stop test (5/node).

### 3.2 Label and chain parameters

T(v) = floor(2^128 v/p); label parts have PART = 64 + D1 = 106 bits, comp(v) = floor(2^106 v/p) = T(v) >> 22. For a leaf x-coordinate x let v_m = beta^m x mod p (m = 0,1,2); the class's canonical member is `v* = min_m v_m` (index `j* = argmin`) and its **label** is `(comp(v*), T(beta v* mod p) >> 64)`, a function of the mu_6-class. A record carries `d1 = comp(v*) mod 2^42` (D1 = 42 bits 22..63 of `T(v*)`: the relay), `d2 = (comp(v*) >> 42) mod 2^42` (D2 = 42 bits 64..105: the home), `K2 = T(v*) >> 64` (64 bits; its top D4 = 22 bits d4 = K2 >> 42 are verified at the home) and `K3 = T(beta v*) >> 64` (D3 = 64 bits; bucket K3 mod 2^47, HB = 47). A full match fixes D1 + D2 + D3 + D4 = 170 bits; KEYBITS = 64 + D4 = 86 are the bits compared beyond the home digits. F1 = F2 = 2^42 are the relay count and homes per relay (2^84 homes); SIDE = F1. yround advances a chain by YPC = 33 points per round (Z +- i S for i = 1..16, then Z <- Z + 33 S), YROUNDS = ceil(2^21/33) = 63,551 rounds per chain, batching all affine denominators of YB = 256 chains into one fe_inv.

### 3.3 Truncated fraction labels, window set W, label-error set D', lattice lemma

**Fractions.** 2^128 v/p = v/2^128 + C0 v/(2^128 p) with the second term in [0, 2^-95), so T(v) = (v >> 128) + e0, e0 in {0,1}; write T_m(c) = T(beta^m c mod p). **Truncated products** (TR0, TRK). For a stored component c with rows R_k == c 2^(64k) (mod p) below 2^256 (R_0 = c, R_(k+1) = SHX(R_k)) and a multiplier M < 2^256 with limbs M_k, Z = sum M_k R_k == cM (mod p), Z < 2^322, and T(Z mod p) == floor(Z/2^128) + e (mod 2^128), e in {0,1} (as 2^128 Z/p - Z/2^128 = Z C0/(2^128 p) < 2^-28). The kernels keep the words of columns 2 and 3: f = sum lo(M_k r_k3) + hi(M_k r_k2) mod 2^64, s = sum (lo(M_k r_k2) >> 3) + (hi(M_k r_k1) >> 3) < 2^64, A = f 2^64 + 8s mod 2^128. Then floor(Z/2^128) - A == c_low + d, where c_low <= 7 is the carry out of columns 0-1 (each limb's part is below 2^129, four limbs) and d <= 56 the eight dropped 3-bit parts. So T(Z mod p) - A in [0, 64] (RAW = [0,1] + [0,7] + [0,56]) for every such R_k, M; with M = w it estimates T_0(cw), with the beta-row multiplier T_1(cw).

**Corrections and sums.** A sign's leaves are L_t = alpha + beta^t beta' + beta^(2t) gamma with alpha = Ew - b, beta' = Fw - a, gamma = Gw (section 1). bwd adds -T_m(b) to alpha's and -T_m(a) to beta''s estimates V_m (m = 0,1); as T_m(c - y) == T_m(c) - T_m(y) - {0,1}, their error becomes [-1, 64]. keys takes U_m = V_m (m = 0,1), U_2 = -U_0 - U_1; the three beta^m c mod p sum to 0, p or 2p, so T_0 + T_1 + T_2 == -k, k in {0,1,2}, and U_2 errs by -(T_0 - U_0) - (T_1 - U_1) - k: [-130, 0] for gamma, [-130, 2] for alpha, beta'. As beta^m L_t = beta^m alpha + beta^(m+t) beta' + beta^(m+2t) gamma in F_p, T(v_m) == T_m(alpha) + T_(m+t)(beta') + T_(m+2t)(gamma) + kappa, kappa in {0,1,2}, so W_m = U_m(alpha) + U_(m+t)(beta') + U_(m+2t)(gamma) mod 2^128 errs by the sum of the three errors plus [0,2], and N' = ~(W_0 + W_1) by -(T(v_0) - W_0) - (T(v_1) - W_1) - k + 1. Over t in {0,1,2} (indices mod 3): T(v_0) - W_0, T(v_1) - W_1 in [-132, 194] and T(v_2) - N' in [-389, 264] (widths 326, 326, 653; certificate.py derives this table from the three terms).

**The index.** keys takes the top words F0, F1 of W_0, W_1 and the exact-carry word sigma = floor((W_0 + W_1)/2^64) mod 2^64: if F0 >= F1, j = 2 if F1 + sigma >= 2^64, else 1; otherwise j = 2 if F0 + sigma >= 2^64, else 0. Let X_m = 2^64 v_m/p, so X_0 + X_1 + X_2 in {2^64, 2^65}. The **window set** W is the set of points Z whose x = x(Z) has (W1) X_0 or X_1 below 1 or above 2^64 - 1, (W2) X_2 below 1 or above 2^64 - 4, (W3) |X_0 - X_1| < 2, or (W4) X_0 - X_2 or X_1 - X_2 in (-1, 4). *Exactness outside W.* Outside (W1), 2^64 <= T(v_m) <= 2^128 - 2^64 (m = 0,1), so W_m = T(v_m) - e_m does not wrap and, as 2^64 X_m - T(v_m) in [0,1), a' = X_0 - F0 and b' = X_1 - F1 lie in [-132/2^64, 1 + 195/2^64). Write (W_0 + W_1)/2^64 = X_0 + X_1 - eps, eps in [-264/2^64, 390/2^64); outside (W2), sigma = 2^64 - ceil(X_2 + eps). Hence F0 >= F1 iff X_0 - X_1 >= a' - b' (in (-2, 2)), F1 + sigma >= 2^64 iff X_1 - X_2 >= b' + eps and F0 + sigma >= 2^64 iff X_0 - X_2 >= a' + eps (both in (-1, 2)). Outside (W3) and (W4) each test has the sign of the exact difference: F0 >= F1 iff v_0 > v_1, and then the carry of F1 + sigma decides v_2 < v_1; otherwise it decides v_2 < v_0 with F0. So outside W, `j = j*`. *Rarity.* X_m < 1 means v_m < p/2^64 < 2^192; X_m > 2^64 - c means v_m > p - c p/2^64; a window of width c on X_i - X_j means (beta^i - beta^j) x mod p lies within c 2^192 of 0 or of p. These maps of x are bijections of F_p (beta^i != beta^j), so (W1) holds for at most `4 * 2^192` values of x, (W2) `5 * 2^192`, (W3) `4 * 2^192`, (W4) `2 * 5 * 2^192`: 23 windows. A uniform point of G \ {O} has a given x with probability <= 2/(r-1), so `P(W) <= D_WJ = (2/(r-1)) 23 * 2^192 < 2^-58.47`. W depends on which member's x a leaf carries; its mu_6-closure W^6 = W U phi(W) U phi^2(W) (W is closed under negation) is a union of classes with P(W^6) <= 3 D_WJ.

**Labels and D'.** A leaf of index j emits the fractions (W_0, W_1) (j = 0), (W_1, N') (j = 1) or (N', W_0) (j = 2): d1, d2, K2 from bits 22..127 of the first and K3 from bits 64..127 of the second (3.2). With the index exact, `v_j = v*` and `v_(j+1) = beta v*`, so the record carries the class label unless a computed fraction's error carries it across a multiple of 2^22. The **label-error set** D' is the set of Z whose x has T(v_0) mod 2^22 or T(v_1) mod 2^22 in [0, 194) U [2^22 - 132, 2^22), or T(v_2) mod 2^22 in [0, 264) U [2^22 - 389, 2^22) (a wrap mod 2^128 sits at these residues too): 326 + 326 + 653 = 1305 residues. Each value of T is taken by at most 2^128 values of v, each residue mod 2^22 by 2^106 values of T, and x -> v_m is a bijection, so `P(D') <= D_LAB = (2/(r-1)) 1305 * 2^(128+PART) < 2^-10.65`. *Label counts (Lemma L's premises).* Outside W U D' a leaf of a clean batch (3.4) emits its class label for every representation; on D' \ W the index is exact and each of the path's two fractions floors to one of two adjacent 2^22-blocks (mod 2^128), at most 4 labels; on W any of the three paths, at most 12. So a point emits at most `1 + 11 * 1[Z in W U D']` labels. The symmetric boundary D_sym (success.md 6.1) puts the widest window ([0, 264) U [2^22 - 389, 2^22), 653 residues) at all three members, so D' ⊆ D_sym, D_sym is a union of classes, and the same count gives `P(D_sym) <= D_LAB_SYM = (2/(r-1)) 3 * 653 * 2^(128+PART)`.

**Lattice lemma (KB).** FA = 0x114ca50f7a8e2f3f657c1108d9d44cfd9, FB = 0xe4437ed6010e88286f547fa90abfe4c3 satisfy FA^2 - FA FB + FB^2 = p, FB beta == FA - FB and (FA - FB) beta == -FA (mod p), so Lam = {(v,u) in Z^2 : u == beta v (mod p)} has the basis (FB, FA - FB), (FA - FB, -FA) of determinant -p; as FA > FB > 0 its half-open fundamental parallelogram P0 spans [0, FA) in v and (-FA, FA - FB) in u. For each point lambda of Lam in a box [v0, v0 + a) x [u0, u0 + b), lambda + P0 lies in [v0, v0 + a - 1 + FA) x (u0 - FA, u0 + b - 1 + FA - FB); these translates are disjoint (P0 tiles the plane under Lam) and have area p, so the box holds at most (a + FA)(b + 2FA - FB)/p points of Lam. Fixing f label bits (all among the `2 * 106` bits of (comp(v), comp(u)), u = beta v mod p) leaves 2^(212-f) pairs of component values; a computed component value is an interval of at most BOX = (p >> PART) + 1 values of v (of u for the second), widened by its fraction's error range, at most 654 units of p/2^128, i.e. WIDE = 654 (p >> 128) + 4 values (a fraction wrapping mod 2^128 gives two end pieces of [0, p), one interval as pZ^2 ⊂ Lam). So on each path at most 2^(212-f)(BOX + WIDE + FA)(BOX + WIDE + 2FA - FB)/p < (1 + 1/KBF) 2^-f p values of v_j, hence of x, give those bits (KBF = 3195, checked by certificate.py), whatever index keys returns. With three paths and two points per x, a uniform point's emitted label takes f given bits with probability at most `KB(f) = 6 * 2^(256-f) (KBF + 1)/((r-1) KBF)`; equivalently a widened f-bit cell holds at most (r-1) KB(f) points.

### 3.4 Arithmetic sites, batch defects and metered fixups

**Carry-losing steps.** A row shift SHX of B = (b0..b3) loses its carry iff (B mod 2^192) + floor(b3 C0/2^64) >= 2^192, which needs B mod 2^192 > 2^192 - 2^33: `SHX_BAD = 2^64 * 2^33` rows. A fold FDX of Z < 2^322 (t = (Z mod 2^256) + floor(Z/2^256) C0) loses it iff t >= 2^256, which needs Z mod p = t - p in [C0, 2^66 C0): FOLD_BAD = 2^66 C0. The square fold F5 (fifth word <= C0 + 1) loses it iff the true square lies in [C0, C0^2 + 2C0): SQ_BAD = C0^2 + 2C0. The P1 steps FS (u^2 = M - N, +p on borrow) and FADDW (v^2 = M + N, -p on carry) take folded operands in [0, p + C0); a deviation forces u^2 mod p in [p - C0 + 1, p - 1] or v^2 mod p in [C0, 2C0 - 2]: FS_P1_BAD = C0. Lookup and beta-window sums (LKFOLD4) of n <= 8 table words fold `S < 8 * 2^256` by t = S >> 256 <= 7 and add C0 once more on carry, exact on every input; every other step (RF, RA, RA4, fe_mul_f, fe_sqr_f, fe_inv, truncated products, key-pass arithmetic) is exact on its inputs. While no earlier site of the batch has deviated, a row or output is a word below 2^256 congruent to its operand value, which it therefore determines; the operand is a function of the fresh point Y (or of rho_(g,k), uniform on [1, p)) with at most mult preimages per value: 1 for the rho-scaled acc, R; 6 for bijections of B = y_Y^2 (each B from <= 3 values of x_Y, 2 points each) and for u^2, v^2 (u = 1/(y_Y + y_X)); 12 for values fixing B up to 2 (e_j = (B - A_1)(B - A_2), inv_e, 1/D^2) or y_Y up to 4 (N = P y_Y); 8 for E, F, G (degree <= 4 in x_Y). A run fails with probability `<= bad * mult/(r-1)`.

**Defect sites** (QP = Q2/2 X-pairs; runs, bad, mult): fwd row shifts of acc_(j-1) (3QP, 2^97, 1); fwd fold of acc_j (QP, 2^66 C0, 1); bwd row shifts of R_j (3QP, 2^97, 1); bwd fold of inv_e = R_j acc_(j-1) (QP, 2^66 C0, 12); bwd fold of R_(j-1) = R_j e_j (QP, 2^66 C0, 1); bwd row shifts of D_2 = B - A_2 (3QP, 2^97, 6); bwd fold of 1/D_1 = D_2 inv_e (QP, 2^66 C0, 6); bwd square fold of 1/D^2 (Q2, C0^2 + 2C0, 12); bwd fold of N = P y_Y (Q2, 2^66 C0, 12); bwd FS/FADDW of u^2, v^2 (2Q2, C0, 6); bwd row shifts of E, F, G (9Q2, 2^97, 8). `D_SITES = sum runs * bad * mult/(r-1)` over these 11 sites. A batch also fails if D_j = 0 (Y = +-phi^t(X), <= 6/(r-1) per incidence) or if a c_(c,k) makes a chain point O or two added x-coordinates equal (`<= YPC + 2*16 + 2` values of c per round): `D_YGEN = YROUNDS (YPC + 2*16 + 2)/(r-1)`, D_BATCH = D_SITES + 6 Q2/(r-1) + D_YGEN < 2^-127.4.

**Metered fixups.** Each rare carry (first ADDS of SHX/SHXT, carry into limb 2 of FDX/F5, the C0 step of FS/FADDW, the carry of a LKFOLD4) branches over a short **fixup** that adds FIX_EXTRA instructions (3 for SHX, FDX, F5; 4 for FS, FADDW; 5 for BLK lookup folds) and C0 to a per-call word; registers equal the inline chain's on every input, so a fixup never changes a value or label. The word is C0 n for n fixups; the driver adds it shifted right by 32 (one ADD, LSR #32) to the node's meter, a step floor(C0 n/2^32) = n + floor(977 n/2^32) in [n, C0 n/2^32], and starts a batch only while the meter is <= DELTA_F - FIX_BATCH; a stopped generator starts no batch but keeps forwarding Y records and sending its finals and barrier messages, so only its own leaves are lost (d_f, success.md 6.4) (DELTA_F = 2^52, FIX_BATCH = 56 Q2/2 bounds a batch's fixups; its meter step is at most FIX_BATCH + 160, so the meter stays below 2^53). A fixup needs a word in a small set: SHX a row with low word above 2^64 - C0 (FIX_ROW = C0 2^192 rows); FDX an output with low 128 bits below (2^66 + 1) C0 (FIX_FOLD = (2^66 + 1) 2^128 C0); F5 low 128 bits below 2^65 (FIX_SQ = 2^193); FS/FADDW a low word within C0 of an end (FIX_SUB = C0 2^192); a fold of n table words carries iff S mod 2^128 >= 2^128 - t C0, at most sum_(t < n) t C0 2^128 sums: FIX_LK7 = 21 C0 2^128 (n = 7), FIX_LK8 = 28 C0 2^128 (n = 8), and each 6-word beta-window fold 15 C0 2^128, charged FIX_BLK = 30 C0 2^128. The 20 fixup sites (runs, set, mult; 56 per X-pair: 27 SHX, 6 FDX, 2 F5, 3 FS, 2 FADDW, 16 BLK): fwd 8-word fold of e_j (QP, FIX_LK8, 12); fwd rows of acc_(j-1) (3QP, FIX_ROW, 1); fwd fold of acc_j (QP, FIX_FOLD, 1); bwd rows of R_j (3QP, FIX_ROW, 1); bwd folds of inv_e (QP, FIX_FOLD, 12) and R_(j-1) (QP, FIX_FOLD, 1); bwd FS of D_2 (QP, FIX_SUB, 6); bwd rows of D_2 (3QP, FIX_ROW, 6); bwd fold of 1/D_1 (QP, FIX_FOLD, 6); bwd 8-word fold of 1/D_2 (QP, FIX_LK8, 6); bwd square fold of 1/D^2 (Q2, FIX_SQ, 12); bwd 8-word fold of M (Q2, FIX_LK8, 12); bwd 7-word fold of P (Q2, FIX_LK7, 12); bwd fold of N (Q2, FIX_FOLD, 12); bwd FS of u^2 and FADDW of v^2 (Q2 each, FIX_SUB, 6); bwd beta-window folds (2Q2, FIX_BLK, 6); bwd 8-word fold of E (Q2, FIX_LK8, 8); bwd 7-word folds of F, G (2Q2, FIX_LK7, 8); bwd rows of E, F, G (9Q2, FIX_ROW, 8). `E_FIX = sum runs * set * mult/(r-1)` is the expected fixup count per batch; success.md 6.4 turns it into the meter-stop rate d_f, and proof.md 5 charges max FIX_EXTRA = 5 per expected fixup.
