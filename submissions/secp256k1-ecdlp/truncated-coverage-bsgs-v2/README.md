# secp256k1-ecdlp

Deterministic truncated-coverage baby-step/giant-step accounting control, submitted
for exploratory review. Success probability is H*m/r >= 2/5 on the specified full
target; the giant walk is stopped at that coverage floor and the table is rebalanced
against it.
