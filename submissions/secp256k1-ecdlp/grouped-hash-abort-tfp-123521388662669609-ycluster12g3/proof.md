## 1. Overview

On secp256k1 (`y^2 = x^3 + 7` over `F_p`, `p = 2^256 - 2^32 - 977`, group `G` of prime order `r`, `phi(x, y) = (beta x, y) = [lambda](x, y)`), after the §2.4 coordinator run gate opens (`p_gate = K_GATE / 2^128`), six leaves `x(phi^t(X) +- Y)` (`t = 0, 1, 2`) are labelled per pair from one batched inverse of `D = y_Y^2 - y_X^2` via Fourier components `(Ew - b) + beta^t(Fw - a) + beta^(2t) Gw` (Galbraith, Wang and Zhang, ePrint 2015/605). Records travel in two bulk-synchronous hops from `2^68` generators through `2^42` relays to `2^84` homes, joining arrival-order hash chains (`HB = 47`) over `G = 1536` power-law groups (`m_g = floor(q1 * (g/1536)^(28/32))`).

## 2. The algorithm and pairwise-disjoint 52-bit-VA machine

### 2.1 Machine, addressing, ordering and completion

One coordinator (designated generator `0`) runs the §2.4 run gate; on an opened run, three roles of nodes, each with one main processor and one delivery processor per incoming message kind, execute scalar AArch64 instructions (`C = 1000` instructions per unit, `COST_MODEL.md`):
- **Generators** `g < 2^68` (`2^58` rings of `M_G = 1,024` generators): permanent `X` setup (`MX = 12`), Y-chain generation and ring forwarding (`yround`, `ysnd`, `ydlv`, `ydlve`), batch kernels (`fwd`, `fe_inv`, `bwd`, `keys`), hop-1 sends to relay `d1`, phase-4 request serving.
- **Relays** `d1 < 2^42`: hop-1 arrival `h2s`, hop-2 row blocks (`k2 = 16`) to home `(d1, d2)`, phase-4 forwarding.
- **Homes** `(d1, d2)` (`d2 < 2^42`, `2^84` homes): cumulative 4,777-TiB 0-mod-64 signed-VA `R2` slot `[-682 TiB, +4,095 TiB)` (`CAP_H` records, strictly below `LINK = 4,095 TiB`), fused copy-and-join `dlvh`, candidate resolution.

Architectural extensions and premises (all scalar, no SIMD/SVE):
- **52-bit VAs (`FEAT_LVA`, `T0SZ = T1SZ = 12`, TBI = 0) and 56-bit PAs (`FEAT_D128`).** Valid VAs lie in `TTBR0` `[0, 2^52)` or `TTBR1` `[2^64 - 2^52, 2^64)` (`a64.py` asserts `va52()` on every access; `certificate.py` `disjoint_va` verifies pairwise disjointness of all memory and MMIO intervals per role), mapped 1-to-1 onto physical addresses `< 2^56` (max per-node storage `<= 2^52.9998` B `< 2^56` B).
- **Base-ISA `DC ZVA` (`DCZID_EL0.BS = 6`, `DZP = 0`, `SCTLR_EL1.DZE = 1`).** Zeroes 256-byte aligned Normal-memory blocks (`zero16384`).
- **`FEAT_LS64` (`LD64B`/`ST64B`, `SCTLR_EL1.EnALS = 1`).** Moves 64-byte aligned blocks (`t` even, `t <= 22`, `[Xn]` base only, `n not in {t..t+7}` on `LD64B`). Supported locations (`IMPLEMENTATION DEFINED`): per-processor incoming link windows (`LINK = 2^52 - 2^40` on Relay/Home and `LINK_GEN = 34 TiB` on Generator for block arrivals, Device, `LD64B`, placing the 32-B header at `+32..+63` and 512-B payload 64B-aligned at `+64..+575`; `LINK_MSG = LINK + 0x1000` and `LINK_GEN_MSG = 34 TiB + 0x1000` for 6-word messages at `+0..+47`), outgoing Y-ring port (`34 TiB + 0xb000`, Device, `ST64B`), home `R2` and generator Y-buffers/pair entries (Normal Non-cacheable, `LD64B`/`ST64B`), and generator X-tables `[59 TiB, 2^51)` and beta tables `[2^64 - 2^51, 2^64)` (Normal Non-cacheable, `LD64B`).
- **Links, store-release ordering and `DMB ISH`.** Point-to-point links carry hop-1 blocks (`1,024` B, `k1 = 16`, `STLR`/`STLUR` to `+0`), hop-2 row blocks (`1,024` B, `k2 = 16`, `STLUR` to `+0`) and 48-B messages (`STLUR` to `+40`), and 512-B Y-ring blocks (`7 × 64` B payload at `+64..+511`, `STLR` to `34 TiB + 0xb000`, received at `34 TiB + 0x40..0x1ff` by `ydlv`/`ydlve` with `STADDL` to `CNTY`). Every sender executes `DMB ISH` before buffer reuse (`machine.py` enforces delayed reads and rejects pending messages at `RET`).
- **Two-wave barriers and completion.** Hop 1 completes at relay `d1` via `h2s`'s 128-bit `D = 2^126 + sum m - msgs` and missing-finals `x5:x15` (`|sum m - msgs| <= 2^68 * 2^50 = 2^118 < 2^126`, `RCV1 = 4`, `FIN_CNT = 6`, `H2S_DONE = 4`); Y-ring batches complete via `CNTY == L_chain` (`NBAR_COUNT = 29,189 <= 30,000`); hop 2 completes at home `(d1, d2)` via `CNTE` and `CNT` (`EXPECTH = 16`). Wait graph is strictly acyclic.
- **Coins (`FEAT_RNG`).** `MRS Xt, RNDR` (`64` instructions per 256-bit scalar; conservatively `2 * COIN_SCALAR = 128` for the two 64-bit gate words).

### 2.2 Cluster leaves, labels and records

In cluster `c < 2^58`, generator `g = 1024 c + m` holds `R_g = [b_g]Q` and `X_(g, j) = R_g + [a_(g, j)]P` (`0 <= j < 12`). Batch `k` (`1 <= k <= q1 = 11,600,000,000`) originates on `m = (k - 1) mod 1024` (`Y_(c, k, u) = [c_(c, k) + delta_u s_(c, k)]P`, `0 <= u < 2^21`) and pairs `Y_(c, k, l // 12)` with `X_(g, l mod 12)` (`0 <= l < Q2 = 25,165,824`) on every `g in C_c` (`rho_(g, k)` independent per generator). Pair entries occupy `[EB_START, EB_END)` (`EB_BASE = 33 TiB`, `EB_END = EB_BASE + 2^34`, `EB_START = EB_END - 512 * Q2`).

For `Z != O` with canonical `v* = min(x, beta x mod p, beta^2 x mod p)` and 106-bit parts `(comp(v*), comp(beta v* mod p))`, `comp(v) = T(v) >> 22`, a 32-byte record `[K2, K3, w2, w3]` carries top 64-bit words `K2, K3`, `w2 = g mod 2^64`, and `w3 = (g >> 64) | ((2 * l + s) << 4) | ((k - 1) << 30)` (`4 + 26 + 34 = 64 <= 64` bits). Relay `d1` = low 42 bits of part 1, home `d2 = K2 mod 2^42`, hash bucket `K3 mod 2^47` (`HB = 47`), verified `d4 = K2 >> 42` (`42 + 42 + 64 + 22 = 170` label bits).

### 2.3–2.4 Coordinator run gate and opened-run phases

- **Run gate (`kernels/route.s` `gate`, `GATE_INSNS = 256` charged unconditionally on every run):** Before waking any other node or reading `Q`, generator `0` draws two fresh independent 64-bit `RNDR` words `u = u_0 + 2^64 u_1` uniform on `[0, 2^128)`, loads `K_GATE = 132917291944920932309227833155252984270` (`p_gate = K_GATE / 2^128 = 0.390608815`), and executes `gate` (`subs xzr, x0, x2; sbcs xzr, x1, x3; cset x0, lo; ret`, `4` instructions; `2 * 64 + 4 + 8 = 140 <= 256`, tested in `machine.py` `gate_checks`). If `u >= K_GATE` (`x0 = 0`), generator `0` halts immediately with no output and no other processor executes an instruction. If `u < K_GATE` (`x0 = 1`), generator `0` initiates Phase 0 below. Nothing is amortized across challenges.
- **Phase 0 (Opened-run preprocessing, `E_PRE <= 2^117.0429` units, charged in `E_run`):** program delivery (`<= 2^17` B: `29,429 * 4 = 117,716 < 131,072` B), node state (`ydlv0` `19`, `dlvh0` `15`), all scalar coins, `12` permanent `X_j` points + descriptors (`GEN_MULX + XSETUP`), `21` contiguous `49 TiB` paired + `6` single `32 TiB` + `12` paired `64 TiB` 7-window X-tables (`tbld`), pair-entry `X` words, 7-slot 43-bit beta tables (`tbld`), LC/RC/read-cursor init (`init3`, `tinit`), home `zero16384` (`BS = 6`, `2^47` words at `2^64 - 2^52`), `Q` broadcast, and `R_g = [b_g]Q`.
- **Phases 1–5 (`G = 1536` opened-run groups, `m_g = floor(q1 * (g/1536)^(28/32))`):** Y-chain generation `yround` + 1,024-node Y-ring (`ysnd`, `ydlv`, `ydlve`), per-batch `fwd + fe_inv + bwd + keys` + `fin1`, relay `h2s + fin`, home `dlvh`, phase-4 resolution (`CAND_CAP = 2^27`, `REQ_CAP = 49 * 2^33`, `RELAY_CAP = 2^40`), and stop test (`5`/node).
