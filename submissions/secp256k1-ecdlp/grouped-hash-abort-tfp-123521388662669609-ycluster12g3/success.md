# Success, section 6 of proof.md (explicit failure-row enclosure and coordinator run gate)

### 6.1 Opened-run Y-cluster flipped-grid coin model and pairwise chain uniformity

All algorithm coins (the 128-bit coordinator gate coin `u` of §6.7 and all opened-run coins `b, a, c, s, rho`) are independent and uniform; the challenge `Q = [x]P` is uniform on `G`. Sections 6.1–6.6 analyze the conditional distribution of an **opened run** (given `u < K_GATE`, which is independent of `(Q, b, a, c, s, rho)`); §6.7 multiplies by `p_gate = K_GATE / 2^128` for the unconditional single-execution bound.

The `NODES = 2^68` generators are partitioned into `N_CLUST = 2^58` disjoint Y-ring clusters `C_c` (`0 <= c < 2^58`) of `M_G = 1,024` generators `g = 1024 c + m` (`0 <= m < 1024`). Each generator `g` draws fresh uniform `b_g in [0, r)` and `a_(g, 0), ..., a_(g, 11) in [0, r)`, setting `R_g = [b_g]Q` and its `MX = 12` permanent points `X_(g, j) = R_g + [a_(g, j)]P` (`12,288` independent permanent `X` points across cluster `C_c`).

For each cluster batch `k = 1..q1` (`q1 = 11,600,000,000 < 2^34`), generator `m = (k - 1) mod 1024` of cluster `C_c` draws fresh uniform `c_(c, k) in [0, r)` and `s_(c, k) in [1, r)` (`S_(c, k) = [s_(c, k)]P != O`), generating `L_chain = 2^21` points `Y_(c, k, u) = [c_(c, k) + delta_u * s_(c, k)]P` (`0 <= u < 2^21`, `delta_u = chain_n(u)` distinct integers in `[-16, 33 * 63549 - 17]`, width `< 2^22 << r`) and streaming their 448-byte Y-records around the 1,024-generator ring (`ysnd -> ydlv -> ydlve`); meanwhile each generator `g` in `C_c` draws its own independent batch blinding coin `rho_(g, k) in [1, p)`. Incidence `l` (`0 <= l < Q2 = 12 * 2^21 = 25,165,824`) on generator `g` pairs `Y_(c, k, l // 12)` with `X_(g, l mod 12)`, producing `6 * Q2` leaves `x(phi^t(X_(g, j)) + s * Y_(c, k, u))` (`t in {0, 1, 2}`, `s in {+1, -1}`), `n0 = 6 * q1 * Q2 = 1,751,541,350,400,000,000` leaves per generator, `M_G * n0` per cluster, and `S = 2^68 * n0 = 2^128.603331` leaves in all.

Three exact distributional properties hold on an opened run:
1. **Permanent X uniformity and scalar hiding.** Given all `b_g`, all `2^68 * 12` points `X_(g, j)` are i.i.d. uniform on `G`. Conversely, given all curve points `(X_(g, j))`, for each `b_g in [0, r)` there is a unique tuple `(a_(g, 0), ..., a_(g, 11)) in [0, r)^12` producing `(X_(g, j))`, so all `b_g` remain independent and uniform on `[0, r)` given all curve points.
2. **Streamed Y marginal uniformity.** For any `(c, k, u)` and any fixed `s_(c, k)`, since `c_(c, k)` is uniform on `[0, r)` independent of `(s_(c, k), X)`, `c_(c, k) + delta_u * s_(c, k) mod r` is uniform on `[0, r)`, so `Y_(c, k, u)` is uniform on `G`, independent of `X` and of every other chain `(c', k') != (c, k)`.
3. **Pairwise chain uniformity.** Fix any `u != v` in `[0, 2^21)`. Since `0 < |delta_v - delta_u| < 2^22 < r` and `r` is prime, `delta_v - delta_u != 0 (mod r)`. The bijection `(c_k, s_k) in Z_r x (Z_r \ {0}) |-> (y_1, y_2) = (c_k + delta_u * s_k, c_k + delta_v * s_k) mod r` maps onto `{(y_1, y_2) in Z_r^2 : y_1 != y_2}` (`s_k = (y_2 - y_1)/(delta_v - delta_u) != 0`, `c_k = y_1 - delta_u * s_k`), so `(Y_(c, k, u), Y_(c, k, v))` is **uniform on `{(P_1, P_2) in G^2 : P_1 != P_2}`** (`r(r - 1)` pairs, probability `1/(r(r - 1)) < 1/(r - 1)^2` per distinct pair).

Let `D_sym` be the `mu_6`-symmetric boundary set `{Z in G \ {O} : exists t in {0,1,2}, t128(beta^t x(Z) mod p) mod 2^22 in [0, 264) U [2^22 - 389, 2^22)}`, which contains `D'` (`[-132, 194] subset [-389, 264]`) and has measure `<= D_LAB_SYM = 2 * (3 * 653) * 2^(128 + PART) / (r - 1)`. Both `W` and `D_sym` are unions of 6-element `mu_6`-classes in `G \ {O}` depending solely on the curve point (`L' in class(L) => (L not in W U D_sym <=> L' not in W U D_sym)`), and on clean batches every leaf outside `W U D_sym` emits the unique exact `class_label` (Lemma L.1). For `alpha = {L, L'} in Gamma` (`|Gamma| = (S^2 - 2^58 * (1024 n0)^2)/2`), define the good-class collision indicator `J_alpha = 1[L' in class(L) and L not in W U D_sym] <= I_alpha`. Since distinct clusters have independent uniform `L, L'` on `G` and `|G \ (O U W U D_sym)| >= (r - 1)(1 - D_WJ - D_LAB_SYM)` partitioned into 6-element classes, `E[J_alpha] >= P1_GOOD = 6(r - 1)(1 - D_WJ - D_LAB_SYM) / r^2`, giving `mu = |Gamma| * P1_GOOD = 6.917619811` (while `mu_raw = |Gamma| * P1`). Because `0 <= J_alpha <= I_alpha` depends on the exact same cluster/point coins `(X, c, s)` as `I_alpha`, `B_alpha` (`b_3 = 0`) and the pairwise upper bound `E[J_alpha J_beta] <= E[I_alpha I_beta] <= 36/(r - 1)^2` in §6.2 hold unchanged.

### 6.2 Chen–Stein on cross-cluster pairs and halving-and-squaring `e^-mu` enclosure (`mu > 1`)

Let `W = sum_(alpha in Gamma) I_alpha`. An indicator `I_alpha` for `alpha = {L_1, L_1'}` (`L_1` in cluster `c` using `X_(g, j)` and chain `(c, k)`, `L_1'` in `c' != c` using `X'_(g', j')` and chain `(c', k')`) depends only on `(X_(g, j), c_(c, k), s_(c, k), X'_(g', j'), c'_(c', k'), s'_(c', k'))`. Let `B_alpha` be the set of `beta in Gamma` sharing at least one of those two permanent `X`-points or two cluster Y-chains with `alpha`. Then `I_alpha` is independent of `{I_beta : beta not in B_alpha}` (`b_3 = 0`). Each permanent `X_(g, j)` participates in `6 * q1 * L_chain = 6 * n_Y` leaves (`n_Y = q1 * 2^21`), and each cluster Y-chain `(c, k)` participates in `6 * M_G * Q2` leaves across the `M_G = 1,024` generators of cluster `c`, so `|B_alpha| <= 2 * (6 * n_Y + 6 * M_G * Q2) * S = 12(n_Y + M_G * Q2) * S`.

For every `beta != alpha` in `B_alpha`, `E[I_alpha * I_beta] <= 36 / (r - 1)^2`: write `I_alpha <= sum_(w_1 in mu_6) 1[E_1(w_1)]` and `I_beta <= sum_(w_2 in mu_6) 1[E_2(w_2)]` over `mu_6 = {+-1, +-lambda, +-lambda^2} mod r`, where `E_1(w_1)` is
`lambda^(t_1') x' + e_1' (c'_(c', k') + delta_(u') s'_(c', k')) - w_1 lambda^(t_1) x - w_1 e_1 (c_(c, k) + delta_u s_(c, k)) ≡ 0 (mod r)`.
- **Case 1 (`beta` uses at least one permanent `X`-point or cluster Y-chain outside `alpha`).** Condition on all coins except that fresh `X` (uniform on `Z_r` even if it sits on another generator `g_2 != g` of the same cluster `c`) or fresh `c_(c_2, k_2)` (uniform on `Z_r`). Its coefficient in `E_2(w_2)` is a unit in `mu_6`, while `E_1(w_1)` does not contain it and has probability `1/r`, giving `P(E_1 and E_2) = 1/r^2 < 1/(r - 1)^2`.
- **Case 2 (`beta` uses the exact same `X_(g, j), X'_(g', j')` and chains `(c, k), (c', k')` as `alpha`).** Condition on `(s_(c, k), s'_(c', k')) in (Z_r \ {0})^2`. Then `(x, c_(c, k), x', c'_(c', k'))` is uniform on `Z_r^4`.
  - *Subcase 2a (coefficient rows non-proportional mod `r`):* rank 2 over `F_r` gives `P(E_1 and E_2) = 1/r^2`.
  - *Subcase 2b (`Row 2 = gamma * Row 1`):* comparing coordinates forces `gamma in {+1, -1}` and `gamma^3 = 1`, hence `gamma = 1`, `(t_2, e_2, t_2', e_2', w_2) = (t_1, e_1, t_1', e_1', w_1)`, and `(v, v') != (u, u')`. Subtracting `E_1` from `E_2` leaves `w_1 e_1 (delta_v - delta_u) s_(c, k) - e_1' (delta_(v') - delta_(u')) s'_(c', k') ≡ 0 (mod r)` with at least one nonzero `(delta_v - delta_u)` or `(delta_(v') - delta_(u'))` mod `r`: either no solution (`P = 0`) or at most one `s'_(c', k')` per `s_(c, k)` (`P <= 1/(r - 1)`) times `1/r` over `c_(c, k)`, giving `P(E_1 and E_2) <= 1/(r(r - 1)) < 1/(r - 1)^2`.

Summing over the 36 pairs `(w_1, w_2)` and applying Arratia, Goldstein and Gordon (*Ann. Probab.* 17 (1989), Theorem 1) gives
`|P(W = 0) - e^(-mu)| <= b_1 + b_2 <= |Gamma| * 12(n_Y + M_G * Q2) * S * (P1^2 + 36/(r - 1)^2) < 2^-62.95`, verified in `certificate.py`. For `mu > 1`, `exp_neg_hi(mu)` in `certificate.py` chooses the least `k >= 0` with `m = mu / 2^k <= 1`, lower-truncates `m_lo = floor(2^200 * m) / 2^200 <= m` (so `e^(-m_lo) >= e^(-m)`), encloses `eh_0 = exp_interval(-m_lo, 45)[1] >= e^(-m)`, and squares `k` times with outward ceiling rounding to `2^-300` at each step (`eh_(i+1) >= eh_i^2 >= 0`), yielding a rigorous upper bound `e_hi >= (e^(-mu / 2^k))^(2^k) = e^(-mu)`.

### 6.3 Usefulness on an opened run

An opened-run cross-cluster colliding pair `alpha = {L, L'} in Gamma` (`g in C_c`, `g' in C_(c')`, `c != c'`) is **detected** if no permanent `X` is `O`, no two permanent `X`'s in a cluster share a class, both records come from clean batches without wrong class index, label error or fixup-meter stop, both survive the home-slot cap, no intruder enters their chain between them, and no candidate, request or relay cap is reached first. Given all curve points, `b_g` and `b_(g')` are independent uniform on `[0, r)` (6.1), so `n' = u * n` occurs with probability `1/r`, and otherwise resolution recovers `x` with `[x]P = Q`. Thus `P(opened run fails) <= P(W = 0) + E #{alpha in Gamma : I_alpha = 1, alpha useless or undetected} + glob`.

### 6.4 Lemma L (computed labels), Lemma C (collision conditioning), and defect/cap/intruder rows

- **Lemma L (representation-dependent computed labels).** For any point `Z in G \ {O}`, let `Lambda_b(Z)` be the set of `b`-bit label prefixes (`b in {42, 84, 148, 170}`) that `bwd` and `keys` can emit for `Z` across all valid representations `(c, w)` and member indices `j in {0, 1, 2}` on clean batches. By §3.3's deterministic error enclosures (`[-132, 194]`, `[-132, 194]`, `[-389, 264]` in `2^22`-unit 106-bit boxes):
  1. Outside `W U D'`, `j` equals the exact canonical index and neither 106-bit part crosses a box boundary, so **`|Lambda_b(Z)| = 1`**.
  2. On `D' \ W` (measure `<= d_lab`), `j` is exact and each 106-bit part's `<= 654`-ulp error window straddles at most one boundary of a `2^22`-ulp box, so **`|Lambda_b(Z)| <= 2 * 2 = 4`**.
  3. On `W` (measure `<= d_wj`), any of the `3` class rotations can be chosen and each of its two parts can straddle at most one box boundary, so **`|Lambda_b(Z)| <= 3 * 4 = 12`**.
  Conversely, every `Z` with `lambda in Lambda_b(Z)` falls in `lambda`'s widened `b`-bit lattice cell (`WIDE = 654 * floor(p / 2^128) + 4`, `lattice lemma` box factor `< 1 + 1/3195`), containing `<= (r - 1) * KB(b)` curve points:
  - *(a) Cross-incidence leaf with a fresh coin:* `P(lambda_b(B) = lambda_b(A)) <= P(lambda_b(A) in Lambda_b(B)) <= KB(b)`.
  - *(b) Same-incidence ordered pair `(A, B)` (`A != B`, 5 choices of `B` per `A` on a clean batch):* `(A, B)` is an invertible `Z[omega]`-linear map of `(X, Y)`, so given `A`, `B` is uniform on `G` (up to `RHO`), giving `P(lambda_170(A) = lambda_170(B)) <= E_A[|Lambda_170(A)|] * KB(170) <= (1 + 11(d_wj + d_lab)) * KB(170)` and `sip = RHO * (5/2) * (1 + 11(d_wj + d_lab)) * KB(170)`.

- **Lemma C (joint home/relay-cell bounds under collision conditioning `I_alpha = 1`).** Fix `alpha = {L, L'} in Gamma` (`L` in `(c_0, k_0)`, `L'` in `(c'_0, k'_0)`, `c'_0 != c_0`). Outside `W U D'`, `L` and `L'` emit the exact common home `h(L') = (d_1, d_2)` (`84` bits) and relay `d_1` (`42` bits; relay cell `d_2` has `42` bits).
  1. For any event `E` depending only on coins outside `c'_0`, `P(E | I_alpha = 1) <= (r / (r - 1)) P(E) < RHO * P(E)`.
  2. Set `CLUST_BATCH = M_G * 6 * Q2` (`= 1,024 * 6 * 25,165,824`), `FIXED_LEAVES = 2 * CLUST_BATCH`, `PARTNER_PAIRS = CLUST_BATCH * (CLUST_BATCH - 1)`, and `alpha_cross = 12 * S + PARTNER_PAIRS + CLUST_BATCH^2` (summed explicitly in `certificate.py`).
  3. Partition every unordered pair `pi = {A, B} != alpha` into three exhaustive cases:
     - *Case 3a (`A, B` both outside `(c_0, k_0) U (c'_0, k'_0)`):* bounded by `RHO * S^2 * KB(84) * KB(170)` (and `sip * S`; `KB(42)` for relay cell `d_2`).
     - *Case 3b (`B` outside `(c_0, k_0) U (c'_0, k'_0)`, `A` inside):* the `<= 12 * S` pairs with `A` in `L`'s or `L'`'s incidence have `P(match_170(A, B) | I_alpha = 1) <= KB(170)` via `B`'s fresh `c_B` (charged via `12 * S * KB(170)` in `alpha_cross`); all other `A` in `(c_0, k_0) U (c'_0, k'_0)` also carry `KB(84)` (`KB(42)`) by independent `X` or Pairwise Chain Uniformity 6.1.
     - *Case 3c (`A, B` both inside `(c_0, k_0) U (c'_0, k'_0)`):* all `PARTNER_PAIRS + CLUST_BATCH^2` cross-incidence pairs are charged explicitly inside `alpha_cross * KB(170)` without any `KB(84)` or `KB(42)` factor.

- **Defect, slot, intruder and cap bounds (`certificate.py`):** `glob < 2^-25.96`, `d_f < 2^-18.42`, `d_p2 < 2^-36.03` (`CAP_H = 2^47.2219`, `m_p2 = S * KB(84) + 1`), `d_cl < 2^-18.59` (`CAND_CAP = 2^27`), `d_rq < 2^-15.79` (`REQ_CAP = 49 * 2^33`), `d_rl < 2^-27.42` (`RELAY_CAP = 2^40`), `lam_int < 2^-38.79`.

### 6.5–6.6 Opened-run success lower bound and grouped early abort (`G = 1536`, `m_g = floor(q1 * (g/1536)^(28/32))`)

At `q1 = 11,600,000,000`, `lo_run = 1 - e_hi - (b_1 + b_2) - mu_raw(1 + 1/r)(1/r + lam_int + 2 * per_leaf) - glob >= 0.998697380855`. On an opened run, group `g` (`1 <= g <= 1536`) runs `(m_(g-1), m_g]` with history `H_g = (Y_(<g), X, b, Q)` and outward-rounded `PHI[g] >= min(1, max(0, 1 - lo(m_(g-1))))` (`PHI[0] = 1` down to `PHI[1535]`, verified nonincreasing in `[0, 1]`): deterministic group work, main-pair walks/K3 hits (`PAIRM = KB(131) + 1/r`, `PAIRK2 = KB(148) + 1/r`), and exact-carry key paths (`JPATH = 1, SJOIN = 1`) are weighted by `PHI[g]`, while same-cluster-batch pairs (`SXV, SXK2, EK2, ELIST`) and defective-batch rows (`DEFV, DEFK2, DEFL, DEFJ`) are charged globally without `PHI`, summing to `E_run <= 2^134.843377` instructions.

### 6.7 Unconditional single-execution success and expected work under the 128-bit coordinator run gate

Let `G_open = {u < K_GATE}` be the coordinator gate event (`u` uniform on `[0, 2^128)`, independent of `Q` and of all opened-run coins `(b, a, c, s, rho)`), with `K_GATE = 132917291944920932309227833155252984270` (`p_gate = P(G_open) = K_GATE / 2^128 = 0.390608815`).
1. **Unconditional single-execution success probability:** On `G_open^c` the algorithm outputs nothing (`0` success); on `G_open` it executes the full opened run with conditional recovery probability `P(recover x | G_open) = P_open(recover x) >= lo_run` by independence of `u` from `(Q, b, a, c, s, rho)`. Therefore:
   `P(recover x) = P(G_open) * P(recover x | G_open) >= p_gate * lo_run >= 0.390100000000 > 0.39`,
   and `certificate.py` verifies both `(K_GATE / 2^128) * lo_run >= 0.3901` and `((K_GATE - 1) / 2^128) * lo_run < 0.3901`.
2. **Unconditional expected and worst-case work:** Every execution runs the coordinator gate (`<= GATE_INSNS = 256` instructions); on `G_open^c` (`0` instructions thereafter) total work is `<= 256`, and on `G_open` conditional expected further work is `<= E_run` (worst case `<= R_worst_open`). By linearity of expectation:
   `E[R] <= GATE_INSNS + P(G_open) * E_run = 256 + (K_GATE / 2^128) * E_run <= 2^133.487173` instructions (`time_log2 <= 123.521388662669609`), and on every execution `R <= 256 + R_worst_open <= 2^179.732111` instructions.
