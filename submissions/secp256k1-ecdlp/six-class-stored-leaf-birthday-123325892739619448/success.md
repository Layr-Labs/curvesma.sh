## 6.6 Grouped early abort: stopping time, hash chains, E-work
Groups and stopping are proof.md 2.3's: G = 1023 groups of 155250000 batches in lockstep, each run as in 6.1-6.5, stopping at the first group resolving an x with [x]P = Q (latched); otherwise no output. So E[walks_g^main 1_valid | H_g] <= (pair count) PAIRM uniformly in H_g (a deterministic count), and E[1_{T>g-1} walks_g^main] <= PHI[g] x bound + DEFV. **Same-batch pairs** (SAMEX: a batch's 6 q2 leaves) are charged globally without PHI. Both emitted folds come from one batch, so the joint-label argument of 6.4 applies: through two points Z_B is uniform given Z_A (F3) and the pair fold-matches with probability <= PAIRM_SB = JL KB_C130 + 1/r; through one Y point Lemma M multiplies this by F2 on average over Phase 0 (SB_PAIRS = sum SAMEX + (F2 - 1) SAMEY; certificate SXV), plus d_batch for a defective shared batch (in DEFV).
**Fold lemma (C130).** A uniform leaf (>= r - 1 points) of a clean batch emits given fold bits (d1, d2, K2 mod 2^58) with probability <= KB_C130 = 6 CNT130 (CELLU + 2D)²/(p(r-1)) = 0.341289 KB(130). ### 6.7 Run gate
One coin u, uniform on [0, 2^64) and independent of the challenge and of every other coin, opens the run iff u < K (proof.md 2.4). The run's success is a function of the challenge and the run's coins only, so conditioning on u < K leaves 6.0-6.6 verbatim and P(success) >= (K/2^64) lo_run. K = 7195544218988398094 is the least integer with (K/2^64) lo_run >= 0.39 (K and K - 1 checked, exact rationals). A closed gate costs GATE = 2^7 instructions, an opened one GATE plus the run's work, of expectation E_run: E = 2^7 + (K/2^64) E_run (proof.md 7). The gate is independent of H_g, so PHI and every E-row are unchanged.

No independence hypothesis is added; PHI, every row, K and the gate are exact Fractions; finite tests are not success evidence.
