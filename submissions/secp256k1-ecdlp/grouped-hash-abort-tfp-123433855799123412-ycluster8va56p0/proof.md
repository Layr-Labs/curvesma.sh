## 1. Overview

On secp256k1 (y^2 = x^3 + 7 over F_p, p = 2^256 - 2^32 - 977, prime order r, phi(x,y) = (beta x, y) = [lambda](x,y)), after the gate opens Phase 0 partitions the 2^66 generators into N_POOLS = 2^15 pools of K_GEN = 2^51 generators via a GF(1024) Vandermonde map and uses yround + xemit + route.s + dlvh + hhclr to mine MX = 8 permanent points X_(p,0..7) per pool in 4 birthday pairs with 0 < delta_A_q = A_(p,2q+1) - A_(p,2q) < 2^63 (A = y^2 = x^3 + 7 mod p). In Phases 1-5, six leaves x(phi^t(X) +- Y) (t = 0,1,2) are labelled per incidence from one batched inverse of D = y_Y^2 - y_X^2 via (Ew - b) + beta^t(Fw - a) + beta^(2t) Gw, using 1-limb delta_A_q in C1BSPLIT_BDAY and 2 delta_A_q < 2^64 in EQUAD6_ONE. Records travel in two hops from 2^66 generators through 2^41 relays to 2^82 homes, joining arrival-order hash chains (HB = 50) over G = 2048 groups.
