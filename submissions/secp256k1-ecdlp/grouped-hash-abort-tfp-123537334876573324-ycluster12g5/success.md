# Success (proof.md section 6): opened-run success >= 0.3901 and expected work

Every symbol is defined here or in proof.md 1-5 (caps 2; label and chain parameters 3.2; W, D', KB 3.3; sites and fixups 3.4; costs 5); certificate.py recomputes every stated rate bound (each check threshold is the stated figure) and the census figures. Constants: p = 2^256 - 2^32 - 977, r = group order (prime), C0 = 2^32 + 977, phi(x,y) = (beta x, y) = [lambda](x,y), mu_6 = {+-1, +-lambda, +-lambda^2} mod r (the 6 units fixing the x-class), RHO = (r/(r-1))^2.

## 6.1 Opened-run model, indicators, distributional facts

All algorithm coins (the 128-bit coordinator gate coin u of 6.7 and all opened-run coins b_g, a_(g,j), c_(c,k), s_(c,k), rho_(g,k)) are drawn by the sampler of proof.md 5.1; given that no coin fails (a failure is charged in glob, 6.4) they are independent and exactly uniform on their stated ranges; the challenge Q = [x]P is uniform on G. Sections 6.1-6.6 analyze an **opened run** (conditional on u < K_GATE, independent of (Q, b, a, c, s, rho)); 6.7 multiplies by p_gate = K_GATE/2^128.

The NODES = 2^68 generators are partitioned into N_CLUST = 2^58 disjoint Y-ring clusters C_c (0 <= c < 2^58) of M_G = 1,024 generators g = 1024 c + m (0 <= m < 1024). **Each generator g draws its own fresh independent uniform b_g in [0, r) and MX = 12 fresh independent uniform scalars a_(g,0), ..., a_(g,11) in [0, r)**, setting R_g = [b_g]Q and its permanent points X_(g,j) = R_g + [a_(g,j)]P. **No two generators share a coin.**

For batch k = 1..q1 (q1 = 11,600,000,000 < 2^34), generator m = (k-1) mod 1024 of cluster C_c draws fresh uniform c_(c,k) in [0, r) and s_(c,k) in [1, r) (S_(c,k) = [s_(c,k)]P != O) and generates L_CHAIN = 2^21 points Y_(c,k,u) = [c_(c,k) + delta_u s_(c,k)]P (0 <= u < 2^21, delta_u distinct integers of width < 2^22 << r), streamed as 448-byte records around the 1,024-generator ring; each generator g in C_c draws its own batch coin rho_(g,k) in [1, p). Incidence l (`0 <= l < Q2 = 12 * 2^21 = 25,165,824`) on g pairs Y_(c,k,l//12) with X_(g, l mod 12), producing LEAVES = 6 leaves x(phi^t(X_(g,j)) + s Y_(c,k,u)) (t in {0,1,2}, s in {+1,-1}). Thus n0 = 6 q1 Q2 = 1,751,541,350,400,000,000 leaves per generator, M_G n0 per cluster, and S = 2^68 n0 = 2^128.603331 leaves overall.

**Three exact distributional facts on an opened run:**
1. **Permanent-X uniformity and scalar hiding.** Given all b_g, the `2^68 * 12` points X_(g,j) are independent uniform on G. Conversely, given all X_(g,j), for each b_g in [0,r) there is a unique (a_(g,0),...,a_(g,11)) reproducing X_(g,.), so all b_g remain independent uniform given all curve points.
2. **Streamed-Y marginal uniformity.** For any (c,k,u) and any fixed s_(c,k), c_(c,k) uniform and independent of (s,X) makes c_(c,k) + delta_u s_(c,k) mod r uniform, so Y_(c,k,u) is uniform on G, independent of X and of every other chain (c',k') != (c,k).
3. **Pairwise chain uniformity.** Fix u != v in [0, 2^21). Since 0 < |delta_v - delta_u| < 2^22 < r and r is prime, delta_v - delta_u != 0 mod r. The map (c_k, s_k) in Z_r x (Z_r \ {0}) -> (c_k + delta_u s_k, c_k + delta_v s_k) is a bijection onto {(y_1,y_2): y_1 != y_2}, so (Y_(c,k,u), Y_(c,k,v)) is uniform on {(P_1,P_2) in G^2 : P_1 != P_2} (probability 1/(r(r-1)) < 1/(r-1)^2 per distinct pair).

**Boundary and good sets.** W (window set, measure <= D_WJ) and D' (label-error set, <= D_LAB) are defined in proof.md 3.3 on the x-coordinate a leaf carries; W^6 = W U phi(W) U phi^2(W) is the mu_6-closure of W (measure <= 3 D_WJ); D_sym is the mu_6-symmetric boundary {Z in G \ {O} : exists t in {0,1,2}, T(beta^t x(Z) mod p) mod 2^22 in [0,264) U [2^22-389, 2^22)} (T of proof.md 3.2), which contains D' and has measure `<= D_LAB_SYM = (2/(r-1)) * (3*653) * 2^(128+PART)` (PART = 64 + D1 = 106). Both W^6 and D_sym are unions of 6-element mu_6-classes depending only on the curve point.

**Indicators.** Gamma is the set of unordered cross-cluster leaf pairs alpha = {L, L'} with L in cluster c, L' in c' != c; |Gamma| = (S^2 - N_CLUST (M_G n0)^2)/2. For alpha in Gamma, I_alpha = 1[L' in class(L)] (an x-coordinate collision), and the **good-collision indicator** J_alpha = 1[L' in class(L) and L notin W^6 U D_sym] <= I_alpha: as W^6 U D_sym is a union of classes, neither L nor L' then lies in W U D', so both emit the class label (proof.md 3.3). Define W_good = sum_(alpha in Gamma) J_alpha. Since distinct clusters have independent uniform L, L' (facts 1-2), with |G \ (O U W^6 U D_sym)| >= (r-1)(1 - 3 D_WJ - D_LAB_SYM) partitioned into 6-element classes:
- P1 = (6(r-1)+1)/r^2 (the exact per-pair x-collision probability, E[I_alpha] = P1);
- P1_GOOD = (6(r-1)/r^2)(1 - 3 D_WJ - D_LAB_SYM) (E[J_alpha] >= P1_GOOD);
- mu_raw = |Gamma| P1 and mu = |Gamma| P1_GOOD = 6.917619811.

## 6.2 Chen-Stein for W_good; e^-mu enclosure

Let W_cnt = sum_(alpha in Gamma) I_alpha. I_alpha for alpha = {L_1, L_1'} (L_1 using X_(g,j) and chain (c,k); L_1' using `X'_(g',j')` and chain (c',k')) depends only on (X_(g,j), c_(c,k), s_(c,k), `X'_(g',j')`, `c'_(c',k')`, `s'_(c',k')`). Let B_alpha be the set of beta in Gamma sharing at least one permanent X-point **or** one cluster Y-chain with alpha. Then I_alpha is independent of {I_beta : beta notin B_alpha} (so the Chen-Stein b_3 = 0). Each X_(g,j) lies in 6 n_Y leaves (n_Y = q1 2^21), each chain (c,k) in 6 M_G Q2 leaves, so |B_alpha| <= 2(6 n_Y + 6 M_G Q2) S = 12(n_Y + M_G Q2) S =: deg.

**Joint-pair bound E[I_alpha I_beta] <= 36/(r-1)^2 for every beta != alpha in B_alpha.** Write I_alpha <= sum_(w_1 in mu_6) 1[E_1(w_1)], I_beta <= sum_(w_2 in mu_6) 1[E_2(w_2)], where each E(w) is one linear collision equation over F_r in the fresh coins. Because permanent X-points are per-generator independent (6.1 fact 1), the only coins alpha and beta can share are (i) an identical permanent X_(g,j) of a common generator, and/or (ii) an identical cluster Y-chain (c,k).
- **Case 1 (beta uses a permanent X or a cluster chain outside alpha):** condition on all coins except that extra fresh X (uniform on Z_r) or fresh c_(.,.) (uniform on Z_r); it appears with a unit coefficient in E_2 but not in E_1, so P(E_1 and E_2) = 1/r^2 < 1/(r-1)^2.
- **Case 2 (beta uses exactly the same X_(g,j), `X'_(g',j')` and chains (c,k), (c',k') as alpha):** condition on (s_(c,k), `s'_(c',k')`); then (x, c_(c,k), x', `c'_(c',k')`) is uniform on Z_r^4.
  - *2a (the two coefficient rows are non-proportional mod r):* rank 2 gives P(E_1 and E_2) = 1/r^2.
  - *2b (Row 2 = gamma Row 1):* matching coordinates forces gamma^3 = 1 and gamma in {+-1}, hence gamma = 1, (t,e,t',e',w) equal, and (v,v') != (u,u'). Subtracting leaves w_1 e_1 (delta_v - delta_u) s_(c,k) - e_1' (delta_(v') - delta_(u')) `s'_(c',k')` = 0 with a nonzero delta difference: either no solution or at most one s' per s, times 1/r over c_(c,k), so P(E_1 and E_2) <= 1/(r(r-1)) < 1/(r-1)^2.

  Summing the 36 pairs (w_1,w_2) gives the stated bound. experiment.py part C checks these inequalities and the degree-4 fibre count on a toy curve (p = 43, r = 31: Case 2a over all (X_1,Y_1,X_2,Y_2), Case 1 in fresh-X form and Case 2b at fixed X_1, X_2, alpha = (0,+1)); the proof is the case analysis.

**Chen-Stein applied directly to W_good (Arratia, Goldstein, Gordon, Ann. Probab. 17 (1989), Thm 1).** The theorem states: for indicators Z_alpha with p_alpha = E[Z_alpha], lambda = sum p_alpha, and neighbourhoods B_alpha (alpha in B_alpha) such that Z_alpha is independent of {Z_beta : beta notin B_alpha}, |P(sum Z_alpha = 0) - e^-lambda| <= b_1 + b_2 with b_1 = sum_alpha sum_(beta in B_alpha) p_alpha p_beta, b_2 = sum_alpha sum_(alpha != beta in B_alpha) E[Z_alpha Z_beta] (and b_3 = 0). Apply it to Z_alpha = J_alpha. Since J_alpha = I_alpha 1[L notin W^6 U D_sym] and membership of the curve point L in W^6 U D_sym is a function of L, hence of the same coins as I_alpha, J_alpha is independent of {J_beta : beta notin B_alpha} with the same B_alpha. From 0 <= J <= I pointwise: p_alpha = E[J_alpha] <= P1 and E[J_alpha J_beta] <= E[I_alpha I_beta] <= 36/(r-1)^2, so b_1 + b_2 <= |Gamma| deg (P1^2 + 36/(r-1)^2) =: cs < 2^-63. And lambda_J = E[W_good] = sum_alpha E[J_alpha] >= |Gamma| P1_GOOD = mu, so, e^-x being decreasing, **P(W_good = 0) <= e^-lambda_J + cs <= e^-mu + cs**. This one-sided bound is the only Chen-Stein step used; it holds verbatim at every prefix batch count q1p, with mu(q1p), cs(q1p) computed from n0 = 6 q1p Q2. For mu > 1, exp_neg_hi(mu) chooses least k with m = mu/2^k <= 1, lower-truncates m_lo = floor(2^200 m)/2^200 <= m, encloses e_hi_0 = exp_interval(-m_lo)[1] >= e^-m, and squares k times with outward ceiling rounding (each e_hi_(i+1) >= e_hi_i^2), yielding e_hi >= e^-mu.

## 6.3 Usefulness on an opened run

A cross-cluster colliding pair alpha = {L, L'} in Gamma (g in C_c, g' in C_(c'), c != c') is **detected** if: no permanent X is O; no two permanent X in a cluster share a class; both records come from clean batches with no wrong class index, no label error, no fixup-meter stop; both survive the home-slot cap; no intruder (6.4 item 2) exists; and no candidate, request or relay cap is reached first. Given all curve points, b_g, b_(g') are independent uniform (6.1 fact 1), so the useless event n' = u n has probability 1/r; otherwise resolution recovers x with [x]P = Q. Thus P(opened run fails) <= P(W_good = 0) + E#{alpha : J_alpha = 1, alpha useless or undetected} + glob, and P(W_good = 0) <= e^-mu + cs <= e_hi + cs by 6.2; the expected count is bounded through J <= I by mu_raw times the per-pair failure rates (6.4, `rows_`).

## 6.4 Lemmas L and C; defect, cap and intruder rows

**KB.** For b label bits, `KB(b) = 6 * 2^(256-b) (KBF+1)/((r-1) KBF)` (KBF = 3195) bounds the probability that a uniform curve point's emitted label takes b given bits; a widened b-bit cell holds <= (r-1) KB(b) points (lattice lemma, proof.md 3.3).

**Lemma L (representation-dependent computed labels).** For Z in G \ {O}, let Lambda_b(Z) be the set of b-bit prefixes that bwd/keys can emit for Z over all valid representations and member indices on clean batches. By proof.md 3.3: outside W U D', |Lambda_b(Z)| = 1; on D' \ W, <= 4; on W, <= 12; so `|Lambda_b(Z)| <= 1 + 11 * 1[Z in W U D']`. Conversely every Z with a given lambda in Lambda_b(Z) lies in lambda's widened cell, which holds <= (r-1) KB(b) curve points. Hence (a) a cross-incidence leaf with a fresh coin matches a fixed label with probability <= KB(b); (b) a same-incidence ordered pair (A,B) (A != B, 5 choices of B) has B = s A + (lambda^t' - s lambda^t) X (s, t, t' its sign and windows) with a nonzero coefficient; this term is averaged over the uniform X, which is independent of I_alpha (P(I_alpha = 1 | X) = P1 for every X), so B is uniform on G (up to RHO) given A, and P(label_170(A)=label_170(B)) <= (1 + 11(D_WJ + D_LAB)) KB(170) and sip = RHO (5/2)(1 + 11(D_WJ + D_LAB)) KB(KEYBITS+D1+D2).

**Batch-defect and fixup rows.** D_BATCH < 2^-127.4 (11 defect sites, D_j = 0, D_YGEN), E_FIX (20 fixup sites), FIX_BATCH and DELTA_F = 2^52 are derived in proof.md 3.4; a generator stops on its meter with probability <= q1 E_FIX/(DELTA_F - FIX_BATCH) (Markov) or meets a defect with probability <= q1 D_BATCH, so d_f = q1 E_FIX/(DELTA_F - FIX_BATCH) + q1 D_BATCH < 2^-18.4. D_WJ < 2^-58.47 and D_LAB < 2^-10.65 are proof.md 3.3's.

**Lemma C (bounds conditional on (X, I_alpha = 1)).** As J_alpha <= I_alpha, P(J_alpha = 1, F) <= P(I_alpha = 1) P(F | I_alpha = 1) for each failure event F, so rows conditioned on I_alpha = 1 and weighted by mu_raw = sum P(I_alpha = 1) bound the 6.3 count. The rows are Markov bounds on expected counts, so by linearity E[. | I_alpha = 1] = E_X E[. | X, I_alpha = 1] (X is independent of I_alpha), and bounds conditional on X also bound Lemma L(b)'s averages over X. Condition on all permanent points X outside the excluded set {X = O} U {two X in a cluster share a class} (facts 1-3 then fix X), and fix alpha = {L_1, L_2} in Gamma with L_1 in (c_1,k_1) at offset u_1, L_2 in (c_2,k_2) at u_2, c_1 != c_2. Set CLUST_BATCH = M_G LEAVES Q2, FIXED_LEAVES = 2 CLUST_BATCH, PARTNER_PAIRS = CLUST_BATCH(CLUST_BATCH - 1), K_U_CLUST = LEAVES M_G MX = 73,728.
1. **Conditional Y-coin law.** Every batch outside {(c_1,k_1),(c_2,k_2)} is independent of I_alpha, law unchanged up to RHO. For (c_1,k_1),(c_2,k_2), for each fixed (s_1,s_2) in (Z_r \ {0})^2 the pair (c_(c_1,k_1), c_(c_2,k_2)) is uniform on Z_r^2 with P(I_alpha = 1 | X, s_1, s_2) = P1 independent of (s_1,s_2). By Bayes, given (X, I_alpha = 1): (s_1,s_2) stays uniform on (Z_r \ {0})^2; L_1 (hence Y_(c_1,k_1,u_1)) has conditional point-mass <= 6/(6(r-1)+1) < 1/(r-1) <= RHO/r; and every other point Y_(c_1,k_1,u') (u' != u_1) is uniform on G \ {Y_(c_1,k_1,u_1)} by pairwise chain uniformity, hence <= 1/(r-1) <= RHO/r marginally (likewise in (c_2,k_2)).
2. **Intruders lam_int.** An **intruder** for alpha is a record of a third leaf whose emitted 170-bit label equals the class label of L_1; it can take the place of L_1 or L_2 in the home chain, so 6.3 counts alpha as undetected whenever one exists, whatever its arrival time. The Sp - FIXED_LEAVES leaves outside the two batches have independent Y (<= KB(D1+D2+D3+D4) each); the leaves inside at u' != u_1,u_2 have density <= RHO/r (<= RHO KB(...)); the <= 2 K_U_CLUST leaves at u_1,u_2 have A' = +-[zeta] L_1 + Delta with fixed Delta != O, where zeta = 1 at u_1 and zeta in {1, lambda, lambda^2} at u_2 (I_alpha = 1 gives L_2 = +-[zeta] L_1), so a separated-pole degree-4 map gives <= 8 solutions per residue. Hence the expected number of intruders, and so their probability, is <= lam_int = RHO (Sp + FIXED_LEAVES) KB(D1+D2+D3+D4) < 2^-38.8.
3. **Home-slot overflow d_p2.** Let Z_out be records at home h(L_1) from batches outside the two, Z_in <= FIXED_LEAVES all records from the two batches. Z_out is independent of I_alpha, so P(Z_in + Z_out >= CAP_H | X, I_alpha=1) <= P(Z_out >= CAP_H - FIXED_LEAVES | X) <= v_p2 / (CAP_H - FIXED_LEAVES - m_p2)^2 = d_p2 < 2^-19.9, with m_p2 = Sp KB(D1+D2) + 1, cov_p2 = (Sp K_U_CLUST L_CHAIN/(r-1)) KB(D1+D2)^2, v_p2 = K_U_CLUST Sp KB(D1+D2) + cov_p2 + 1 (the bounded-position second moment: at most K_U_CLUST same-X leaves per chain position contribute covariance).
4. **Candidate/request/relay loads.** With SAMEX_FAC = ((CLUST_BATCH - K_U_CLUST)/(CLUST_BATCH - 1))(r/(r-1)) + 24(K_U_CLUST-1)/(CLUST_BATCH-1) and alpha_cross = 2 K_U_CLUST Sp + SAMEX_FAC Sp (CLUST_BATCH - 1) + PARTNER_PAIRS + CLUST_BATCH^2, partition all pairs pi = {A,B} != alpha: both outside the two batches (independent of I_alpha, bounded by RHO Sp^2 KB(D1+D2) kb_m with kb_m = KB(KEYBITS+D1+D2), plus sip Sp same-incidence); one inside (fresh outside Y gives KB(170), inside density <= RHO/r); both inside (alpha_cross cross-incidence pairs, same-offset handled by the degree-4 map). Then other_h = RHO(Sp^2 KB(D1+D2) kb_m + alpha_cross kb_m) + sip Sp, d_cl = other_h/(CAND_CAP - 4) < 2^-18.6; other_g = RHO(2 n0 Sp kb_m + 2 LEAVES MX Sp kb_m) + 24 LEAVES MX n0 kb_m, d_rq = other_g/(REQ_CAP - 8) < 2^-15.8; other_v = RHO(2 + 16)((Sp/SIDE) Sp KB(D2) kb_m + alpha_cross kb_m) + 18 sip Sp, d_rl = other_v/(RELAY_CAP - 16) < 2^-27.4.

**Per-leaf and whole-run rows.** per_leaf = D_BATCH + d_f + d_p2 + d_cl + d_rq + d_rl; `rows_ = mu_raw (1 + 1/r)(1/r + lam_int + 2 per_leaf)` (the factor 1 + 1/r is unused slack; 1/r is the useless event of 6.3); glob = NODES(3 q1 + MX + 1)/2^254 + NODES MX/r + N_CLUST ((M_G MX)(M_G MX - 1)/2)(6/(r-1)) + g_def with g_def = NODES q1 D_BATCH, glob < 2^-25.5: a coin failure (proof.md 5.1: < 2^-254 per coin, <= 3 q1 + MX + 1 coins per generator), a permanent X = O (1/r each), two permanent X of one cluster in one class (6/(r-1) per pair), and the whole-run defect rows.

## 6.5-6.6 Opened-run success; grouped early abort

`lo(q1p) = 1 - e_hi - cs - rows_ - glob` at generator-batch count q1p (with `Sp = S(q1p) = 2^68 * 6 q1p Q2`, n0p = 6 q1p Q2) (certificate.py success_prefix; 6.2-6.3 at q1p). At q1 = 11,600,000,000, lo_run = lo(q1) >= 0.998683334439.

Group g (1 <= g <= G = 1536) runs batches (m_(g-1), m_g] with m_g = floor(q1 (g/1536)^(28/32)). Let F_(<g) be the sigma-algebra of all coins used in groups 1..g-1 (all Y_(<g), all X, b, Q). The early-abort rule stops the run once a useful collision has been detected; so group g executes only on the event {T_stop > g-1}, which is F_(<g)-measurable (it depends only on records produced in groups < g). The **PHI-weighted** rows are the deterministic per-group work and the clean walks/d4-hits/key-paths whose expected cost is bounded, conditional on F_(<g), by its unconditional bound times 1[T_stop > g-1]: with PHI[g] = ceil_256(1 - lo(m_(g-1))) (where ceil_256(x) = ceil(2^256 x)/2^256, clamped to [0,1]), P(T_stop > g-1) <= PHI[g], because {T_stop > g-1} is contained in the failure of the prefix run on batches 1..m_(g-1), whose probability is <= 1 - lo(m_(g-1)) by the 6.2-6.4 argument applied verbatim at q1p = m_(g-1) and the clean rows' conditional expectation uses the fresh uniform c_(c,k) of group g (independent of F_(<g)), so E[1[T_stop>g-1] W_g] <= PHI[g] E[W_g] pointwise over the tower. certificate.py checks PHI[0] = 1, PHI nonincreasing in [0,1], and PHI[g] >= 1 - lo(m_(g-1)) exactly. The rows **not** weighted by PHI (SXV, SXK2, EK2, ELIST, the `DEF*` defective-batch rows, E_FIX_WORK, E_CAND_WORK, E_REQ_WORK) are charged in full. The resulting opened-run expected work is E_run <= 2^134.859302 instructions (2^124.893518 units, <= 76.4250 per leaf), itemized as the 26-cell ledger of proof.md 5.

## 6.7 Unconditional success and expected work under the gate

Let G_open = {u < K_GATE}, u uniform on [0, 2^128) independent of (Q, b, a, c, s, rho), K_GATE = 132919164825389149851328308155366463994, p_gate = K_GATE/2^128 = 0.390614318.
1. **Success.** On G_open^c the algorithm outputs nothing; on G_open it runs the full opened run with P(recover x | G_open) >= lo_run. Thus `P(recover x) = p_gate * lo_run >= 0.39010001 > 0.3901`. certificate.py verifies (K_GATE/2^128) lo_run >= 0.39010001 and ((K_GATE-1)/2^128) lo_run < 0.39010001.
2. **Expected work.** Every run executes the gate (<= GATE_INSNS = 256); on G_open^c nothing more. By linearity, E[R] <= 256 + p_gate E_run = 2^133.503120 instructions, i.e. time_log2 <= 123.537334876573324.
