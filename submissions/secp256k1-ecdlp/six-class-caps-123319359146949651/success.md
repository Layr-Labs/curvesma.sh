## 6.6 Grouped early abort: stopping time, hash chains, E-work
Groups and stopping are proof.md 2.3's: G = 1023 groups of 155420000 batches in lockstep, each run as in 6.1-6.5, stopping at the first group resolving an x with [x]P = Q (latched); otherwise no output. With T the first resolving group, group g's leaf/route work and hash fixed cost are deterministic and run only if T > g - 1, and its main-pair walks, K2 hits and listings have means bounded uniformly in H_g; so with P(T > g - 1) <= PHI[g] the expected work is E_pre + sum_g PHI[g] (W_g + W_K2,g + W_list,g) + W_sameX + W_K2,glob + W_list,glob + W_def + W_rest (proof.md 7) by linearity and the domination below. ### 6.7 Run gate
One coin u, uniform on [0, 2^64) and independent of the challenge and of every other coin, opens the run iff u < K (proof.md 2.4). The run's success is a function of the challenge and the run's coins only, so conditioning on u < K leaves 6.0-6.6 verbatim and P(success) >= (K/2^64) lo_run. K = 7195514789500152966 is the least integer with (K/2^64) lo_run >= 0.39 (K and K - 1 checked, exact rationals). A closed gate costs GATE = 2^7 instructions, an opened one GATE plus the run's work, of expectation E_run: E = 2^7 + (K/2^64) E_run (proof.md 7). The gate is independent of H_g, so PHI and every E-row are unchanged.

No independence hypothesis is added; PHI, every row, K and the gate are exact Fractions; finite tests are not success evidence.
