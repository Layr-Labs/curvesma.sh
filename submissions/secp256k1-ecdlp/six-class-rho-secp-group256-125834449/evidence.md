# Evidence (proof.md section 2.6)

The declared `experiment.py` run with `"kernels": true` is designed to perform the following checks. The full declared run has not completed locally; only the separate diagnostics explicitly described in items 2, 3, 5 and 6 completed. Inherited numbers elsewhere describe the predecessor and are not a claim of a successful run of this candidate:

1. **Limb ports, planned check.** The run compares the field multiplication, squaring, subtraction, reduction, fused operations and shared rows against big integers, including edge values, random values and constructed carry and negative-fold cases. The complete declared run has not finished locally.
2. **The shipped loops.** The declared run checks pass1, prod and pass2 on production points in batches of 1, 3, 6 and 257 walks against affine arithmetic and checks the returned borrow counts. It compares the 1- and 257-walk counts with the group rates. A separate isolated diagnostic using four repeated points checked 258 walks, with zero mismatches and group rates 13.5078125, 169.50390625 and 337.50390625; this diagnostic is narrower than the declared random-point run.
3. **Counts and ledger.** The run parses the shipped files and checks 1,729 = 128·13 + 65, 43,393 = 256·169 + 129 and 86,401 = 256·337 + 129. The loop A 127-walk and prod/pass2 255-walk tail charge is 1,780.015625, and the conservative per-round fixed charge is 26,333. The step price is 34849/64 + 1155/256 + 26,333/2^23. The separate accounting diagnostic used assumed already-checked instruction counts; it is not a complete certificate run.

5. **Rare exits.** The declared run is designed to exercise the pass1, prod and pass2 rare exits in constructed batches of up to 257 walks, checking each result, meter decrement and borrow count. These batches were split to fit the local runner limit, and are not a substitute for completion of the declared initial experiment.
