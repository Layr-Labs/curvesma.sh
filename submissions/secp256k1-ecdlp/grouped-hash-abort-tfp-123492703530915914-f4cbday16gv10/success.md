### 6.1 Phase-0 Vandermonde transversal birthday X-pair mining, scalar hiding, and coin model

All coins — the 128-bit gate coin `u in [0, 2^128)` (§6.7), Phase-0 coins `(b_g, c_(g,b), s_(g,b), rho)`, and Phase 1–3 coins `(c_(c,k), s_(c,k), rho_(g,k))` — are independent and uniform; `Q = [x]P` is uniform on `G` (`|G| = r` prime). Sections 6.1–6.6 bound opened-run (`u < K_GATE`) success `lo_run` and expected work `E_run`; §6.7 combines them unconditionally with `p_gate = K_GATE / 2^128`.

The `2^68` generators form `N_CLUST = 2^58` Y-clusters `C_c` (`g = 1024 c + m`, `0 <= m < 1024`) and `N_POOLS = 2^15` transversal X-pools `P_p` via `GF(1024) = GF(2)[z]/(z^10 + z^3 + 1)`: writing `u_c = c & 31`, `v_c = (c >> 5) & 0x3ff`, generator `g` belongs to `pool(g) = 32 m + h(c, m)` with `h(c, m) = (u_c ^ gf1024_mul(v_c, m)) & 31`. For fixed `(m, v_c)`, `u_c -> h(c, m)` is a bijection on `[0, 32)`, so every pool has exact size `K_GEN = 2^53` and each `C_c` has `1024` distinct pools. For any `0 <= m_1 < m_2 < 1024`, `m_1 ^ m_2 != 0` in `GF(1024)`, so `dv -> gf1024_mul(dv, m_1 ^ m_2) & 31` is surjective of `GF(2)`-rank `5` (`certificate.py` `_vand_gf1024_ok` checks all `1023` non-zero `d`), hitting `0` on `32` of `1024` values of `dv = v_(c_1) ^ v_(c_2)` with unique `du = u_(c_1) ^ u_(c_2) = gf1024_mul(dv, m_1) & 31`; thus exact count `SHARED_BOTH_CLUST_PAIRS = (N_CLUST^2 / 1024 - N_CLUST) / 2` of cluster pairs `c_1 < c_2` satisfy `h(c_1, m_1) == h(c_2, m_1)` and `h(c_1, m_2) == h(c_2, m_2)` (`experiment.py` `C_vandermonde_cs`).

**Phase-0 pool & bad-`X` bounds (`P_FAIL_ALL_POOLS < 2^-47.21`, `P_BAD_X < 2^-72.99`).** In `P_p`, each `g` draws `b_g in [0, r)` (`R_g = [b_g]Q`) and runs `NBATCH_MINE = 2^32` chains (`c_(g,b) in [0, r)`, `s_(g,b) in [1, r)`) of `32,768` points `R_g + [c_(g,b) +- j s_(g,b)]P` (`1 <= j <= 16,384`, `M_POOL = 2^100`/pool), hashing `A = x^3 + 7 mod p` into `2^193` buckets `A >> 63`:
1. Each bucket holds `<= 6 * 2^63` points (`P_BUCKET_MAX = 6 * 2^63 / (r - 1)`), giving same-chain hits `P_SAME_CHAIN_POOL < 2^-76.4` by pairwise uniformity (`2 * 16,384 < r`). Distinct chains have independent uniform `c_(g,b) in [0, r)` (absorbing `R_g`), hitting the same bucket with `0 < |A_2 - A_1| < 2^63` with probability `>= 1/2^193 - 6/(r - 1) = P_BDAY_HIT_MIN` by Cauchy–Schwarz (`MU_POOL_LO > 63.99`).
2. Cross-chain indicators in `P_p` depend only on their two chains; by chain independence (1 shared chain) and pairwise chain uniformity (2 shared chains, distinct offsets), co-occurrence is `<= P_BUCKET_MAX^2`, giving `CS_POOL < 2^-64.8`, `P_TRIPLE_POOL < 2^-83.3` on 3-chain triples (any triple sharing a chain already contains a same-chain pair in `P_SAME_CHAIN_POOL`), `P_FAIL_ALL_POOLS < 2^-47.21`, and same-`A` cross-chain hits `P_SAME_A_ALL = N_POOLS * C(M_POOL, 2) * 6/(r - 1) < 2^-39.4` across `2^15` pools (charged in `glob`). Outside `P_FAIL_ALL_POOLS U SAME_A_ALL`, `0` triples and `0` same-`A` matches occur, so the collector's first `8` (hence `<= 64` capped) reports yield `8` vertex-disjoint pairs `(X_(p,2q), X_(p,2q+1))` lie in distinct `193`-bit buckets with `0 < A_(p,2q+1) - A_(p,2q) < 2^63`, so all `16` points in `P_p` have distinct `A` (disjoint `mu_6`-orbits). For any `z in G \ {O}`, the probability `z` is selected in `P_p` — or that a mined pair satisfies `phi^(t_2)(X_(2q+1)) - sigma phi^(t_1)(X_(2q)) = z`, bounded via the degree-12 elliptic morphism `Q -> x(z - Q)^3 - x(Q)^3` whose poles at `O != z` give fiber `<= 12` per `d in (-2^63, 2^63) \ {0}` — is `<= POINTWISE_X_MAX / (r - 1) < 1,538 / (r - 1)`. Let `B_X` be the event that `1 <= k <= 4` formally distinct slots `(p_s, j_s)` across `>= 2` pools satisfy a non-zero `Z[lambda]`-sum `sum_s gamma_s X_(p_s, j_s) = O` (`<= 2,048` unit-sum tuples): unioning over `1`-slot-in-`p_b` (`N_POOLS (N_POOLS MX)^3 M_POOL 2048 / r`) and `2`-slots-in-`p_a` vs `2`-slots-in-`p_b` (single mined pair via `24 * 2^63 / (r(r - 1))` degree-12 fibers plus two mined pairs) gives `P(B_X) <= P_BAD_X < 2^-72.99` (charged in `glob`).
3. **Scalar hiding:** Conditional on all Phase 0–3 curve points and step scalars (fixing `(X_(p,j), h(p,j))` and all candidates), for `Q != O` (`x = 0` covered by `1/r` in `rows_`), `c_(g,b) = dlog_P(P_(g,b,0)) - b_g x mod r` is a bijection on `[0, r)^NBATCH_MINE`, so `(b_g)` remain i.i.d. uniform on `[0, r)`.

### 6.2–6.4 Swap-free conditional-`X` Chen–Stein, shared-position audit, and failure rows

For `q1p` batches (`n0p = 6 q1p Q2`, `Sp = 2^68 n0p`), define **swap-free `Gamma(q1p)`** as all unordered leaf pairs `alpha = {L_1, L_2}` on `g_1 = 1024 c_1 + m_1`, `g_2 = 1024 c_2 + m_2` with `c_1 < c_2`, `pool(g_1) != pool(g_2)`, **and** `m_1 < m_2` whenever `h(c_1, m_1) == h(c_2, m_1)` and `h(c_1, m_2) == h(c_2, m_2)`, giving exact size `|Gamma(q1p)| = GOOD_NODE_PAIRS * n0p^2`. Condition on `X` outside `P_FAIL_ALL_POOLS U B_X`:
- **Mean:** Independent uniform `c_(c_1,k_1), c_(c_2,k_2) in [0, r)` make `(L_1, L_2)` uniform on `G x G`, so `E[J_alpha | X] = P1_GOOD = (6(r - 1)/r^2)(1 - D_WJ - D_LAB_SYM)` by `mu_6`-invariance of `W U D_sym`, and `mu(q1p) = |Gamma(q1p)| P1_GOOD` (`6.913803478` at `q1 = 8.7e9`).
- **Dependence (`|B_alpha| <= 2 CLUST_BATCH Sp`, `E[J_alpha J_beta | X] <= 36/(r(r - 1))`, `cs < 2^-82.43`):** Given `X`, `J_alpha` depends only on `(c_1, k_1), (c_2, k_2)`. For `beta = {L_3, L_4} in B_alpha \ {alpha}` (`c_3 < c_4`): (1) if `beta` has an unshared batch, its uniform `c in [0, r)` gives `<= 36/r^2 < 36/(r(r - 1))`; (2) if `(c_3, k_3) = (c_1, k_1)` and `(c_4, k_4) = (c_2, k_2)` with `u_3 != u_1` (or `u_4 != u_2`), uniformity of `(Y_(u_1), Y_(u_3))` on distinct pairs of `G` (`0 < |delta_(u_3) - delta_(u_1)| < L_chain < r`) gives `(6/r)(6/(r - 1)) = 36/(r(r - 1))`; (3) if `(u_3, u_4) = (u_1, u_2)`, `sigma_2 Y_2 - zeta sigma_1 Y_1 = Delta_alpha` and `sigma_4 Y_2 - zeta' sigma_3 Y_1 = Delta_beta` have `<= 1` solution `(Y_1, Y_2) in G^2` on the `30` pairs `(zeta, zeta')` with `sigma_2 sigma_4 sigma_3 zeta' != sigma_1 zeta`, and `0` solutions on the `6` zero-determinant pairs (`(1,3)+(2,4)` forces `beta = alpha`; `(1,2)+(3,4)` contradicts `p_1 != p_2`; swapped `(1,4)+(2,3)` requires shared pools with both `m_1 < m_2` and `m_2 < m_1`, impossible; single-pool survival contradicts distinct `A`; multi-pool survival is excluded by `B_X^c`), giving `<= 30/r^2 < 36/(r(r - 1))` (`C_vandermonde_cs`) and `cs < 2^-82.43` by Arratia–Goldstein–Gordon Theorem 1.
- **Shared-position & cap rows:** Since `h(p_1, j_1) != h(p_2, j_2)` for `p_1 != p_2`, §6.1(3) gives `P(nu' == u nu mod r | points) = 1/r`. At each `(c, k, u)` (`K_u = 6 M_G MX = 98,304` leaves), `0 <= Z_(c,k,u) <= K_u` gives `Var(Z_(c,k,u) | X) <= K_u E[Z_(c,k,u) | X]`, `u != u'` adds `COV < 2^-250`, and distinct batches have `0` covariance given `X`, so `v_p2 = K_u Sp KB(84) + COV + 1` (`d_p2 < 2^-19.41`). Same-cluster-batch pairs (`u_1 != u_2` at `r/(r - 1)` plus `u_1 = u_2` at `<= 1,538 / L_chain`) obey `SAMEX_FAC < 1.001` in `SXV`, `SXK2`, and `alpha_cross` (`2 K_u Sp` covering `u_1, u_2` in `alpha`'s batches): `d_f < 2^-18.33`, `d_cl < 2^-18.62`, `d_rq < 2^-15.82`, `d_rl < 2^-27.45`, `lam_int < 2^-38.81`, `glob < 2^-25.81`, `lo(q1p) = 1 - exp(-mu(q1p)) - cs(q1p) - rows(q1p) - glob(q1p)`.
