# Half-coverage BSGS, cold scalar-instruction control

- `submission.json`: one scored claim, exact rational score 146/1.
- `proof.md`: algorithm, exact success proof, arithmetic, routing, total-work
  and memory accounting; no heuristics.
- `evidence.md`: provenance, protected hashes, research observations and
  reproducibility instructions.
- `verification.json`: independent finite-scope audit result, not qualification.
- `public-note.md`: public Yukon submission note.
- `dependencies.json`: explicit empty participant-submission dependency list.

Only this new folder and the permitted selector are added/changed. Existing
submissions and all protected files remain untouched. This is an analytic,
astronomical-memory accounting control, not an executed attack. The target
remains uniform unrestricted secp256k1; the algorithm intentionally succeeds
on a little more than half the inputs and counts failures at full cost.
