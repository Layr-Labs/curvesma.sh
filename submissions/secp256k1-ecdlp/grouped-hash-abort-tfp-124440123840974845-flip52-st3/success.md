# Success, section 6 of proof.md (no heuristic)

### 6.1 Flipped-grid coin model and pairwise chain uniformity

All algorithm coins are independent and uniform; the challenge `Q = [x]P` is uniform on `G`. Each generator `g` (`0 <= g < 2^68`, called a "node" below) draws fresh uniform `b_g in [0, r)` and `a_0, ..., a_255 in [0, r)`, setting `R_g = [b_g]Q` and its `MX = 256` permanent points `X_j = R_g + [a_j]P`. For each batch `k = 1..q1` (`q1 = 2327370190`), generator `g` draws fresh uniform `c_k in [0, r)`, `s_k in [1, r)` (`S_k = [s_k]P != O`), and `rho_k in [1, p)`, forming `L_chain = q2 / MX = 2^17` (`q2 = 2^25`) streamed points `Y_(k, u) = [c_k + delta_u * s_k]P` (`0 <= u < 2^17`), where `delta_u = chain_n(u)` are `2^17` distinct integers in `[-16, 33 * 3972 - 17]` (`width < 2^18 << r`). Batch `k`'s `q2` incidences are `(Y_(k, l >> 8), X_(l & 255))` for `0 <= l < 2^25`, yielding `6 * q2` leaves `x(phi^t(X_j) + s * Y_(k, u))` (`t in {0, 1, 2}`, `s in {+1, -1}`), `n0 = 6 * q1 * q2` per generator and `S = 2^68 * n0 = 2^126.701016` leaves in all.

Three exact distributional properties hold:
1. **Permanent X uniformity and scalar hiding.** For any fixed `b_g`, `X_0, ..., X_255` are i.i.d. uniform on `G` (`r` points). Conversely, given all points `(X_j)`, for each value of `b_g in [0, r)` there is a unique tuple `(a_0, ..., a_255) in [0, r)^256` producing `(X_j)`, so the `b_g` remain independent and uniform on `[0, r)` given all curve points.
2. **Streamed Y marginal uniformity.** For any `k, u` and any fixed `s_k`, as `c_k` is uniform on `[0, r)` independent of `(s_k, X)`, `c_k + delta_u * s_k mod r` is uniform on `[0, r)`, so `Y_(k, u)` is uniform on `G`, independent of `X` and of every other chain `k' != k`.
3. **Pairwise chain uniformity.** Fix any `u != v` in `[0, 2^17)`. Since `0 < |delta_v - delta_u| < 2^18 < r` and `r` is prime, `delta_v - delta_u != 0 (mod r)`. The map `(c_k, s_k) in Z_r x (Z_r \ {0}) |-> (y_1, y_2) = (c_k + delta_u * s_k, c_k + delta_v * s_k) mod r` has `y_2 - y_1 = (delta_v - delta_u) * s_k != 0 (mod r)`, and every pair `(y_1, y_2) in Z_r^2` with `y_1 != y_2` has the unique preimage `s_k = (y_2 - y_1)/(delta_v - delta_u) != 0`, `c_k = y_1 - delta_u * s_k`. Hence `(Y_(k, u), Y_(k, v))` is **uniform on `{(P_1, P_2) in G^2 : P_1 != P_2}`**, a set of `r(r - 1)` pairs (probability `1/(r(r - 1)) < 1/(r - 1)^2` per distinct pair).

Let `Gamma` be the set of unordered leaf pairs from different generators (`|Gamma| = (S^2 - 2^68 * n0^2)/2`). For `alpha = {L, L'} in Gamma`, `L` and `L'` are independent and uniform on `G`, so `P(I_alpha = 1) = P(L' in class(L)) = P1 = (6(r - 1) + 1)/r^2` (`6(r - 1)` pairs on `G \ {O}` plus `(O, O)`), and `mu = |Gamma| * P1 = 0.495512933`. Same-generator collisions are omitted; they can only help. Cross-generator collisions are single pairs, not clusters: a match `phi^t(X) + sY = w(phi^(t')(X') + s'Y')` between independent generators forces a second match among the two incidences' other leaves only via a second linearly independent relation on fresh coins (probability `<= 1/(r - 1)`, inside `P1` and section 6.2).

### 6.2 Chen–Stein on cross-generator pairs (per-chain random steps)

Let `W = sum_(alpha in Gamma) I_alpha`. An indicator `I_alpha` for `alpha = {L_1, L_1'}` (`L_1` in generator `g` using `X_j` and chain `k`, `L_1'` in `g' != g` using `X'_{j'}` and chain `k'`) depends only on `(X_j, c_k, s_k, X'_{j'}, c'_{k'}, s'_{k'})`. Let `B_alpha` be the set of `beta in Gamma` sharing at least one of those two X-points or two Y-chains with `alpha`. Then `I_alpha` is independent of `{I_beta : beta not in B_alpha}` (`b_3 = 0` in the Chen–Stein theorem). On any generator, a fixed `X_j` participates in `6 * q1 * L_chain = 6 * n_Y` leaves (`n_Y = q1 * 2^17`) and a fixed chain `k` participates in `6 * q2` leaves, so `|B_alpha| <= 2 * (6 * n_Y + 6 * q2) * S = 12(n_Y + q2) * S`.

We now show `E[I_alpha * I_beta] <= 36 / (r - 1)^2` for every `beta != alpha` in `B_alpha`. Write `I_alpha <= sum_(w_1 in mu_6) 1[E_1(w_1)]` and `I_beta <= sum_(w_2 in mu_6) 1[E_2(w_2)]` over the 6 cube-root/sign units `mu_6 = {+-1, +-lambda, +-lambda^2} mod r`, where `E_1(w_1)` is the linear relation:

`lambda^(t_1') x' + e_1' (c'_{k'} + delta_(u') s'_{k'}) - w_1 lambda^(t_1) x - w_1 e_1 (c_k + delta_u s_k) ≡ 0 (mod r)`.

- **Case 1 (`beta` uses at least one X-point or Y-chain outside `alpha`).** Condition on all coins except that fresh `X_{j_2}` (uniform on `Z_r`) or fresh `c_{k_2}` (uniform on `Z_r`). Its coefficient in `E_2(w_2)` is a unit in `mu_6` (invertible mod `r`), while `E_1(w_1)` does not contain it and has probability `1/r` (fixing `x'` or `c'_{k'}`). Thus `P(E_1(w_1) and E_2(w_2)) = 1/r^2 < 1/(r - 1)^2`.
- **Case 2 (`beta` lies in `{g, g'}` and uses only `alpha`'s `X, X'` and `alpha`'s chains `k, k'`).** Then `beta = {L_2, L_2'}` with `L_2 = phi^(t_2)(X) + e_2 Y_(k, v)` in `g` and `L_2' = phi^(t_2')(X') + e_2' Y'_(k', v')` in `g'`. Condition on `(s_k, s'_{k'}) in (Z_r \ {0})^2`. Given `(s_k, s'_{k'})`, the four scalars `(x, c_k, x', c'_{k'})` remain i.i.d. uniform on `Z_r^4`, and `E_1(w_1), E_2(w_2)` are two linear equations on `Z_r^4` with homogeneous coefficient rows:
  `Row 1 = (-w_1 lambda^(t_1), -w_1 e_1, lambda^(t_1'), e_1')`, `Row 2 = (-w_2 lambda^(t_2), -w_2 e_2, lambda^(t_2'), e_2')`.
  - **Subcase 2a (`Row 1` and `Row 2` are not proportional mod `r`).** The `2 x 4` matrix has rank 2 over `F_r`, so for every `(s_k, s'_{k'})`, the solution space in `Z_r^4` has size `r^2`, giving `P(E_1 and E_2) = 1/r^2 < 1/(r - 1)^2`.
  - **Subcase 2b (`Row 2 = gamma * Row 1` for some `gamma in F_r^*`).** Comparing the last two coordinates gives `lambda^(t_2') = gamma * lambda^(t_1')` and `e_2' = gamma * e_1'`. Thus `gamma = e_2'/e_1' in {+1, -1}` while `gamma = lambda^(t_2' - t_1')` satisfies `gamma^3 = 1`; since `(-1)^3 = -1 != 1`, `gamma = 1`, forcing `t_2' = t_1'` and `e_2' = e_1'`. Comparing the first two coordinates then gives `w_2 lambda^(t_2) = w_1 lambda^(t_1)` and `w_2 e_2 = w_1 e_1`, so `lambda^(t_2 - t_1) = e_2/e_1 in {+1, -1}`, hence `t_2 = t_1`, `e_2 = e_1`, and `w_2 = w_1` (`Row 1 == Row 2`). Because `beta != alpha`, `(v, v') != (u, u')`, so at least one of `delta_v - delta_u` or `delta_(v') - delta_(u')` is nonzero mod `r`. Subtracting `E_1` from `E_2` cancels `(x, c_k, x', c'_{k'})` identically and leaves:
    `w_1 e_1 (delta_v - delta_u) s_k - e_1' (delta_(v') - delta_(u')) s'_{k'} ≡ 0 (mod r)`.
    If only one difference is nonzero, this equation has **no solution** in `(Z_r \ {0})^2` (`P = 0`). If both differences are nonzero, for each `s_k in Z_r \ {0}` at most one `s'_{k'} in Z_r \ {0}` satisfies it (`P <= 1/(r - 1)`), and given any such `(s_k, s'_{k'})`, `E_1` holds with probability `1/r` over `c_k`. Thus `P(E_1 and E_2) <= 1/(r(r - 1)) < 1/(r - 1)^2`. *(Note: a public step `s_k = s'_{k'}` would fail here at `delta_v - delta_u = delta_(v') - delta_(u')`; per-chain random steps `s_k` prevent shift-recurring collisions.)*

Summing over the 36 unit pairs `(w_1, w_2)` gives `E[I_alpha I_beta] <= 36/(r - 1)^2`. By the Chen–Stein Poisson approximation theorem (Arratia, Goldstein and Gordon, *Ann. Probab.* 17 (1989), Theorem 1),
`|P(W = 0) - e^(-mu)| <= b_1 + b_2 <= |Gamma| * 12(n_Y + q2) * S * (P1^2 + 36/(r - 1)^2) < 2^-75.02`, checked in `certificate.py`.

### 6.3 Usefulness

A cross-generator colliding pair `alpha = {L, L'}` is **detected** if no permanent `X_j` is `O`, both records come from clean batches without wrong class index, label error or fixup-meter stop, both survive the home-slot cap, no intruder enters their chain between them, and no candidate, request or relay cap is reached first. Its pair is then resolved, a useful chain edge (proof.md §4) yields `x`, and `[x]P = Q` is verified before output. Given all curve points, `b_g` and `b_(g')` are independent uniform on `[0, r)` (6.1), so `n' = u * n` (`n = lambda^t b_g`, `n' = lambda^(t') b_(g')`) occurs with probability `1/r`. Any valid relation among the two records' candidate leaves solves `x` when `n' != u * n`. Thus `P(fail) <= P(W = 0) + E #{alpha in Gamma : I_alpha = 1, alpha useless or undetected} + glob`.

### 6.4 Defect, cap and intruder rows

Two lemmas, written out here, carry every label-match and home/relay factor below (they were asserted in 17a007c8's text; the numbers are unchanged).

**Lemma L (computed labels).** For a point `Z != O` and a set of `b` compared label bits (`170` for a record match, `83` home, `41` relay part, `147`/`130` for `K3` hits and buckets), let `Lambda_b(Z)` be the set of values the kernels can store for `Z` over **all** representations `Z = phi^t(X) + sY` and all members `KEY` may select. (i) The truncated-product errors of 3.3 lie in representation-independent intervals (`[-132, 194]`, `[-132, 194]`, `[-389, 264]` units of `2^-128`), so outside `W ∪ D'` the stored bits are `Z`'s exact class bits (`|Lambda_b(Z)| = 1`); on `D' \ W` each 106-bit part of the selected member is its exact value or the single neighbour reachable inside the error window (a part box is `2^22` units wide, the window `654` units, so at most one boundary is reachable), `|Lambda_b(Z)| <= 4`; on `W` any of the three members may be selected, `|Lambda_b(Z)| <= 12`. `Lambda_b`, `W` and `D'` depend only on `Z`'s class. (ii) For every fixed value `lambda`, `mu{Z : lambda in Lambda_b(Z)} <= KB(b)`: such a `Z` has a member value `v` whose two parts lie in `lambda`'s cell widened by the error window, the lattice lemma (3.3; `certificate.py` "lattice lemma", box `BOX + WIDE`) bounds the number of such `v`, and each `v` accounts for the `6` points whose x-coordinate is `v`, `beta^-1 v` or `beta^-2 v`; `KB(b) = 6 * 2^(256 - b) (1 + 1/3000)/(r - 1)` is that count over `r - 1`. (iii) Hence (a) if `lambda` is fixed independently of `Z`'s coins and `Z` is uniform on `G` (or on `G` minus one point), the stored bits of `Z` equal `lambda` with probability `<= KB(b)` (`<= (r/(r - 1)) KB(b)`); and (b) if `A, B` are independent uniform points whose stored bits are arbitrary functions of `(A, B)` (two leaves of one incidence: `(A, B)` is an invertible linear image of `(X, Y)`, uniform on `G^2`), then `P(stored(A) = stored(B)) <= E[sum_(lambda in Lambda(A)) mu{B : lambda in Lambda(B)}] <= E|Lambda(A)| KB(b) <= (1 + 3 d_lab + 11 d_wj) KB(b) <= (1 + 11(d_wj + d_lab)) KB(b)`, since a uniform point lies in `D'` with probability `<= d_lab` and in `W` with probability `<= d_wj` (3.3). This is the same-incidence factor `sip`. A pair whose second leaf has a fresh coin unused by the first leaf's representation (another generator, another batch `c_k`, another permanent `X_j`, or another chain point by 6.1's Pairwise Chain Uniformity) falls under (a) with `lambda` the first leaf's stored bits: factor `rho`, no `sip` factor.

**Lemma C (conditioning on the colliding pair).** Fix `alpha = {L, L'}` in `Gamma`, `L` in generator `g` (batch `k_0`, `X_(j_0)`), `L'` in `g'` (batch `k'_0`). (i) For an event `F` determined by coins of generators other than `g'`, `P(F ∩ {I_alpha = 1}) <= (6/r) P(F)` (given those coins `L` is fixed and `L'` uniform, `|class(L)| <= 6`), while `P(I_alpha = 1) = P1 >= (6/r)(1 - 1/r)`; so conditioning a count on `I_alpha` costs at most `r/(r - 1)`, inside `rho`. The same holds with `g, g'` exchanged. (ii) Detection needs `L, L' not in W ∪ D'` (otherwise the pair is charged by the `d_wj`, `d_lab` rows), so on the counted event both records go to the exact home (and relay part) `h(L') = h(L)`. For a pair `pi` with no leaf in batch `k_0` of `g` or `k'_0` of `g'`, condition on every coin except `c_(k_0)` and `c'_(k'_0)`: `pi`'s leaves, representations, stored bits, match event `M_pi` and home `h_pi` are then fixed, and `L`, `L'` are independent and uniform on `G` (each a bijection of its fresh `c` given its `X` and `s`), so `P(M_pi, h(L') = h_pi, I_alpha = 1 | rest) <= 1[M_pi] KB(83) (6/r)`; averaging, `P(M_pi) <= rho KB(170)` by Lemma L(a). For `pi = {A, B}` with `A != L` in batch `k_0` of `g` and `B` outside both of `alpha`'s batches, condition first on every coin except `B`'s fresh coin (`B` uniform up to `r/(r - 1)`, `A`'s stored bits fixed: `M_pi` has probability `<= rho KB(170)`), then over `c'_(k'_0)` (`P(L' in class(L)) <= 6/r`, and then `h(L') = h(L)`), then over batch `k_0`: `h(L) = h_A` has probability `<= rho KB(83)` when `A` is in another incidence (given `A`'s representation points, `L` is uniform on `G` or `G` minus one point) and `<= (1 + 11(d_wj + d_lab)) KB(83) < 2 KB(83)` for the `<= 5` leaves `A` of `L`'s own incidence (Lemma L(b)). Pairs with one leaf in each of `alpha`'s batches (`<= 36 q2^2`) and these `<= 5S` same-incidence-with-`L` pairs are covered by the main term's factor-`2` slack (it counts `S^2` ordered pairs at `KB(83)` for at most `S^2/2` unordered ones; `36 q2^2 + 10 S << S^2/2`). Pairs with both leaves in one of `alpha`'s batches (`PARTNER_PAIRS`) and pairs containing `L` or `L'` (`2S`) are counted without the home/relay factor. The relay rows use the same argument with the `41`-bit relay part of `h`.

- **Whole-run exclusions (`glob < 2^-28.02`).** Any permanent `X_j = O` (`<= 2^68 * 256 / r < 2^-180`), any batch defect anywhere (`g_def = 2^68 * q1 * d_batch < 2^-28.02`), or two coin-draw rejections (`2^68 * (3 q1 + 257) * 2^-254`) is charged unconditionally to `glob`. Outside `glob`, every `X_j != O` and every batch is clean.
- **Node-local defects (`d_batch`, `d_wj`, `d_lab`, `d_f`).** Each is a function of generator `g`'s coins alone, given which `L'` in `g'` is uniform on `G` (`P(I_alpha | g's coins) <= (6(r-1)+1)/r^2 < (6/r)(1 + 1/r)`), so each per-leaf rate `d` contributes at most `2 * mu * (1 + 1/r) * d` over the two leaves of `alpha`.
- **Home slots (`d_p2 < 2^-32.65`; hop 1 has no slots).** By the keep lemma (proof.md §4), a record is dropped at hop 2 only if `>= CAP_H` records addressed to its home `(d1, d2)` arrived. Set `FIXED_LEAVES = 12 * q2` (`= 2 * 6 * 2^25`), covering **all** leaves of `alpha`'s two batches (`k_0` in `g`, `k'_0` in `g'`). Condition on `(X_(j_0), c_(k_0), s_(k_0), X'_(j'_0), c'_(k'_0), s'_(k'_0))`. Every remaining leaf `A` in the run belongs to an unconditioned batch `k != k_0` (`c_k` uniform on `Z_r`), so `A` is uniform on `G` and lands in the home's widened 83-bit cell `C` (`|C| <= (r - 1) KB(83)`) with probability `|C|/r <= KB(83)`: the free count `Z` has `E Z <= m_p2 = S * KB(83) + 1`. For ordered distinct pairs `(A, B)` in `Z`, `Cov(1[A in C], 1[B in C])` is:
  - `0` if `A, B` are in different generators or different batches `k_1 != k_2` (`c_(k_1), c_(k_2)` are independent uniform on all of `Z_r`, making `A, B` independent uniform on `G` even when they share `X_(j_0)` or a free `X_j`);
  - `0` if `A, B` are in the same batch `k_1` with `j_1 != j_2` (at most one of `j_1, j_2` can be `j_0`, so the other has a free `X_j` uniform on `G`);
  - `|C|^2/(r(r - 1)) - |C|^2/r^2 <= KB(83)^2/(r - 1)` if `A, B` are in the same batch `k_1` with `j_1 == j_2` and `u_1 != u_2` (by 6.1's Pairwise Chain Uniformity; `<= 6 * L_chain * S` ordered pairs, total `COV < 2^-270 < 1`);
  - `0` if `A, B` share an incidence `(X_j, Y_(k_1, u))` with `j != j_0` (`(A, B)` is an invertible linear image of `(X_j, Y_(k_1, u))` uniform on `G^2`);
  - `<= KB(83)` on same-incidence ordered pairs using `X_(j_0)` or `X'_(j'_0)` (`2` generators × `q1 * L_chain` incidences × `30` ordered pairs = `60 * n_Y` pairs).
  Thus `Var Z <= m_p2 + 1 + 60 * n_Y * KB(83)`, and Chebyshev bounds drop probability by `d_p2 = Var Z / (CAP_H - 12 q2 - m_p2)^2 < 2^-32.65`.
- **Intruders and candidate/request/relay caps (`lam_int`, `d_cl`, `d_rq`, `d_rl`).** Here `rho = (r/(r - 1))^2` covers the at most two `s_k != 0` exclusions. Set `PARTNER_PAIRS = 6 * q2 * (6 * q2 - 1)` (`2 * (6 q2 choose 2)`), covering all cross-incidence pairs inside `alpha`'s batch `k_0` (in `g`) or `k'_0` (in `g'`). Same-incidence pairs (`5` per leaf) have `170`-bit match mass `<= (1 + 11(d_wj + d_lab)) KB(170)` (`sip`, Lemma L(b)); the home and relay factors below are Lemma C(ii). For any cross-incidence pair `pi = {A, B} != alpha`:
  - if `pi` has a leaf in a generator outside `{g, g'}`, or in a batch `k_1 != k_0`, conditioning on the other generator makes `P(I_alpha | g's coins) <= 6/r`, while over `g`'s coins `(A, B)` is pairwise uniform up to `rho` (by independent `c` across batches, independent `X` across `j`, or 6.1's Pairwise Chain Uniformity for `j_1 == j_2, u_1 != u_2`), and outside `alpha`'s batch `c_(k_0)` is untouched so `L` is independent uniform on `G` given `(A, B)` (supplying the `KB(83)` home or `KB(41)` relay factor);

### 6.5 The bound

`certificate.py` bisects from `2^31` (where the bound fails) to the least `q1` satisfying
`1 - e^(-mu) - (b_1 + b_2) - mu(1 + 1/r)(1/r + lam_int + 2 * per_leaf) - glob >= 0.390000001`,

### 6.6 Grouped early abort on streamed Y-chains: `H_g` domination and E-work

The `q1` Y-chain batches are partitioned into `G = 160` contiguous groups (`group_sizes`). All nodes execute groups `g = 1..160` in lockstep separated by two-wave barriers, halting after the first group `T` that resolves a verified `[x]P = Q` (`T = 161` if none). Let `H_g = (Y_(<g), X, b, Q)` be the history before group `g`: all permanent points `X_j` on every generator, all Y-chains of groups `< g`, all scalars `b_(g')`, and `Q` (plus earlier groups' `rho` scalars). The event `{T > g - 1}` is a deterministic function of `H_g` alone (records, chains, candidates, regenerated Y's, unit tests, `n' != u * n`, and `[x]P = Q` of groups `< g` are determined by `H_g`), and `P(T > g - 1) <= PHI[g] = min(1, 1 - lo(MQ1[g - 1]))` by the prefix bound of 6.5 (`PHI[0] = 1`, nonincreasing).

- **Deterministic group work** (Y-chain generation `y_group`, `fwd`, `fe_inv`, `bwd`, `keys` base, hop-1/hop-2 block flushes and finals, completion waits, join fixed `4`, phase-4 count exchanges, stop check) runs iff `T > g - 1`, contributing `PHI[g]` times its exact count.
- **Walks and joint K3 hit verifications.** An insert `u` from batch `k` of group `g` visits prior same-bucket records `v` (`4` instructions per visit; hit blocks are out of line via `.pushsection`, so chain ends fall through at `0` extra). Split pairs `(u, v)` into **main** (`v` from a different batch `k' != k`, either `< g` or in `g`) and **same-batch** (`k' == k`, `SAMEX[g] = 2^68 * q_g * 6 q2 * (6 q2 - 1)/2`).
  - For a **main** pair, condition on `H_g`, all batches of group `g` except `k`, and `s_k`. Batch `k`'s `c_k in [0, r)` remains fresh uniform and independent of everything conditioned on (including `v`'s stored fields, whether `v`'s batch was clean or defective!). On `{u's batch valid and X_j != O}`, `u`'s exact leaf point `phi^t(X_j) + s[c_k + delta_n s_k]P` is a bijection of `c_k` onto `G`, so `u`'s bucket match (`42 + 41 + 47 = 130` bits) has conditional probability `<= KB(130) + 1/r = PAIRM`, and its full `K3` hit (`42 + 41 + 64 = 147` bits, `5` instructions) has conditional probability `<= KB(147) + 1/r = PAIRK2`, uniformly in `H_g`. Since `1[T > g - 1]` is `H_g`-measurable, multiplying before taking expectation gives `PHI[g]` times the main-pair count (`WG`, `WGK2`). Defective `u` batches (unconditional rate `d_batch` per batch: in §3.4, `c_k` and `rho_k` are fresh per batch given `X`) walk at most `HOME_MAX = CAP_H` entries, charged globally without `PHI` in `DEFV`, `DEFK2`, `DEFL`.
  - For a **same-batch** pair (`k' == k`), dropping `1[T > g - 1] <= 1`, if `j_1 != j_2` the leaves use independent permanent `X`'s; if `(j_1, u_1) == (j_2, u_2)` the single-leaf marginal applies (`sip` in `EK2`, `ELIST`); if `j_1 == j_2` and `u_1 != u_2`, 6.1's Pairwise Chain Uniformity gives probability `<= (r/(r - 1)) KB(130) < KB(130) + 1/r = PAIRM` (`SXV`, `SXK2`).
- **Exact-carry key paths (`JPATH = 1`, `SJOIN = 1`).** In group `g`, given `H_g` and `s_k`, `c_k` makes each leaf point uniform on `G`. On `{batch valid and X_j != O}`, exact index `1` or `2` has probability `2/3` on `G \ {O}` (`phi` acts freely in 3-cycles), plus `<= d_wj` in `W` and `1/r` at `O`: `<= PJ = 2/3 + 2 d_wj + 1/(r - 1)`, uniformly in `H_g`. Each `j in {1, 2}` leaf adds `1` instruction (`MVN` vs inline `CMN, B.HS`), and the C2/C3 tree executes at most `1` `B` per sign (`1/3` per leaf, charged on every sign), giving `PHI[g] * s_g * (PJ + 1/3)` (`WGJ`) plus `DEFJ` globally; `R_worst` charges `1 + 1/3` on every leaf (`JROW_W`).
