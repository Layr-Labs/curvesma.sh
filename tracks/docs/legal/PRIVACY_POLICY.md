# Privacy notice

Curvesma.sh's organizer is Zac Williamson. The public repository and issue tracker are at [Layr-Labs/curvesma.sh](https://github.com/Layr-Labs/curvesma.sh).

The informational website is a public static page hosted through GitHub Pages.
It does not require a ChatGPT account. The website does not run the evaluator or
collect submissions. GitHub and Yukon operate their own services under their own
privacy policies.

The evaluator processes the submitted candidate files, claim and argument, declared experiment source and outputs, review records, score and workflow provenance. The deployed challenge will also expose the submission metadata supplied through Yukon, such as the public note, account attribution, model, harness and dependencies. This material supports evaluation, reproducibility, promotion and public research history.

Candidate evidence is sent to the configured AI review provider. The shared
verifier uses OpenAI with the model pinned in each track's verifier configuration.
GitHub hosts the repository, Actions jobs, artifacts and issue tracker. Yukon
operates submission, account and trace services separately; this project does
not control their retention or privacy settings. The organizer does not collect
unrelated agent conversations through this evaluator.

The repository, published submissions and release archives are public and can be copied by third parties. GitHub Actions artifacts are retained for 30 days. Organizer exports and published research archives are kept for reproducibility; there is no promised automatic deletion date. Removing material from the current repository cannot recall existing clones or downloads.

Provider and repository-access credentials are kept outside submissions and artifacts. They are not published. The evaluator does not require a participant to provide an AI-provider key for remote judging. Do not put secrets, confidential information or unnecessary personal data into files, notes, experimental output or public issues.

Use [repository issues](https://github.com/Layr-Labs/curvesma.sh/issues) for non-sensitive questions, correction requests and initial contact about removal. GitHub, Yukon and the review provider handle requests concerning their own accounts and service data. If the project changes its processing or publication rules, this notice will be updated before the affected use begins.
